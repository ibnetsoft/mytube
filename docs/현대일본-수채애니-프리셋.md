# 비 오는 골목 수채 애니

현대 일본 휴먼드라마를 위한 재사용 프리셋. 로컬 콘솔의 신규 대본 생성과 자료 기반 토픽 후보 구성에서 **현대 일본 · 비 오는 골목 수채 애니 설정** 버튼으로 적용한다. 주제와 분량을 입력한 뒤 생성한다. 기존 시대극 토픽은 변경하지 않는다.

- 언어: 일본어. 배경: 현대 일본 지방 소도시와 상점가.
- 장르: 현대 일본 휴먼드라마. 현대 구어체, 평상복, 현대 생활 환경.
- 시각: 손그림 수채·과슈 질감, 불규칙한 먹선, 청록·올리브·황토의 차분한 색감, 따뜻한 생활감.
- 참고 이미지의 비·고양이·소녀·구도는 고정 요소가 아니다. 장면과 날씨는 대본에 따른다. 참고 이미지의 한국어 간판은 복제하지 않는다.

정식 설정은 `worker/codex_console/modern_japan_watercolor.json`. 로컬 생성 워커가 프리셋 이름 또는 키를 상세 영문 이미지 지침으로 해석하여 인물 레퍼런스, 씬 이미지, 영상 프롬프트와 썸네일에 전달한다. 토픽 후보에서 신규 대본으로 이어갈 때 언어·배경·시대·이미지 스타일과 이야기 방향을 함께 넘긴다.

사용자가 제공한 참고 이미지: [스타일 참고](style-references/rainy-alley-watercolor-anime.png). 이미지는 질감·색감 검토용이며 생성 결과의 동일성은 보장하지 않는다.
