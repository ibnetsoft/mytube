# 「나 혼자 무공을 진화시킨다」 고정 소품 기준 v1

2026-11-07 사용자 요청: 주인공·주요 조연의 소품을 확정하고, 장면마다 단검 등이 바뀌는 문제를 방지한다. 기존 승인 캐릭터 시트와 1~4화 설정을 기준으로 세부 디자인을 고정한다. 아래 치수는 기존 확정 치수를 복구한 것이 아니라 이번에 고정하는 제작 기준이다. 기존 확정 원화를 일괄 덮어쓰지 않는다.

## 서진 — SEJ_DAGGER_01 / SEJ_SHEATH_01 / SEJ_PACK_01

- 단검: 전체 32cm, 칼날 21cm, 손잡이·가드·끝마개 전체 11cm. 칼날 최대 폭 3.2cm. 회색 강철 **외날**, 곧은 등과 끝으로 완만히 올라가는 날배, 하나의 뾰족한 끝. 톱니·구멍·룬·금장 없음. 부상이나 접촉에 따른 피·먼지는 장면별 상태이며 형태 변경이 아니다.
- 손잡이: 갈색 나무, 둥근 철제 리벳 정확히 2개. 짧고 곧은 폭 6cm 철제 가드, 납작한 어두운 철제 끝마개. 환두 고리·금속 원통 손잡이·주먹보호 고리·삼각 돌촉으로 바꾸지 않는다.
- 칼집: 칼날과 맞는 짙은 갈색 봉제 가죽. 날 쪽 가장자리의 누런 봉제선과 단순 가죽 허리걸이. **인물 자신의 오른쪽 허리**에 단다. 정면에서는 화면 왼쪽, 후면에서는 화면 오른쪽이다. 정면/후면 그림을 거울복사해 착용 위치를 바꾸지 않는다.
- 운반틀: 낡은 갈색 목재 A자 지게와 황갈색 삼끈. 짐·끈의 실제 소유와 보관 상태는 직전 회차에 따른다. 손에 든 단검을 또 칼집에 중복 삽입하지 않으며, 발도 상태에는 빈 칼집 입구가 보인다.

## 도겸 — DOG_FLASK_01 / DOG_PACK_01 / DOG_SCARF_01

- 물통: 기존 시트의 납작한 원형 짙은 적갈색 **가죽 물통**. 둘레 봉제선, 짧은 나무 마개, 목 부분의 삼끈 결속과 단일 긴 가죽 휴대끈. 술 호리병·도자기 병·금속 수통으로 바꾸지 않는다. 물통 지름 약 17cm, 두께 약 7cm를 기준으로 한다.
- 지게: 나무 세로대 2개와 가로대, 황갈색 삼끈, 베이지색 천 짐꾸러미. 서진과 같은 물건을 공유하는 것이 아니라 각자 별도 소유물이다. 회차별로 버리거나 보관한 지게를 무조건 등에 재등장시키지 않는다.
- 목도리: 빛바랜 연청색 천. 평상시 목에 두르지만 **2화 후반 이후 오른쪽 무릎 아래 부상 고정에 사용된 동일한 천**이다. 치료/해제 사건 전에는 목에 복제해 그리지 않는다. 물통도 직전 장면의 소유·전달 이력이 우선한다.

## 장호 — JAN_SWORD_01 / JAN_SCABBARD_01 / JAN_CASE_01

- 검: 전체 100cm, 날 78cm, 손잡이부 22cm인 곧은 양날 직검. 중앙 능선, 검은 감기 손잡이, 기존 시트의 청동색 완만한 날개형 가드와 절제된 곡선 문양, 작은 청동 끝장식. 서진의 단검·일반 무사의 검과 혼동하지 않는다.
- 칼집: 검은 칠 목재, 청동 입구·끝장식, 청동 걸이 2개. **인물 자신의 왼쪽 허리**. 붉은 허리띠는 장호의 복식 표식이고 일반 무사에게 복제하지 않는다.
- 봉함: 적갈색 직사각 목함, 청동 모서리·붉은 봉인끈. 소유권과 개폐 상태는 대본의 장호 탈출·봉인첩 설정을 따른다. 검이나 목함의 마법 발광은 원래 디자인의 일부가 아니다.

## 서리 — CLK_LEDGER_01 / CLK_BRUSH_01 / CLK_SCALE_01

- 장부: 남색 천 표지, 왼쪽 등 누런 실 4점 선장 제본, 미색 종이·붉은 세로 기입선. 장면마다 표지색·제본 방향을 바꾸지 않는다. 장부 내용은 회차 사건에 따르며 이미지 생성 글자를 실제 증거 문서 내용으로 취급하지 않는다.
- 붓: 황갈색 대나무 몸통, 작은 갈색 끝테, 미색 털과 검은 먹 끝. 주로 먹 묻은 **오른손**으로 사용한다. 칼·금속 펜으로 바꾸지 않는다.
- 저울: 작은 청동 양팔 접시저울, 둥근 받침과 접시 2개. 책상 소품이며 자동으로 휴대시키지 않는다.

## 철산문 일반 무사 — GRD_SWORD_01 / GRD_SCABBARD_01

- 검: 전체 95cm, 날 75cm, 손잡이부 20cm, 장식 없는 곧은 양날 강철검. 검은 감기 손잡이, 단순 짧은 은회색 가드와 작은 끝마개. 장호의 곡선 청동 가드·고급 장식과 명확히 구별한다.
- 칼집: 무광 검정, 단순 어두운 금속 입구와 끝. 인물 자신의 왼쪽 허리. 일반 무사·망보기·검문 무사는 얼굴 정체성을 각각 유지하되, 같은 계급의 표준 무기는 공유 가능하다.

## 운반 인부 및 이후 주요 인물

- 현 회차 운반 인부의 운반 수레·광석 자루는 그의 작업 소품이며 서진의 소유 무기로 바꾸지 않는다. 승인된 회차 원화의 수레 형태와 짐 상태를 이어받는다.
- 백소연·유하린·곽무 등 이후 인물은 실제 등장 전 승인된 인물·소품 설정에서 새 자산 ID와 전용 시트를 추가한다. 아직 확정하지 않은 소품을 이번 시트에서 확정했다고 보고하지 않는다.

## 제작·검수 계약

1. 프롬프트의 추상적인 “단검/검/물통”만으로 생성하지 않는다. 등장하는 소품의 ID, 소유자, 실제 참조 PNG와 SHA, 형태·재질·비율·착용 방향을 함께 전달한다. 없는 소품은 프롬프트에 넣지 않는다.
2. 같은 소품의 정면·측면·반대면·발도/납도는 **한 디자인의 시점/상태 차이**이며 새 디자인 후보가 아니다. 원근 때문에 화면 픽셀 길이가 달라도 실제 비율은 유지한다.
3. 매 상태 원화에서 칼날 실루엣·외날/양날·가드·손잡이 리벳·끝마개·칼집·착용 좌우와 손 해부학을 확인한다. 단검이 짧은 돌촉·환두 단검·장검으로 바뀐 이미지는 소품 불일치로 기록하고 보정한다.
4. 전달·분실·파손·수리·교체·부상 고정은 소품 연속성 표에 사건·회차·새 상태를 기록한다. 의도된 교체는 새 버전 ID로 명시한다. 이전 회차의 실제 소유권·부상 상태가 기본 착용도보다 우선한다.
5. 예전 캐릭터 시트나 원화에 모순되는 세부가 있으면 새 제작에는 본 고정 소품 시트를 우선 사용하고, 기존 최종 회차를 자동 재작성하지 않는다. 소품 보정으로 원화 SHA가 바뀌면 입모양·팝업·보호 좌표의 연결을 재검수한다.

## 승인 그림 추출 시트 우선 적용 (2026-11-07 사용자 확정)

- 실제 참조: `references/seojin-weapon-sheet-v1.png`, `references/jangho-weapon-sheet-v1.png`. 승인된 원본의 소품 부분을 픽셀 그대로 추출하고 비율 유지 2배 확대해 배치했다. 원본 크롭도 `*-weapon-crop-v1.png`로 보관한다. 새 디자인·반대면·손·착용도를 합성하지 않았다.
- **형태의 최종 권위는 이 추출 이미지다.** 앞서 텍스트로 새로 정한 치수는 계획용 비율이며 승인 그림에 없던 세부를 강제하거나 그림을 바꾸는 근거가 아니다. 특히 리벳·가드·칼집 상단 고리는 그림의 실제 모양을 유지한다. 착용 위치는 기존 소유권·인물 해부학적 좌우 규칙을 따른다.
- 새 상태 원화의 도구 호출 전에 `worker.wuxia_prop_references.imagegen_arguments(prompt, prop_ids, character_reference_paths)`를 사용한다. 반환된 `prompt`와 **`referenced_image_paths`를 내장 image_gen 호출에 그대로 전달**한다. 예: 서진 단검 노출 시 `SEJ_DAGGER_01`, 칼집 노출 시 `SEJ_SHEATH_01`, 장호 검은 `JAN_SWORD_01`, 칼집은 `JAN_SCABBARD_01`. 캐릭터 전체 참조는 기존 입력에 유지하고 소품 시트를 추가한다. 등장 소품만 명시하고 없는 무기를 만들지 않는다. 파일 SHA 불일치나 알 수 없는 ID는 조용히 참조를 빼지 않고 오류로 처리한다.
- CLI에서도 `python3 -m worker.wuxia_prop_references --prop SEJ_DAGGER_01 --reference CHARACTER.png --prompt '장면 지시'`로 실제 이미지 첨부용 인자를 만들 수 있다. 단순 프롬프트 문장·경로 기재만으로 실제 첨부했다고 보고하지 않는다. 이미지 생성 호출의 첨부 목록·SHA와 결과 원화의 모양을 함께 검수한다.
