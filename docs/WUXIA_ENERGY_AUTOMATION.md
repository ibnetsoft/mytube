# 무협 검기·신체 기운 자동 준비

새 `new`/`grounded` 무협 제작물은 `wuxia_energy_auto/v1` 정책을 켠다. 기존 확정 회차는 자동 변경하지 않는다. 사용자의 명시적 `wuxia_auto_energy:false` 설정을 보존한다.

실제 게시된 상태 원화를 SHA로 고정하고 로컬 Codex CLI가 모든 상태를 검토한다. 대본 키워드나 푸른색만으로 선택하지 않는다. 실제 검기 또는 몸에서 방출되는 기운이 있을 때만, 검토한 에너지 다각형과 인물 전체·손·검날·손잡이·글자 보호 다각형을 준비한다. 큰 신체 기운은 겹치지 않는 최대 네 영역으로 분리한다. 다른 보조 패치를 덮어쓰거나 정원에 맞춰 컷을 강제로 선택하지 않는다.

기존 내장 imagegen 브리지로 기운 제거 클린 플레이트를 만들고, 승인된 밝은 기운 영역에만 사용한다. 청색 검기뿐 아니라 황금색·붉은색·흰색 등 실제 발광을 지원한다. 검기는 원본에서 분리한 발광 성분만 이동시키며 배경 RGB를 함께 굴절시키지 않는다. 자동 선택은 육안으로 읽히는 2~16픽셀 진폭을 요구하고, 안전할 때 4~10픽셀을 권장한다. 16개 투명 패치를 준비한 뒤 실제 합성 위상 네 개를 독립 검수하고, 게시한 모든 파일을 다시 내려받아 SHA를 확인한다. 원화·대본·자막·음성은 변경하지 않는다.

기운 패치의 시간창은 0~3,600,000ms이며 0.96초 주기를 반복한다. 실제 표시 여부는 원화 상태의 노출에 종속된다. 따라서 9초 컷도 끝까지 반복되며 정지·탐색·다른 상태로 전환할 때 웹과 AE가 같은 편집 시계를 사용한다. 기운 상태의 카메라·열기 왜곡·충격 흔들림·입 움직임은 고정한다. 장면 경계의 저장된 전환은 유지한다.

입 모션을 꺼두어도 기운 자동 준비는 독립적으로 실행한다. 최종 음성 타이밍 바인딩에서도 기운의 소스·패치 검증과 품질 결과를 유지한다.

이 준비는 기존 원화/입 준비 워커의 소유권·취소·리스·재시도·원자적 저장 경로를 사용한다. 실제 원화가 없으면 기다리고, 생성·업로드·해시 오류를 무효과 성공으로 바꾸지 않는다. 불확실한 선택·합성 검수 실패는 실제 품질 결과로 기록하고 감독된 복구 대상으로 남긴다. 기운이 실제로 없는 컷의 `absent`는 정상 결과다.

저장된 패치는 기존 웹 프리뷰와 네이티브 `wuxia_native_timeline`이 소비한다. 자동 기운이 있는 제출은 `wuxia_sword_aura/v1` 워커 계약과 실제 출력 검수를 요구한다. 로컬 검토/저장/웹 재생/실제 Adobe AE 출력은 각각 별도로 검증한다. 관리자 게시와 YouTube 업로드는 별도다.
