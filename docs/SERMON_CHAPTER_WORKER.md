# 기독교 설교: 성경 자료실 · 장별 제작

활성 웹 `/admin/codex-worker` → 이 컴퓨터의 `http://127.0.0.1:3003/#grounded`에서 실행한다.
대본은 로컬 Codex CLI로 작성한다. 영상은 로컬 웹 워커의 별도 통합 제작 큐에서 FFmpeg로 제작한다.
Windows 설치 프로그램/과거 Hermes 큐에는 작업을 넣지 않는다.

## 자료실

사용 가능한 번역본·주석의 출처와 사용 조건을 입력한다. 텍스트 자료는 40,000자 단위로
저장하며 성경은 선택적으로 책·장·시작절·끝절을 색인한다. JSON 장절 자료는 다음 형식이다.
본문은 등록된 자료 그대로 저장하고 대본 인용을 정확한 부분 문자열로 대조한다.
번역본이나 장절의 진위, 이용 허락 자체를 AI가 인증하는 기능은 아니다.

```json
{"translation":"사용하는 번역본", "permission_notes":"출처와 확인한 사용 조건",
 "verses":[{"book":"책 이름", "chapter":1, "verse":1, "text":"사용 권한이 있는 정확한 본문"}]}
```

한 요청은 최대 2,000절, UI는 20MB 이하 JSON 파일을 나눠 가져온다. 같은 내용·출처 조건은
같은 ID로 저장한다. 수정 번역/사용 조건은 별도 ID다. 번역본·책·장·절 또는 제목으로 검색한다.
설교 선택 자료는 256개까지, 각 장에 보내는 실제 원문은 최대 80,000자다. 큰 자료를 자동 절단하지 않는다.

## 대본

설교 모드 최대 360분, 기본 135분·장당 15분. 장별 목표는 5–20분으로 선택한다.
목차에는 장별 제목, 목표, 연결 문장과 성경 자료 ID를 저장한다. 작성·정확 인용 검사·원문 검토·
청취 검토·앞 장과의 연결/중복 검토를 통과한 장만 완료로 저장한다. 마지막에는 전체 구조를
요약·정확 발췌·인용과 장별 검토 증거로 점검한다. 이 마지막 검토가 전체 원문 재독을 대신한다고
표시하지 않는다. 전체 성경 원문을 모델 파라미터에 학습시키지 않는다.

`output/codex-local-console/JOB_ID/sermon/`에는 원본 요청·자료 지문을 포함한 manifest와
장별 대본/검토 결과가 저장된다. 실패/중단 작업의 재시도는 동일 작업 ID·경로에서 이어 쓴다.
요청·자료 변경 시 기존 작업을 그대로 재개하지 않는다. 완료본 체크섬이 맞지 않으면 다시 작성/검토한다.

## 통합 제작

생성 전에 기존 ElevenLabs 음성 목록의 음성 ID를 입력한다. 대본 승인 후 자동 제작한다.
키는 서버의 `global_settings.sys_api_elevenlabs[_keys]`를 우선하고 미설정 시 로컬
`ELEVENLABS_API_KEY[S]`를 사용한다. 모델은 기존 장문 음성용 `eleven_multilingual_v2`다.
성경/해설 한 장면씩 생성하여 앞뒤 음성 문맥을 전달하고 48kHz WAV로 정규화한다.

`sermon-media/media.json`이 장면별 음성·영상·장별 영상·최종 영상의 입력 지문과 파일 SHA256을
저장한다. 실제 WAV 길이로 화면 타이밍을 정하고, 인용 위치·번역본이 있는 읽기 화면을 제작한다.
장별 MP4를 만들고 순서대로 최종 `sermon-final.mp4`를 합친다. 이미지 생성 모델은 필요 없다.
임의 무음이나 반복 화면을 덧붙여 목표 길이를 채우지 않는다. 작성 분량에는 15% 여유를 주며,
실제 음성이 목표보다 짧을 경우 최대 15% 이내에서 자연스럽게 재생 속도를 낮춘다. 그래도 부족하면
분량 보완 필요로 중단한다. 목표 길이 미달을 완료라고 기록하지 않는다.

콘솔 종료 중 중단 요청은 안전한 장면 경계에서 기록하며, 강제 종료 후에는 진행 중 제작을 자동 재개한다.
키/잔여 사용량/자료 오류는 완료 파일을 보존하고 실패로 표시한다. 문제 해결 후 `통합워커 이어서 제작`을
누른다. 최종 상태는 `review_pending`: 실제 음성·성경 화면·완성 영상을 검토한다. 자동 게시/YouTube 업로드는 없다.
웹 관리자 작업 목록은 제작 상태, 완료 장 수와 실제 길이를 보여 준다. 실제 파일은 로컬 워커에서 확인/다운로드한다.

## 실행 조건

기존 Database 연결과 Codex CLI 로그인, 유효한 ElevenLabs 키·음성 ID가 필요하다.
`worker/requirements-script.txt`의 Pillow/imageio-ffmpeg를 설치한다. macOS에서는 Apple SD Gothic Neo를
사용한다. Linux는 Noto Sans CJK를 설치하거나 `SERMON_FONT_PATH`를 지정한다.

검증은 인공 성경 본문·모의 CLI·시험 음성으로 한다. 실제 두 시간 분량의 유료 생성/신학적 검토를
자동 테스트가 수행한 것으로 표시하지 않는다.
