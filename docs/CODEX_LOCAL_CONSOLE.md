# Codex 전용 로컬 대본 워커

주소: **http://127.0.0.1:3003**

실행: 프로젝트 루트에서 `powershell -File scripts/start_codex_local_console.ps1`

## 세 화면의 구분

| 주소 | 역할 |
| --- | --- |
| `127.0.0.1:3003` | 이 문서의 Codex 전용 로컬 콘솔. 독립 서버와 로컬 작업 실행기 |
| `127.0.0.1:3002` | 기존 AIR Worker 레거시 대시보드. 새 콘솔의 종속 서비스가 아님 |
| `studio.airing.work/admin/codex-worker` | 운영 DB 큐를 관리하는 웹 관리자. 로컬 콘솔 자체가 아님 |

새 콘솔은 레거시 대시보드·매니저를 시작하거나 종료하지 않는다. 실행 중인 기존 작업을 방해하지 않는다.

## YouTube 자막 가져오기

워커 Python에 `pip install "youtube-transcript-api>=1.2,<2"`를 설치하고 콘솔을 재시작한다. **자료 기반 생성 → YouTube 자막 가져오기**에 영상 URL을 입력하면 제목·출처·자막이 자료 등록 폼에 채워진다. 확인 후 저장하고 사용할 자료로 선택한다. 한국어·영어 우선이며 없으면 제공되는 다른 언어를 사용한다. 자동 생성 여부와 언어를 표시한다. 자막 없음·접근 제한·차단은 오류로 표시하며 음성 전사를 자동 실행하지 않는다. 40,000자 초과 원문은 잘라 저장하지 않고 분할 등록을 안내한다. URL 추출만으로 대본 생성이 시작되지는 않는다.

## 추출한 소재로 토픽 자동 구성

1. 자막을 추출한 뒤 자료를 로컬에 저장한다. 새 자료는 자동 선택된다.
2. 같은 화면의 **선택한 소재로 토픽 자동 구성**에서 카테고리·분량·재구성 방향을 입력한다.
3. **토픽 후보 3개 구성**을 누르면 로컬 Codex가 GPT-5.6 Sol(low 추론)로 원문 요약·분석, GPT-6 Astra로 창작 후보 생성을 순서대로 실행한다. 자막 추출은 AI를 호출하지 않는다. Codex 사용량이 발생한다.
4. 작업 이력에서 원문 요약·갈등·전환점·불확실한 부분·원문 인용과 후보 3개를 확인한다.
5. **이 토픽으로 대본 준비**를 누르면 제목·카테고리·분량·인물·갈등·반전·결말이 신규 생성 폼에 채워진다. 수정 후 대본 생성을 시작한다.

원문과 출처는 작업 시작 시 `references.json`에 고정하고, 분석과 후보는 `candidate.json`/`candidate.md`에 보관한다. 토픽 구성 작업은 `completed`로 끝나며 대본 승인 대상이 아니다. 오류 응답·없는 인용·중복 제목은 한 차례 수정 시도 후에도 유효하지 않으면 실패 처리한다. 정확한 인용 일치 검사는 의미적 정확성이나 창작 차별성을 보증하지 않으므로 후보를 읽고 선택한다. 웹의 새 영상 자동 탐색·운영 토픽 큐 게시는 실행하지 않는다.

## 언어·배경 국가·시대·스타일 연동 및 공통 설정

신규 생성과 소재 기반 토픽 구성 화면에서 4가지 설정을 연동하여 관리한다:
1. **대본 언어**: 내레이션과 대사의 언어 (한국어 `ko`, 영어 `en`, 일본어 `ja`, 스페인어 `es`)
2. **배경 국가**: 인물의 생활환경·건축·복장·소품 (기본 매핑: 한국어→한국, 영어→미국, 일본어→일본, 스페인어→스페인)
3. **시대·지역**: 장면의 구체적 배경 (기본값: `현대 지방 소도시`)
4. **이미지 스타일**: 그림 표현 방식 (기본값: `실사`)

**사용자 선택 우선 및 단계별 적용 원칙**:
- 언어 선택 시 배경 국가가 기본값으로 자동 연동되지만, 사용자가 직접 배경 국가를 변경한 경우 이후 언어를 바꾸더라도 사용자 선택을 덮어쓰지 않는다.
- 화면에서 최종 설정 요약(예: “일본어 · 일본 현대 소도시 · 실사”)을 실시간으로 확인하고 작업을 시작한다.
- 토픽 재구성부터 대본 작성, 캐릭터 설정, 장면 이미지 프롬프트, 썸네일까지 동일한 배경 국가·시대 설정을 공유한다.
- 기존의 한국 배경 강제(`Korean island setting`) 프롬프트를 제거하고 설정된 국가·시대에 맞게 건축·거리·실내·차량·소품을 공통 반영한다. 국적만으로 외모를 획일화하거나 전통의상을 강제하는 고정관념을 지양한다.
- 국가나 시대를 변경하면 캐릭터 및 이미지 캐시 지문이 달라져 이전 캐시를 재사용하지 않는다.
- 자료 기반 영상(설교·해설)은 원본의 국가·인물·역사적 사실을 보존하며 내레이션 언어만 선택된 언어로 작성한다.
- 현재 로컬 콘솔은 대본 생성 단계까지 연결되어 있으므로, 배경 설정 저장 완료 상태와 실제 이미지 생성 단계의 적용 대기 상태를 명확히 구분하여 표시한다. 기존 작업의 배경 설정은 자동 변경되지 않고 보존된다.


## 현재 연결된 기능

- [자료 기반 생성·설교](GROUNDED_SCRIPT_MODE.md): TXT/MD·붙여넣기 자료함, 번역본/장절·출처 기록, 선택 자료 스냅샷, Astra 작성·인용 검수·청취 검수, 결과의 원문/인용 대조. 원문 자체의 진위와 신학적 해석은 사용자 검토가 필요하다.

- 신규 생성 모드: 주제·카테고리·분량·추가 지시 입력. 기존 CodexStagedContentRunner의 기획, Astra 대본, 시니어 및 청취 품질 검수, 대사 판별을 실행한다.
- 신규 대본은 `script_only=True`로 실행하므로 캐릭터 이미지 생성·업로드 전에 멈춘다. 기존 전체 생성 모드의 기본 동작은 변하지 않는다.
- 리페어 목록: 공용 토픽과 사용자 프로젝트를 구분해 검색·페이지 조회한다. 목록은 자동 검수 탈락 판정이 아니다.
- 원본 읽기, 원본 스냅샷 보관, Astra 수정안 생성, 최종 청취·시니어 검수와 대사 판별, 원문/수정안 나란히 읽기.
- 정확한 수정안 해시로 승인 기록을 남긴다. 승인 직전 원본 데이터가 변경됐으면 승인하지 않는다.
- 로컬 작업 상태와 단계 표시, 실패 및 재시작 중단 기록. 재시작 시 자동 재실행하지 않는다.
- 신규 생성 프로세스와 리페어 교본 읽기.

## 아직 이 화면에서 자동 실행하지 않는 기능

YouTube 신규 영상 자동 탐색, 캐릭터/장면 이미지 실제 생성, 영상 프롬프트와 메타데이터 후속 생성, 썸네일 제작·게시, 승인 대본의 운영 프로젝트 적용, Drive 패키지 및 제출 건 동기화는 후속 연결 대상이다. 기존 제작 도구가 존재해도 이 콘솔에 연결됐다고 간주하지 않는다.

**승인 기록은 운영 적용이 아니다.** 승인 후 `approved_pending_repair` 상태로 남으며 [리페어 교본](리페어프로세스.md)의 연관 자료 검증·적용·웹 확인 절차를 수행해야 한다. 영상클립 생성은 범위 밖이다.

## 저장 및 안전 경계

- 작업별 파일은 `output/codex-local-console/<job-id>/`에 저장한다: 요청, 원본 스냅샷, 작업 상태, 수정안 JSON/Markdown.
- 새 콘솔의 DB 조회는 서버 측 읽기 전용이다. 서비스 키는 브라우저로 전달하지 않는다.
- 서버는 127.0.0.1에만 바인딩하고 정확한 Host, Origin, 교차 사이트 요청, API용 임의 세션 토큰을 검사한다. CORS를 열지 않는다.
- 로컬 PC 사용자가 접근하는 관리 도구다. 인터넷에 노출하거나 포트포워딩하지 않는다.
- 로컬에서 한 작업씩 실행한다. CLI 설치 확인과 실제 로그인·모델 실행 성공은 구분한다.
- UI 확인만을 위해 유료 생성이나 실제 대본 적용을 실행하지 않는다.
- 사용자 원문과 제목은 HTML로 삽입하지 않고 텍스트로 표시한다.
