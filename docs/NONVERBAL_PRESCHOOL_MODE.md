# 논버벌 유아 애니메이션

웹 토픽 등록과 로컬 대본 워커의 신규 생성에서 `논버벌 유아 애니메이션`을 선택한다. 내부 값은 `nonverbal_preschool`, 계획 계약은 `nonverbal_preschool/v1`이다. 1~10분, 2D 캐릭터 관절 애니메이션용이다. 입력한 줄거리를 말 없는 행동 이야기로 구성하며 언어 선택은 기획 설명에만 적용한다.

로컬 Codex CLI가 행동 이야기, 재사용 캐릭터/부품/가려진 형태/관절 겹침 이미지 프롬프트, 빈 배경 프롬프트, 장면별 초 단위 행동 연출과 관절 동작 설정을 작성한다. 생성과 독립 기획 검수는 발화 대본, TTS, 자막, AI 영상 생성 단계를 실행하지 않는다. 구조와 시간, 관절 부모 관계, 좌표, 보행 위상, 겹침 지시를 검증한다.

기획 준비 완료는 영상 완성을 뜻하지 않는다. 실제 이미지와 완성된 투명 부품 파일을 준비하고 프로젝트의 관절 편집 화면에서 원화에 맞춰 외곽선/관절 위치를 검수한다. 가려진 부위는 전체 형태를 그려 넣은 부품 PNG를 업로드한다. 부모 연결 및 보행 설정을 조정하고 AE 장면 출력의 관절 틈, 발 접지, 형태와 연출을 확인한 뒤 적용한다. 관절 편집기는 기획/대본/TTS/자막 메뉴에서도 논버벌 계획과 함께 표시된다.

최종 제출에는 모든 장면의 저장된 `region_motion` 검수 영상과 썸네일이 필요하다. TTS 파일은 요구하지 않는다. 렌더 패키지는 계획의 장면 길이와 시작 시간을 고정하고 자막 및 워커 TTS를 비활성화한다. 렌더러의 오디오 시간 기준에는 명시적 무음 WAV를 사용하여 기존 나레이션이 재생되지 않도록 한다. 배경음악/효과음은 별도 자산으로 연결해야 한다. AI 영상 프롬프트나 필수 AI 클립 수는 사용하지 않는다.

캐릭터 좌표는 생성 단계에서는 잠정값이며 실제 원화/AE 출력 검수 없이 자동 승인하지 않는다. AE 출력에는 기존 네이티브 AE 워커가 필요하다. macOS 로컬 대본 워커 업데이트는 AE가 설치된 다른 컴퓨터의 실행 소스를 갱신하는 작업을 대신하지 않는다.
