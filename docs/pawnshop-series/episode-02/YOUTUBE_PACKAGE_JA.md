## Description

結婚十五年。その日々を覚えているのは、妻だけになった。
結婚指輪を預けた先にあったのは、夫と一度も愛し合わなかった世界。

高瀬真紀、四十三歳。印刷会社で働き、帰宅後は夫・直人の食事や家の段取りを考える毎日。行ってみたい写真講座の案内には、取り消した申込日の跡が残っていました。

ある夕暮れ、路地の質屋で自分の結婚指輪を預けた真紀。店を出ると、鍵も写真も、一人で暮らす人生のものに変わっています。元の暮らしへ戻れる期限は、当日を含む三日間。けれど、見慣れた家の扉を開けた直人は、彼女を妻として迎えません。

誰かを待たず、温かいうちに食べる夕食。ためらいながら座る写真講座の椅子。夫のいない暮らしの中で、真紀は家事の負担と、自分自身が踏み出せなかった理由を見つめていきます。

夫婦でいることと、自分の時間を持つこと。その間で揺れる、大人のための不思議な物語です。

本作はオリジナルの創作フィクションです。登場人物・出来事・質屋の仕組みは架空であり、実在の事件を紹介するものではありません。
