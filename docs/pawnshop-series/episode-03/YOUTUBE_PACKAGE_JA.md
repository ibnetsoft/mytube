## Description

この作品は創作の物語です。

家賃が三万円足りない。四十二歳の倉庫作業員・三浦直人は、亡き母から受け継いだ銀色のラジカセを質屋へ預ける。持ち手には青い補修糸が残り、母の姓を記した札もついたままだった。

その夜、午後八時。スマートフォンに表示されたのは、すでに取り壊された「実家」。応答すると、懐かしい台所の音に続いて、母の声が聞こえてきた。

「帰っておいで」

声が届くのは七夜限り。こちらの問いには答えず、かけ直して続きを聞くこともできない。直人は聞こえた言葉と物音を書き留め、母の友人の予定帳や、自分が残した連絡をたどり始める。

最後まで聞かなかった留守番電話。独りだったはずだと思い込んでいた母の夜。そして、帰る日を決められなかった自分。

現代の日本を舞台に、届かなかった言葉の続きを確かめながら、今ある暮らしと人とのつながりに向き合う、不思議で静かな物語です。
