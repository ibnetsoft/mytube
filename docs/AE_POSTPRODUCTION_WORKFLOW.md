# AE 후공정 작업 지침: 1~20씬 우선 파일럿

> **보존된 이전 파일럿 지침. 현재 작업에는 적용하지 않습니다.** 현행 절차는 [CURRENT_VIDEO_PRODUCTION_WORKFLOW.md](CURRENT_VIDEO_PRODUCTION_WORKFLOW.md)를 따릅니다. 이 파일은 ComfyUI 및 8fps 모션그래픽 파일럿을 나중에 다시 선택할 수 있도록 원문을 보존합니다.

## 목적과 범위

후공정은 모든 장면에 일괄 적용하지 않는다. 대본의 극적 목적상 추가 이미지가 필요한 핵심 장면에만 제한적으로 적용한다. 우선 1~20씬의 영상 품질을 확보하고, 19·20씬 파일럿을 검토한 뒤 더 많은 장면에 확대할지 결정한다. 작업 완료 여부는 제작 파이프라인이 임의로 확정하지 않으며, 결과물은 검토 가능한 상태로 제출한다.

## 제출 전 작업

1. 13~18씬: ComfyUI가 생성한 영상 클립을 입력으로 받아 AE 후공정을 수행한다. 원본 클립과 길이를 유지하고, 장면의 연출 의도에 맞는 작업만 추가한다.
2. 19~20씬: 중요 장면용 추가 이미지 시퀀스를 사용하는 파일럿이다. 목표 생성 빈도는 8fps로 한다. 24fps 출력에서는 각 고유 이미지를 3프레임씩 사용한다. 씬 길이가 `D`초이면 필요한 고유 이미지는 `ceil(D × 8)`장이다. 7초 씬은 56장이다.
3. AE 후공정이 끝난 13~20씬 결과물은 검증 후 GCS에 업로드하고, 업로드 경로와 씬 번호를 작업 상태에 기록한다.
4. 21씬 이후는 이번 제작에서 보류한다. 이미지 생성, ComfyUI, AE, 업로드 등 후속 단계를 임의로 시작하지 않는다.

## 사용자 제출 후 작업

사용자가 제출한 뒤 1~18씬에 AE 후공정을 수행하고, 이미 제출 전 처리하여 GCS에 올린 19·20씬 결과와 결합해 1~20씬 렌더를 만든다. 제출 전 처리된 13~18씬 결과는 중복 후공정하지 않는다. 최종 조립 시 씬 순서와 오디오·영상 길이를 확인한다.

## 8fps 이미지 생성 안전 규칙

- 한 번에 한 장만 생성한다. 56장을 병렬로 요청하지 않는다.
- 각 장은 타임코드, 파일명, 프롬프트, 생성 상태를 가진 독립 프레임으로 관리한다.
- 각 성공 이미지를 즉시 디스크에 저장하고 체크포인트를 갱신한다.
- 한 프레임 생성이 실패해도 해당 장을 실패로 기록하고 다음 프레임 생성을 계속한다. 한 장의 실패로 씬이나 전체 작업을 중단하지 않는다.
- 재시작 시 기존 성공 프레임은 재사용하고 실패·누락 프레임부터 이어서 처리한다. 기존 프레임을 덮어쓰지 않는다.
- 실패 프레임이 남으면 가능한 프레임으로 AE 프로젝트와 렌더를 진행하되, 누락 타임코드를 기록하고 검토 필요 상태를 유지한다. 프레임 보간이나 정지 이미지 반복을 성공한 생성 이미지인 것처럼 표시하지 않는다.
- 장면 전반에 의미 없는 미세 움직임, 반복 루프, 임의 줌·흔들림을 넣지 않는다. 컷 전환과 동작은 대사·서사의 타이밍에 연결한다.

## 연출·검수 원칙

장면 연출 담당은 대사와 극적 목적에서 타임라인별 시선 유도와 화면 변화를 설계한다. AE 작업자는 지침에 지정된 이미지·레이어만 사용하고, 일반적인 확대 효과로 연출을 대체하지 않는다. 결과 검수는 장면의 의도, 프레임 연속성, 인물 동일성, 컷 타이밍, 실제 영상 길이·해상도·FPS, 오디오 싱크를 확인한다. 검수자는 연출 의도에 맞는지 판단하고, 자동화된 렌더 QA만으로 제작 완료라고 선언하지 않는다.

## 이번 파일럿의 결정 범위

- 이번 실행: 19씬만 8fps 추가 이미지 시퀀스로 시도한다.
- 20씬: 같은 파일럿 정책을 적용할 대상이지만, 이번 실행에서는 생성·AE 작업을 시작하지 않는다.
- 19·20씬 결과를 비교한 뒤 추가 이미지 방식의 품질과 비용을 평가하고, 적용 범위를 다시 정한다.
- 21씬 이후: 보류한다.
