대상: 토픽 #3428 / 프로젝트 `b45f00f7-fc8b-4d1a-9b72-f27c84fb0a02`. 2·3화는 이 작업에서 변경하지 않는다.

대사가 있는 원화 30개를 연락표로 검토하고 세 원화에 보수적으로 첫 적용했다. 15씬의 옆얼굴·수염 후보는 입 경계의 불확실성 때문에 제외했다. 선택하지 않은 원화가 모두 기술적으로 불가능하다는 판정은 아니다. 어떤 토픽이든 적합한 원화 0개를 허용한다.

## 보존과 실행

- 원화 PNG·상태 컷·말풍선·타이포·대본·음성·성우·기존 타이밍은 보존한다.
- 각 원화에 닫힘·반열림·열림 3개, 총 9개 투명 PNG 패치를 준비했다. 실제 원화의 입 영역 밖에는 알파 픽셀이 없으며, 합성본의 얼굴·눈·코·턱·머리 위치를 확인했다.
- 확정 음성 ID: `c8c18de1-1f3a-42b1-9be8-78855672c5d6`. SHA-256: `d227758d29c85d3faa53d767a50e235c2144a47327bda7db1ff0f3aeb9be6cd9`.
- 대사 행 `sub-2-7`, `sub-3-6`, `sub-13-1`, `sub-13-2`의 원문·성우·시각이 이 녹음의 저장 시간표와 일치하는 것을 확인했다. 녹음 파일 해시도 직접 확인했다.
- 세 포즈의 진폭 기반 큐를 만들고 선택 원화와 대사 블록이 함께 활성화된 동안에만 사용한다. 일부 구간이 다른 파생 연기 원화로 바뀌면 그 파생 원화에 패치를 재사용하지 않는다.
- 준비 도구: `scripts/prepare_wuxia_dialogue_mouth.py`. 체크포인트·원본 스냅샷·게시 패키지·원격 파일 검증·DB 적용/재조회 확인서는 `output/wuxia-mouth-episode01/`에 보존한다. 생성 원본은 기본 imagegen으로 만들고 입 패치로 정규화했으며 다른 모델 API를 호출하지 않았다.

## 검증 범위와 품질 기록

원화·포즈 합성, 선택 대사의 실제 저장 녹음 일치, 원격 파일 SHA 및 알파 영역, 편집 시계와 동결된 AE 포즈 시점을 검사한다. 실제 AE 영상 렌더를 실행한 것으로 보고하지 않는다.

기존 프로젝트의 전체 영상 제출용 대본/자막 식별 검사에서는 말줄임표 차이가 발견됐다. 이 작업에서는 선택한 대사 행이 저장된 녹음과 정확히 일치하는 것을 별도로 검증하고 원래 대본·녹음·자막을 변경하지 않는다. 전체 영상 제출 검사를 우회하거나 전체 회차의 AE 제출 준비 완료로 표시하지 않는다. 이번 적용은 선택 입모양 자산과 연출의 등록 및 웹 재생 검증이다.
