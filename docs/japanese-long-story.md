# 장편 일본 야담

대본워커의 **신규 생성 → 3시간 일본 야담 설정**에서 제목과 작성 방향을 입력한다.
180분, 일본어, 에도 시대, 일본옛날이야기 연출, 15분씩 12장으로 설정된다.
장별 목표는 15분 또는 20분으로 선택할 수 있다. 전체 목표는 61~180분이다.
일반 단편·설교·역사 다큐멘터리의 기존 제작 경로는 그대로 사용한다.

## 대본 제작과 복구

- 전체 줄거리, 결말, 고정 인물 외형, 장별 시간, 복선의 설정·회수 장을 먼저 정한다.
- 각 장은 기존 대본·씬·대사·효과음 검수와 연기 지시 제작을 거친다.
- 별도 검토가 앞 장의 인물 상태, 지식, 관계, 시간, 미회수 복선과의 연결을 확인한다.
  검토에는 현재 실제 대본 인용이 필요하며, 미회수 복선 ID가 전체 계획과 일치해야 한다.
- 검토 완료본은 `output/codex-local-console/JOB_ID/story/chapter-NNN.json`에 저장된다.
  생성한 대본은 검토 전에 draft 파일에도 저장하여, 검토 도중 중단 시 다시 검토할 수 있다.
- 중단된 작업의 결과에서 **완료한 장 보존 · 이어서 제작**을 누른다.
  동일한 작업 ID·요청·지침·앞 장 지문을 확인하고 완료한 장은 재작성하지 않는다.
  요청이나 지침이 바뀌면 기존 검토본을 조용히 재사용하지 않고 새 작업을 요구한다.
- 최종 결과는 한 개의 대본·연속된 씬 번호·전체 대사 및 연기 지시와 `story_plan`을 가진다.
  장별 패키지는 로컬 체크포인트에 두고 최종 결과에는 장 범위와 지문을 기록한다.

## 영상 제작

대본 생성은 음성·영상 제출이나 자동 게시가 아니다. 기존 웹 제작 경로에서 원본 이미지,
화자와 음성을 준비하고 제출하면 통합워커가 처리한다. 기존 음성 조각의 재사용 경로를 유지한다.

60분을 넘는 일반 FFmpeg 영상과 Motion Studio 영상은 비주얼 렌더를 약 15분 단위로 저장한다.
씬 경계에서 나누며 크로스페이드를 자르지 않으므로 한 구간이 더 길어질 수 있다.
완료한 구간은 입력 이미지·설정·파일 SHA-256 및 실제 재생 길이를 검증하여 재사용한다.
자막·내레이션·음악·효과음은 결합한 전체 타임라인에 한 번 적용하므로 장마다 초기화되지 않는다.
인트로를 포함한 기존 호환 렌더 경로 등 다른 렌더러에는 이 비주얼 체크포인트를 강제로 적용하지 않는다.

180분은 대본과 씬의 목표 길이다. 실제 음성·최종 영상의 3시간 재생 길이는 제작 후 검증해야 한다.
3시간 전체 제작에는 로컬 영상 체크포인트와 최종 파일을 저장할 충분한 여유 공간이 필요하다.

## 검증

`python -m pytest tests/test_story_chapters.py tests/test_chapter_visual_cache.py tests/test_ffmpeg_slideshow_service.py -q`

테스트는 3장 제작 도중 중단·재개, 요청 변경 거부, 검토 실패, 전역 씬·연기 지시 번호,
180분 합계, 같은 작업 ID 재시도, 실제 짧은 MP4의 구간 재사용·변경 감지·최종 결합,
전체 음성·자막·음악·효과음 타임라인 보존을 확인한다. 전체 3시간 본편은 자동 테스트에서 생성하지 않는다.
