# 일본사건 · 현대 애니메이션

운영 카테고리 `일본사건`(ID 15), 대본 스타일 `japanese_domestic_drama`를 사용한다. 내부 이미지 스타일 키 `jp_domestic_watercolor`는 기존 토픽 호환을 위해 유지하지만 현재 프롬프트는 첨부 레퍼런스의 따뜻한 현대 애니메이션이다. 세밀한 갈색 선, 자연스러운 애니메이션 얼굴, 머리카락/옷감의 명암, 가을빛, 현실적인 일본 거리의 심도 표현을 적용한다. 유저웹 스타일 카드에는 얼굴이 보이는 사용자 제공 이미지를 그대로 사용한다.

36컷 및 13~15분 제한은 제거했다. 한국 YouTube URL을 등록하면 서버가 영상 메타데이터의 실제 초 단위 재생시간을 확인하고 저장한다. 워커는 이 길이를 수동 분량보다 우선한다. 자막 마지막 시각으로 추정하거나 메타데이터 실패 시 15분으로 대체하지 않는다. URL 없이 만드는 창작 기획은 사용자가 선택한 길이를 사용한다. 현재 제작 엔진의 지원 범위는 1~60분이며 범위를 벗어나면 명시적으로 오류를 반환한다.

실제 원문 자막/전사를 분석한 뒤 한국 이름, 지명, 회사/브랜드, 가족 호칭, 주거/전세, 금액, 기관/법률·사회 관습의 일본 대응표를 작성한다. 이 대응표와 원본 URL/길이는 대본·장면 기획에 전달하고 저장한다. 한국 문장을 그대로 번역하는 대신 사건의 인과와 감정선을 일본 현대 생활에 맞춰 각색한다. 내용을 확인할 수 없으면 출처를 읽었다고 주장하지 않는다. 자막 및 이미지 안의 문구는 참고 데이터로 취급한다.

일본 옛날이야기와 같은 가변 장면 배분 정책을 사용한다. 초반 최대 18씬은 영상(기본 5초), 이후는 이미지다. `video_prompt`, `video_keyframe_plan`, `transition_to_next`, `scene_direction_plan/v1`, 대사 판별 및 AE 연출 데이터는 기존 통합워커 형식을 유지한다. 전체 씬 수는 원본 길이에 따라 달라지고 씬별 시간 합은 원본 초 수와 일치한다. URL 영상이 짧아 18씬 미만이면 실제 씬 수만 영상으로 배분한다.

유동적인 사건 각색이며 불륜이나 동일한 결말을 강제하지 않는다. 픽션 고지는 짧은 첫 씬 시간 예산에 맞는 일본어 문구를 사용하고 설명란에도 표시한다. 확정 자막은 별도 편집 데이터로 처리하며 생성 이미지에 일본어를 굽지 않는다. 음악은 사건의 긴장/반전/결말에 맞게 작성한다. 원본·음성·원화·렌더 검수는 기존 승인 흐름을 따른다.
