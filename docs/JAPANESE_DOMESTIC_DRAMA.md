# 일본사건 · 수라장/스캇토

운영 카테고리 `일본사건`(ID 15)의 기본 대본 스타일은 `japanese_domestic_drama`, 이미지 스타일은 `jp_domestic_watercolor`, 언어는 일본어, 타깃 국가는 일본이다. 기존 다큐멘터리와 같은 담당자를 사용한다. 카테고리 선택 또는 웹 이미지 스타일 선택으로 15분/일본어/현대 일본 배경을 적용한다. 로컬 대본 워커 신규 생성에도 같은 프리셋이 있다.

13~15분, 기본 36개 정지 장면을 사용하며 필수 영상 클립은 0개다. 발단(미묘한 위화감), 갈등(배신과 부당한 편들기), 반격 준비(정당한 증거 보존과 상담), 결정적 대면, 주인공의 새 생활로 구성한다. 한국 원자료는 이름·주소만 치환하지 않고 인물 식별 조합과 사건 전개까지 새로 각색한다. 일본식 임대/대출/생활 배경과 자연스러운 일본어를 사용한다.

실제 상담이나 투고 출처가 입증되지 않은 창작물은 실화라고 표시하지 않는다. 대본 첫머리와 설명란에 일본어 픽션 고지를 넣으며, 실제 발화 대본에서 빠지면 패키지를 거부한다. 특정 위자료·재판 결과·직장 강등을 보장하지 않는다. 살인/중상해/노골적 성 묘사와 불법 정보 수집·신상 공개·집단 보복을 배제한다. 조회수/RPM/수익화 성과는 보장하지 않는다.

차분한 현대 수채화와 깨끗한 만화 선화를 공통 이미지 프롬프트에 고정한다. UI의 스타일 미리보기는 기존 만화풍 샘플을 사용한다. 일본어 글자를 이미지에 생성하지 않고 확정 자막의 편집 가능한 하단 자막 또는 선택 말풍선으로 처리한다. 이 스타일에는 기본 입 모양 AE 작업을 강제하지 않는다. 음악 프롬프트는 긴장감 있는 피아노 → 정당한 반전의 따뜻한 현악기 → 조용한 새 출발이며 실제 음악 파일은 별도 제작이다.

프로필은 `auth-web/lib/japaneseDomesticDramaStyle.json`, 워커 계약은 `worker/japanese_domestic_drama.py`에 있다. 원본/출처 및 실제 원화·음성·최종 렌더 검수는 기존 승인 과정에서 수행한다.
