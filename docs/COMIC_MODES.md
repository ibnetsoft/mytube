# 만화책 / 무빙툰 모드 (가로형 v1)

## 사용 방법

STD 프로젝트를 열고 상단 **제작 모드**에서 **만화책 · 이미지** 또는 **무빙툰 · 영상 + 이미지**를 선택한 뒤 **모드·배치 저장**을 누른다. 기존 프로젝트의 기본값은 **기존 영상**이다.

**페이지 편집·미리보기**에서:

- 좌우 2컷, 전체 1컷, 4컷, 큰 컷 + 인셋 중 배치를 선택한다. 기존 씬 순서대로 페이지를 자동 구성하며 마지막 홀수 컷도 보존한다.
- 각 컷에 전체 보이기 / 꽉 채우기, 말풍선 위 / 아래 위치를 지정한다.
- 모드를 저장한 뒤 컷별 이미지·영상을 교체할 수 있다. 만화책 모드는 이미지 우선이며 영상만 있으면 첫 프레임을 사용한다. 무빙툰은 영상 우선이며 이미지도 혼합 가능하다.
- 기존 자막 편집에서 대사와 TTS 시간을 수정한다. 컷의 말풍선들은 등장 시점부터 페이지가 넘어갈 때까지 누적된다. 말풍선이 너무 많으면 명시적으로 오류를 표시한다. 글을 조용히 잘라내지 않는다.
- 페이지 재생으로 순차 재생과 말풍선을 확인한다. 먼저 재생한 영상은 끝 프레임에 정지하고 다음 컷이 재생된다. 영상 원음은 사용하지 않고 기존 TTS/BGM/SFX를 합성한다.
- **현재 페이지 PNG**는 모든 말풍선을 포함한 1280×720 이미지를 내려받는다. 영상 컷은 미리보기의 현재 프레임을 사용한다. PNG는 TTS 파일 없이도 출력 가능하다.
- MP4는 설정 저장 후 기존 제출·렌더링 경로를 사용한다. 따라서 기존 제출 단계의 TTS·썸네일 등 완료 요건은 그대로 적용된다.

## 출력과 범위

- 가로 16:9, 기존 720p/1080p 렌더 크기, 24fps MP4.
- 종이 뒷면·곡면·그림자가 있는 스타일화된 페이지 말림 전환. 물리적인 양면 책의 모든 면을 모델링한 3D 시뮬레이션은 아니다.
- 전환 구간 0.3~1.5초를 페이지 사이에 추가하고, 다음 페이지의 TTS/SFX 시작도 같은 시간만큼 이동한다. 대사는 전환에 잘리지 않는다. BGM은 전체 결과 길이에 맞춰 재생한다.
- 넘김 효과음은 외부 파일에 의존하지 않는 합성 효과음이다.
- 웹 미리보기는 페이지 내부의 재생/말풍선 확인용이다. 페이지 말림 및 넘김 효과음은 최종 MP4에서 확인한다.
- 워커 출력 폴더에 `comic_pages/page_NNN.png`, `comic_manifest.json`, `output.mp4`를 생성한다. 기존 배포 경로는 MP4를 전달하며 페이지 PNG의 사용자 다운로드는 웹 편집기에서 제공한다.
- 세로 웹툰, PDF/전체 페이지 ZIP 다운로드, 자유 곡선 패널, 드래그 편집, 말풍선별 자유 위치, Ken Burns/말풍선 바운스, 페이지별 서로 다른 레이아웃은 이번 범위에 포함하지 않는다.
- 새 모드에서는 일반 영상용 전환·이미지 모션·템플릿 오버레이 대신 만화책 합성 설정을 사용한다. 해당 기존 설정은 지우지 않아 모드를 되돌리면 다시 사용할 수 있다.

## 호환성과 배포

설정은 기존 `project_payload.render_settings.comic`에 version 1 객체로 보관한다. 별도 DB migration은 없다. 버전/모드가 명시적으로 일치할 때만 새 렌더러를 호출한다. 일반 모드의 기존 합성·미디어 우선순위·초반 12씬 영상 필수 규칙을 유지한다. 업로드 예외는 소유자 확인 후 **저장된 프로젝트 모드**를 기준으로 적용하며 요청 본문의 임의 모드 플래그는 신뢰하지 않는다.

웹 코드와 **렌더 워커를 함께 업데이트해야 한다**. 구버전 워커는 새 모드를 해석하지 못하므로 웹만 먼저 운영 배포하면 안 된다. 이번 작업은 로컬 구현/검증이며 운영 배포, 운영 데이터 수정, Windows 실행파일 재빌드는 수행하지 않았다. 워커 패키징은 기존 services 및 MoviePy 모듈 수집과 번들 폰트(NanumSquareExtraBold)를 사용한다.

## 검증

- `python -m pytest tests/test_comic_render.py -q`: opt-in 분기, 공유 레이아웃, 홀수 페이지, 전환 경계, 말풍선 유지, 영상 정지/재생, 실제 MP4/PNG, 음성 이동·전환 공백, BGM/SFX 합성.
- `cd auth-web && node tests/std-comic.cjs && node tests/std-comic-upload.cjs`: 기존/신규 모드 정책, 미디어 우선순위, 페이지 묶기, 타이밍, 프로젝트 완료 판정, 업로드 소유자/편집 상태 검사.
- 새 TS 파일 ESLint 통과. 전체 TypeScript 검사에는 기존 오류가 있어 HEAD 별도 사본과 비교하며 추가 오류 여부를 검증했다.
- 브라우저의 분리된 임시 QA 화면에서 편집 창 열기, 무빙툰 재생, 말풍선 유지, 인셋/4컷 전환, 설정 저장, 실제 PNG 다운로드를 확인했다. 운영 계정의 업로드/큐 제출은 실행하지 않았다.
- 기존 씬 모션 및 렌더 버전 동작 테스트 통과. 과거 Supabase/Drive 저장 경로를 전제로 하는 일부 Python 소스 검사들은 현재 HEAD에서도 실패하므로 별도 기준 비교로 확인했다.
