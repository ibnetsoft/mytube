# 웹 어드민 메뉴 현황

확인일: 2026-10-02 (한국 시간). 대상: `auth-web`, 운영 `/dashboard`와 별도 `/admin/*` 페이지.

화면 코드 → 호출 API → 운영 Supabase 데이터 및 현재 로컬 워커 경로를 대조했다. 운영 대시보드는 HTTP 200이며 관리자 API는 무인증 요청을 403으로 차단한다. 이번 조사는 읽기 전용이다. 관리자 로그인 후 생성·저장·승인·결제·출금 버튼을 실제 실행한 전체 동작 검증은 아니다. 아래의 '유지'는 현재 기능에 필요한 연결이 존재한다는 뜻이며 모든 동작의 정상 판정과 같지 않다. 데이터가 0건인 메뉴도 고장이나 영구 미사용으로 단정하지 않는다.

## 현재 방식과 맞지 않거나 연결이 끊긴 부분

1. **별도 `/admin/codex-worker` 페이지**는 `script_worker_jobs`가 아니라 `remote_hermes_queue`의 `codex_content_generate`, `script_plan_generate`를 조회·등록한다. 운영 DB의 해당 이전 큐에는 현재 진행 중인 작업이 없고, 대본 생성 관련 최신 등록은 9월 5일이다. 현재 3003 작업 상태를 확인하는 화면으로 사용할 수 없다.
2. **학습 통계의 새 지침 누락:** `script_guideline_versions`, `script_guideline_outcomes`를 조회하지 않는다. 새 지침 관리와 적용 결과는 현재 3003의 **대본 지침 개선**에 있다. 적용 결과는 3건이며 지침 개선안은 현재 0건이다.
3. **YouTube 성과 학습:** API에서 사용하는 `youtube_video_metrics`, `video_learning_snapshots` 테이블이 운영 DB에 없다. 기존 이벤트 통계는 표시할 수 있지만 성과 학습 부분을 정상 가동이라고 판단하면 안 된다.
4. **로컬 8001 연결:** 주제 관리의 채널 목록·채널 로그인과 학습 통계 보조 조회가 8001을 사용한다. 조사 시 이 컴퓨터에서 8001 서버는 실행 중이지 않았다. 현재 3003 대본워커를 사용하는 흐름과 일치하지 않는다.
5. **숨겨진 스타일 세팅:** 메인 메뉴 배열에서는 빠져 있지만 화면 분기와 3002 바로가기 코드는 남아 있다. 실제 프리셋 API가 있다고 이 안내 화면을 현재 스타일 관리 화면으로 간주하면 안 된다.
6. **GCS 안내 문구:** 관리자 화면은 여전히 '1차 Supabase, 2차 GCS'라고 설명한다. 현재 자막 음성은 GCS 1차 저장·우선 재생으로 변경됐으므로 자막 음성에 대해서는 설명이 낡았다. 다른 파일 종류까지 모두 GCS 1차라고 확대해서 바꾸지 않도록 주의한다.
7. **API 모델 설정:** '대본 생성 모델'은 Auto-Pilot API 모델 설정이다. 현재 로컬 Codex 작성·자막 검토 번역 모델을 바꾸는 설정이 아니다. 일반 번역은 공지·토픽 번역 등에 사용될 수 있으므로 일반 번역 설정 전체를 삭제하는 것은 별도 판단이 필요하다.
8. **회원별 로그:** `DashboardContent.tsx`가 `/api/admin/users/{id}/logs`를 호출하지만 현재 저장소에는 대응하는 전용 route 파일이 없다. 로그인 상태에서 정상 응답 여부와 의도한 로그 API를 확인해 수정해야 한다.
9. **별도 정산 페이지 `/admin/settlements`:** 화면의 조회·지급 fetch가 Authorization 헤더를 보내지 않지만 API는 Bearer 토큰을 요구한다. 현재 코드로는 로그인 세션만 있어도 자동으로 API 인증되지 않는다. 기능을 정상이라고 판정할 수 없다.

## 권장 메뉴 구성

- 제작 운영: **토픽·카테고리 / 주제대기열 / 렌더 큐 / 대본워커 상태 / 지침 개선 / 음악**.
- 사용자 운영: **유저 / 구독 인증 / 문의 / 공지**.
- 설정·모니터링: **GCS·TTS·YouTube 설정 / 에러 로그 / 현황 요약**.
- 사업 운영: **출금 / 추천인 / 테넌트**. 실제 사업 운영에서 필요 여부를 확인한 후 노출을 결정한다.
- 이전 기록: **기존 학습 통계 / 이전 Hermes 작업 이력**. 현재 제작 실행 버튼과 분리하여 읽기용으로 보관한다.

이번에는 메뉴나 데이터를 삭제하지 않았다. 먼저 현재 워커 상태·지침 연결과 깨진 링크를 정비한 뒤, 이전 실행 버튼과 8001·3002 안내를 정리하는 것이 순서다.
