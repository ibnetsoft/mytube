# 무협 웹툰 씬 전환

## 컷 리듬과 선택적 전환 효과 (2026-11-07 사용자 요청)

- 참고: https://youtube.com/shorts/QFmbaTSbZj8 — 사용자가 제공한 이미지·전환·구간 분석을 연출 참고로 삼는다. 이 문서의 시간 범위는 무협 제작용 시작 가이드이며 참고 영상의 프레임 실측 결과가 아니다. 쇼츠 전체의 속도를 장편에 강제하지 않되 정지 원화를 오래 유지하는 대신 행동·반응·결과가 연결되는 편집으로 속도감과 타격감을 만든다.
- **씬 길이와 화면 컷 체류 시간을 구분한다.** 하나의 음성 씬 안에서도 필요한 상태 원화·반응 컷·소품 디테일을 전환할 수 있다. 액션 연결 컷은 약 0.5~1.5초, 일반 진행 컷은 약 2~4초를 출발점으로 삼고, 대사·감정·새 정보는 실제 발화와 읽는 시간만큼 확보한다. 수치는 할당량이나 강제 상한이 아니다. 동일 원화의 무의미한 크롭 반복으로 컷 수를 채우지 않는다.
- 기본 전환은 명확한 **하드 컷**이다. 시선·행동 방향이 이어지는 상태 컷을 연결하고, 중요한 공격은 준비/이동 → 접촉 → 상대 반응/결과로 짧게 묶는다. 접촉 직전과 직후의 길이를 달리해 강약을 만들며 모든 컷을 같은 길이·같은 박자로 자르지 않는다. 음악 비트보다 사건·발화·접촉 시점을 우선한다.
- 강조가 필요한 순간만 짧은 펀치 인 또는 방향성 있는 빠른 팬·슬라이드를 선택한다. 카메라 이동 창은 약 0.15~0.35초를 검토 출발점으로 삼고 전후 정지를 둔다. 이는 기존의 느린 줌·장면 전체 완만한 확대 금지를 바꾸지 않는다. 원화 바깥 노출, 얼굴·손·소품 잘림, 말풍선 가림을 실제 이동 범위 전체에서 확인한다.
- 접촉 섬광은 국소적인 짧은 표현을 우선하고 기존 충격 계약의 지속시간·지연·보호 영역을 따른다. 전환용 화면 플래시는 큰 사건 전환에만 드물게 검토하며 반복 점멸을 기본으로 삼지 않는다. 흔들림은 실제 충격 이후에만 사용한다. 교차 편집은 실제로 병행되는 사건·반응에, 팝업은 기존 빈도·가독 시간 계약에 맞는 디테일 강조에 사용한다. 페이드는 시간 경과·여운·종결처럼 의미가 있을 때 선택한다.
- 컷별로 원화/상태 ID, 표시 시작·종료, 전환 이유·종류·이동 창, 동작/접촉/음성 앵커와 효과 시각을 기록한다. 필요한 상태 원화와 분리 자산을 제작 지시에 포함한다. 대본워커는 이 계획과 지시를 준비하며 실제 영상 생성·합성 완료로 보고하지 않는다.
- 미리보기와 실제 출력에서는 액션이 읽히는지, 대사 도중 글자가 사라지지 않는지, 접촉보다 효과가 먼저 나오지 않는지, 긴 정지와 과도한 전환이 반복되지 않는지 확인한다. 지원되지 않는 효과는 이름만 저장해 적용됐다고 하지 않는다. 웹·통합워커의 동일 시간표 적용과 실제 렌더 검증은 각각 증거를 남긴다. 기존 확정 회차는 일괄 재작성하지 않는다.


### 실제 씬 전환 저장과 실행

- 무협 전환은 기존 유저웹의 씬 선택 → 효과 → 화면 전환에서 저장한다. 새 패키지 제작 지시도 해당 씬의 `transition_effect`에 같은 ID를 기록한다: `none` 하드 컷, `wipe_left/right/up/down` 방향 슬라이드, `flash` 짧은 화이트 플래시, `punch` 펀치 줌, `snap_shake` 스냅 흔들림, `dissolve` 디졸브, `fade_out` 끝 페이드. 기존 `push`/`zoom`/`brighten`/`darken`은 각각 왼쪽 슬라이드/펀치/플래시/끝 페이드로 해석한다. 교차 편집은 별도 합성 효과가 아니라 인과가 있는 컷 순서로 계획한다.
- 시작 전환 기본 창은 0.24초, 플래시는 0.125초, 디졸브·끝 페이드는 0.32초이며 짧은 씬은 길이의 절반으로 제한한다. 펀치는 최대 106%에서 짧게 안정하고 유지 구간에 느린 확대를 추가하지 않는다. 스냅 흔들림은 의미 있는 충격/강한 진입에만 선택한다. 사건 의미를 확인해 컷별로 선택하며 반복 순환·전 씬 일괄 적용하지 않는다.
- 슬라이드·디졸브의 뒤 화면은 직전 씬 마지막 상태의 SHA가 확인된 **정지 원화**다. 직전 입모양·말풍선·보조 루프를 이어 재생하는 효과로 보고하지 않는다. 현재 씬의 원화·입 패치·말풍선·타이포는 같은 전환을 적용받는다. 씬 구간 내부에서 처리하므로 녹음 시간·전체 길이는 늘리지 않는다.
- 웹 미리보기의 프레임 값을 `wuxia_native_timeline/v4`로 동결해 AE 통합워커에 전달한다. 구형 워커는 v4를 조용히 생략할 수 없고 업데이트가 필요하다. 효과 없는 기존 씬은 종전 계약을 유지한다. 실제 회차 적용 전후 원화·얼굴·글자 가독성과 실제 출력은 별도 검수하고, 기존 확정 회차를 일괄 변경하지 않는다.

## 씬 시작 이미지 이동·줌·열기 왜곡 (2026-11-07)

- 유저웹의 **이미지 모션**에서 이동 방향(좌→우/우→좌/아래→위/위→아래)과 줌(없음/줌인/줌아웃)을 각각 선택해 조합한다. 열기 왜곡도 별도로 켜거나 끈다. 무협은 1~12씬도 선택할 수 있으며 원본 영상의 움직임은 보존한다. 기존 회차에 자동 일괄 적용하지 않는다.
- 씬 시작부터 기본 0.9초 동안 이동·줌한 후 마지막 구도를 유지한다. 속도 설정 0.5~3배를 반영하되 이동 창은 최대 1.2초이며 씬 종료를 넘지 않는다. 느린 전체 씬 줌으로 바꾸지 않는다. 상태 원화·입·보조 패치·편집 글자는 같은 카메라를 따른다. 실제 원화와 이동 범위 전체에서 얼굴·손·말풍선의 크롭과 가독성을 검수한다.
- `image_effect`는 `none`, `zoom_in/out`, `pan_left/right/up/down` 또는 `pan_right_zoom_in` 같은 이동+줌 조합이다. `+heat` 접미사로 열기 왜곡을 독립 선택한다(예: `none+heat`, `pan_up_zoom_out+heat`). `motion_speed`는 별도 저장한다. 기존 씬 효과 저장 API를 사용하고 음성·씬 길이를 변경하지 않는다.
- 열기 왜곡은 불길·고온 장면에만 근거를 두고 선택한다. 화면을 통째로 흔드는 대신 48개 높이 구간을 서로 다른 위상으로 수평 굴절시킨다. 최대 변위는 1920 기준 ±5px이며 시작·종료에 짧은 강도 완화를 둔다. 말풍선·글자는 굴절하지 않는다. 실제 원화의 `face_exclusion_boxes` 검토가 필요하고, 제공된 손·추가 보호 사각형도 포함해 보호 구간은 움직이지 않는다. 원화 검토가 누락된 것을 얼굴 없음으로 처리하지 않는다.
- 웹이 계산한 카메라와 굴절 프레임을 `wuxia_native_timeline/v5`로 동결한다. AE는 같은 원화/입/보조 패치 합성을 구간별 마스크로 복제해 동일 변위를 적용하고, 글자는 그 위에 유지한다. 카메라와 씬 전환을 함께 적용해도 자식 레이어의 실제 불투명도에 페이드를 반영한다. v5 지원 워커 확인을 요구하며 구형 워커가 효과를 조용히 생략하지 못하게 한다. 브라우저 픽셀 검증·동결 입력 검증·실제 AE 출력 검증은 구분한다.

## 앞으로 만드는 무협의 자동 선택·실제 AE 검수 (2026-11-07 사용자 확정)

- 새 무협 웹툰 대본의 로컬 Codex 워커는 모든 씬의 `visual_action`·이미지 지시·인접 사건을 읽고 이동 방향, 줌 방향, 열기 왜곡을 장면별로 선택한다. 고정 화면도 정상 선택이며 효과 수량이나 순환 패턴을 강제하지 않는다. 명시된 수동 선택과 기존 회차는 보존한다. 새 대본 시작 확인 절차는 유지하며 이 설정 변경이 새 회차 시작은 아니다.
- `wuxia_motion_auto/v1` 정책과 `wuxia_motion_selection`의 선택 이유·같은 컷의 정확한 시각 지시 인용·열기 근거를 저장한다. 저장된 `image_effect`가 웹 미리보기와 AE 동결 입력에 사용된다. 불길·고온의 실제 묘사 없이 대사·비유·상상만으로 열기를 선택하지 않는다. 기획 시각 정보로 고른 상태는 실제 원화 검수로 보고하지 않는다.
- 원화 제작·패키지 준비에서는 실제 원화 SHA와 얼굴·손·글자 보호 좌표를 검토한다. 자동 제작의 AE 워커도 다운로드한 실제 상태 PNG를 직접 열어 장면 적합성·열기 근거·카메라 전체 크롭 범위를 검수한다. 검수 실패·불명확·도구 오류는 사실대로 품질 기록에 남기고, 기존 원화·음성 및 재사용 가능한 산출물을 보존한다.
- 실제 AE 출력 검수는 별도 필수 단계다. 이동 시작·이동 중·이동 종료·정지 유지, 서로 다른 열기 위상의 실제 디코딩 프레임과 해당 상태 원화를 함께 검사한다. 방향·줌 조합·공간별 굴절·얼굴/손/글자 보호·입 패치 정렬을 각각 판정한다. 렌더 성공·저장 메타데이터·웹 예시만으로 통과시키지 않는다. 검사한 구간과 품질 우려를 실제 출력 SHA에 연결하고 샘플 검수를 전 프레임 검수로 표현하지 않는다.
- 자동 정책은 별도 `wuxia_motion_auto/v1` 워커 확인을 요구한다. 검수 기능이 없는 구형 워커의 조용한 생략과 검수 기록 없는 캐시 재사용을 막는다. 품질 우려는 제작을 중단시키지 않고 별도 기록하면서 최종 조립까지 진행하며, 파일·소유권·취소·무결성·실제 타이밍 검사는 유지한다. 관리자 게시·YouTube 업로드는 별도다.
