# 대본 전용 워커 관리 화면

주소: http://127.0.0.1:3003/ (2026-09-22 Supabase 연결)

프로젝트 루트에서 `venv\Scripts\python.exe -X utf8 -m worker.codex_local_console`로 실행한다.
기존 3002 대시보드나 렌더 매니저를 실행할 필요가 없다.

## 저장과 조회

- `script_worker_jobs`: 신규/리페어/자료 기반/토픽 구성 작업의 요청, 진행 상태, 결과 전체,
  원본 스냅샷, 선택한 참고자료, 정확한 결과 해시, 승인 기록을 저장한다.
- `script_worker_history`: 전용 작업과 기존 `remote_hermes_queue`의 대본·기획·메타데이터·효과음
  이력을 담는 뷰다. 관리 화면은 대본 관련 유형만 조회하며 효과음·메타데이터 단독 작업은 목록과 집계에서 제외한다. 제목 검색, 출처/상태 필터, 40건 단위 페이지 이동을 지원한다.
- 대본 보관함은 `topics_queue`와 `std_projects`의 현재 대본을 조회한다.
- 기존 작업에 결과 스냅샷이 없으면 연결된 현재 대본을 조회하고, 과거 작업 결과와 다르다는
  안내를 표시한다. 둘 다 없으면 결과 없음을 표시한다.
- `output/codex-local-console/<job-id>/`는 로컬 복구본이다. 폴더가 없어도 작업 ID로
  Supabase의 요청·대본·참고자료·승인 기록을 다시 불러올 수 있다.
- 참고자료 **등록함**은 로컬이다. 작업에 실제로 선택한 참고자료는 해당 작업과 함께
  Supabase에 고정 보관되므로 그 작업의 결과 검토·재실행에는 로컬 등록함이 필요 없다.

## 실행과 장애 복구

작업 이력의 제목 앞에는 저장된 썸네일을 표시한다. 토픽에 썸네일이 없고 연결 프로젝트에
저장본이 있으면 최신 프로젝트부터 찾아 `연결 프로젝트`로 구분해 표시한다. 배경만 있는
경우에는 `썸네일 배경`이라고 표시하며, 장면 이미지를 썸네일로 대신 사용하지 않는다.
캐릭터와 장면 이미지 배지는 실제 저장된 HTTPS 이미지 링크 수/대상 수를 표시한다.
캐릭터 설정·이미지 프롬프트만 존재하는 경우는 생성 완료로 보지 않는다.
기존 이력의 배지는 현재 토픽/프로젝트 자료 기준, 전용 작업의 배지는 그 작업 결과 기준이다.
조회 실패는 미생성이 아닌 미확인으로 표시한다. 링크의 개수는 이미지 내용 검수 결과가 아니다.

작업을 시작하기 전에 Supabase 저장이 성공해야 한다. DB의 활성 작업 유일 인덱스로
여러 전용 콘솔의 중복 동시 실행을 차단한다. 모델 실행은 기존 전용 Codex 워크플로를 사용한다.
기존 렌더/대본 통합 워커 큐를 새로 등록하거나 소비하지 않는다.

실행 중 DB 연결이 끊기면 결과를 로컬에 남기고 `Supabase 저장 대기`로 표시한다.
작업 결과의 **Supabase 재동기화** 버튼으로 업로드를 다시 시도한다. 서버 재시작 시에도
미동기화 기록을 업로드하며, 완성된 로컬 결과는 중단 상태로 바꾸지 않는다.
이 PC에서 실행 중이던 미완료 작업은 재시작 시 중단 처리하고 자동 재실행하지 않는다.
다른 PC에서 실행 중인 작업에는 이 복구 처리를 적용하지 않는다.

실패/중단 작업의 **같은 요청으로 재실행**은 새 작업 ID를 만들고 `retry_of`로 원본 실패 기록에
연결한다. 리페어는 원본 변경 여부를 다시 확인한다. 변경됐다면 보관함에서 새 작업을 만든다.

대본 승인은 정확한 후보 해시와 승인 시각을 저장한다. 기존 토픽/프로젝트 대본을 교체하거나
이미지·자막을 게시하는 단계는 `리페어프로세스.md`의 연관 자료 검증을 거쳐 별도로 수행한다.

## 접근 권한

Supabase service-role 키는 Python 서버에서만 사용한다. 새 테이블은 RLS를 켜고
`anon`/`authenticated`의 접근 권한을 철회했다. 서버 역할만 SELECT/INSERT/UPDATE가 가능하다.
통합 조회 뷰는 `security_invoker`이며 같은 서버 전용 권한을 적용했다.
RLS 정책 없음에 대한 Advisor INFO는 공개 클라이언트 접근을 허용하지 않는 이 설계에서 의도된 상태다.

스키마 파일: `supabase/migrations/20260922052125_script_worker_console_storage.sql`.
파일 버전은 원격 DB에 적용된 migration history 버전과 맞췄다.

## 검증

- 콘솔·저장소·언어·자료 기반·토픽 구성 관련 Python 테스트 75개 통과.
- 실제 API: 전체 이력 62건, 실패 필터 36건, 40/22건 페이지 이동, 사용자 프로젝트 12건 조회.
- 기존 완료 작업 대본 스냅샷 5,076자 조회 확인.
- 임시 데이터로 Supabase 저장/동일 ID 재저장/재조회 일치 확인 후 검증용 행 제거.
- 브라우저 연결 도구 오류로 시각 검증은 수행하지 못함. 생성 모델 호출은 검증에서 실행하지 않음.
