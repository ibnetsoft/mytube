# 공개·진행 중 토픽 재검수

## 대상과 보호 범위

`scripts/audit_active_content.py`는 공개/배정 후보와 진행 중 프로젝트를 조회하여 최초 스냅샷을 보관한다. 제출·검수대기·승인·완료 작품은 수정하지 않는다. 완료 작품과 원본을 공유하는 주제도 보호한다. 유저 편집본은 원본으로 되돌리지 않고 별도 검수한다.

## 검수 항목

- 카테고리별 구술 문체, 인물 소개와 관계, 시간 순서, 소품 이동, 인과관계.
- 제목의 약속과 결말, 복선 회수, 반복 설명·반복 결말·분량 채우기 방지.
- 각 장면의 내레이션, 감정, 이미지/영상 프롬프트, 캐릭터 DNA 일치.
- 첫 12씬 영상 프롬프트는 하나의 5초 동작과 하나의 카메라 움직임.
- 설명·태그·썸네일 문구의 정확성, 창작과 실제 증언 구분, 금융 정보의 출처.
- 대본 독립 검수와 전체 제작 재료 독립 검수를 모두 통과한 수정안만 저장.

기존 이미지의 실제 픽셀을 확인하지 않은 경우 이미지 검수 완료라고 표시하지 않는다. 새로 작성한 캐릭터 설명 역시 참조 이미지가 생성되었다는 뜻이 아니다.

## 실행

최초 조사: `python scripts/audit_active_content.py`

수정안만 생성: `python scripts/repair_active_materials.py --ids 3370`

통과한 수정안 반영: `python scripts/repair_active_materials.py --ids 3370 --publish`

전체 스냅샷 대상 순차 처리: `python scripts/repair_active_materials.py --publish`

원본 스냅샷, 후보, 건별 결과, 저장 전 백업과 저장 이력은 `output/active_content_review_20260910/`에 있다. 이 디렉터리는 사용자 데이터이므로 Git에 포함하지 않는다. 완료된 건은 다음 실행에서 건너뛴다. 보류 사유는 `run_results.json`에 기록한다. 영상 길이 등 사용자 결정이 필요한 건은 `pending_decisions.json`으로 차단한다.

## 저장과 복구 주의

기존 이미지·영상 주소와 씬 순서/길이를 보존한다. 프로젝트 원본 사본, 편집용 대본, 씬 텍스트와 프롬프트를 함께 수정하고 재조회한다. 기존 자막과 음성은 복구용으로 보관하고 새 대본의 TTS 재생성 필요 상태를 남긴다. 실제 TTS 생성은 이 도구의 범위가 아니다.

REST의 여러 테이블 쓰기는 단일 트랜잭션이 아니다. 저장 도중 충돌하면 `publish_journals`의 완료 작업과 현재 DB를 확인해야 하며, 백업 전체를 무조건 덮어쓰면 안 된다. 현재 유저 변경값을 확인한 뒤 부분 저장을 조정한다. 동시 편집 감지는 낙관적 검사이므로 완전한 원자적 잠금을 보장하지 않는다.

다른 실행과 같은 토픽을 동시에 처리하지 않는다. 생성기 오류나 한도 오류로 중단된 작업을 완료라고 보고하지 않는다.
