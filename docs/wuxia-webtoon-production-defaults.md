# 무협 웹툰 제작 기본 설정

무협 웹툰 카테고리의 새 작품에 아래 기본 방향을 제안하고 적용한다. 작품마다 사용자의 변경 요청이 우선한다. 새 대본은 최종 설정을 보여주고 명시적인 시작 지시를 받은 뒤에 생성한다.

## 이야기와 음성

- 기본 형식은 오리지널 무협 성장 이야기와 한국 웹툰 스타일의 무빙툰이다. 주제와 인물, 배경, 분량은 작품마다 확정한다. 한국어와 가상의 중국풍 강호를 기본 제안으로 삼는다.
- 내레이션이 상황, 사건의 흐름과 필요한 속마음을 설명한다. 갈등, 결단, 반전 등 중요한 순간은 캐릭터가 직접 대사로 말한다.
- 캐릭터 대사는 말풍선으로 표시하고, 준비된 말풍선 효과를 대사 음성의 발화와 타이밍에 맞춘다. 대본과 장면 지시에서 내레이션과 화자별 대사, 말풍선 문구를 구분한다. 캐릭터별 음성은 실제 사용 가능한 음성 중에서 제작 시 배정한다.
- 화자 라벨이 붙은 단락도 닫는 따옴표 뒤의 행동·상황 서술은 별도 내레이션 블록으로 분리한다. 원문을 보존한 뒤 실제 웹 미리보기에서 말풍선에 서술문이 섞이지 않는지 확인하며, 섞인 상태로 등록하지 않는다. 구간 분리로 검토 번역이 달라지면 바뀐 구간만 로컬 Codex 대본워커로 번역하고 기존 번역은 보존한다.
- 참고 영상은 이야기 전달과 연출 방향의 참고 자료로 사용한다. 특정 기존 작품의 인물, 장면, 대사나 줄거리를 그대로 복제하지 않고 독립적인 이야기를 만든다.

## 이미지와 연출

- 기본 이미지 스타일은 `wuxia_webtoon`(무협 웹툰)이다. 명확한 선, 웹툰식 채색, 무협 복식과 무기, 세계관에 맞는 배경을 사용한다. 인물별 얼굴을 확실히 구별하고 각 인물의 정체성을 작품 내에서 일관되게 유지한다.
- 영상 생성 및 업로드 영상 씬은 기본 0개다. 정지 이미지와 준비된 AE 효과로 제작한다.
- 빠른 컷과 장면 전환을 필수로 계획하되 대사와 감정이 읽힐 시간을 확보한다. 중요한 장면에서 검기, 잔상, 속도선 등 준비된 효과를 장면에 맞게 적극 활용한다. 모든 효과를 모든 장면에 억지로 중첩하지 않는다.
- 같은 배경과 구도를 유지하면서 캐릭터의 표정 또는 행동이 다른 정지 이미지 상태를 필요한 장면에 준비하고 컷으로 전환한다. 이는 연속 동작이나 캐릭터 애니메이션을 만들라는 지시가 아니다. 장면별 상태와 전환 시점을 명시한다.
- 패럴럭스와 분리 레이어는 필요한 장면만 선택한다. 카메라는 고정 구도를 기본으로 하고 느린 줌을 사용하지 않는다. 필요할 때만 짧고 분명한 중간 속도 움직임과 전후 정지를 사용한다.
- 장면별로 내레이션, 화자별 대사와 말풍선, 정지 이미지 상태, 컷 전환, 필요한 AE 효과와 타이밍을 제작 지시에 포함한다. 이미지·말풍선은 인물의 얼굴과 중요한 정보를 가리지 않게 배치한다.

## 설정 확인과 제작

- 대본 작성 전 제작 형식, 주제·참고 자료, 분량·장 길이, 언어·국가·시대, 이미지·연출 스타일, 패럴럭스·레이어·영상 씬 범위, 장면 상태 변화, 음악 프롬프트 및 추가 요청을 확인하고 최종 설정에 대한 명시적인 시작 지시를 받는다. 이 문서는 확인을 대신하지 않는다.
- 배경음악 프롬프트 생성 여부는 작품마다 확인한다. 음악 파일 생성 여부는 별도다.
- 승인된 감독 제작은 실제 자료와 출력물을 확인하고 품질 우려를 별도 기록하면서 최종 조립까지 진행한다. 취소, 소유권, 파일 및 타이밍 검증을 유지하고, 관리자 게시와 YouTube 업로드는 별도 작업이다.

## 얼굴 보호·말풍선 종류·타이포그래피 필수 기준

- **말풍선의 중요도와 관계없이 화자를 포함한 모든 인물의 얼굴을 절대 가리지 않는다.** 말풍선 몸체뿐 아니라 꼬리, 글자, 테두리, 그림자와 등장·퇴장 효과까지 얼굴 보호 대상이다. 타이포그래피에도 같은 기준을 적용한다.
- 실제 원화와 최종 화면의 크롭·비율을 기준으로 얼굴 보호 영역을 확인한다. 표시 구간 전체와 상태 컷 전환 전후를 검사한다. 배치 지시에 “얼굴 보호”라고 쓰여 있다는 이유로 안전하다고 판정하지 않는다.
- 안전한 여백이 부족하면 배치·줄바꿈·크기·컷 구성을 조정한다. 얼굴을 덮거나 읽을 수 없을 만큼 글자를 줄여 해결하지 않는다. 확인되지 않은 배치를 검증 완료로 보고하지 않는다.
- 기존 말풍선 프리셋 8종을 확인하고 발화 의미에 맞게 구분한다: `dialogue` 일반 타원, `rounded` 부드러운 둥근 상자, `shout` 외침 톱니형, `whisper` 속삭임 점선형, `thought` 생각 구름형, `reaction` 짧은 반응형, `narration` 사각 설명형, `electronic` 전자통신형. 모든 대사를 타원 하나로 통일하지 않는다. 이 목록은 프리셋 정의이며 무협 내레이션을 화면 자막으로 출력하도록 허용하지 않는다.
- 타이포그래피는 반응·속마음·효과음·시스템 문구를 구분하고 저장된 연출의 글꼴, 크기, 색, 외곽선, 회전, 등장·퇴장 방식, 강조 크기 변화와 표시 타이밍을 확인하여 적용한다. 일부 색상·크기만 반영한 상태를 전체 연출 적용으로 보고하지 않는다.
- 무협 관련 생성·수정·검수 전에 이 절과 실제 사용되는 말풍선·타이포 구현을 읽는다. 웹 미리보기와 렌더 경로가 같은 종류·배치·스타일을 반영하는지 대조하며, 실제 화면에서 얼굴 비가림·말풍선 종류·타이포 표현을 확인한 증거를 남긴다. 구현, 웹 미리보기, 최종 렌더 검증의 완료 범위를 구분하여 보고한다.

## 유저웹 음성 편집과 화면 글자의 구분

- 음성 편집용으로 나눈 대본 행과 화자·성별 정보는 TTS 입력이다. 이를 옛날이야기 등 일반 카테고리의 하단 자막으로 출력하지 않는다.
- `wuxia_webtoon`의 편집 미리보기와 렌더 요청은 일반 자막 트랙을 끈다. 기존 내레이션·화자 정보·녹음·타이밍 데이터는 보존한다.
- 화면 글자는 저장된 `wuxia_still_ae_episode/v1` 연출의 실제 대사 말풍선 및 선택적인 반응·속말·효과음 타이포만 사용한다. 저장된 연출이 없을 때 내레이션 원문 자막으로 대신하지 않는다.
- 화자 표시가 노랗게 보이는 것만으로 무협 연출 적용을 완료했다고 보고하지 않는다. 실제 웹 캔버스의 내레이션 원문 미표시와 말풍선 표시를 각각 확인한다. 편집 프리뷰와 실제 녹음 기준 동기화·렌더 결과는 별도 검증이다.

- 말풍선 몸체와 꼬리는 하나의 닫힌 외곽선으로 연결하며 접합부 안쪽 선을 그리지 않는다. 꼬리는 짧게 유지하고 화자의 머리·얼굴에 닿기 전에 여백을 두고 끝낸다. 웹·HTML·AE 미리보기 모두 같은 기준을 적용한다.
- 보호 좌표를 기록한 패키지는 본체·꼬리뿐 아니라 회전·최대 강조 크기를 포함해 검사한다. 음성 행 분할로 말풍선이 사라지지 않도록 문장 전체를 연결한다. 정지 상태에서 대사를 선택하면 글자를 읽을 수 있게 유지하고, 재생 중에 저장된 등장·퇴장 연출을 적용한다.

## 선택적인 GIF 보조 움직임 (2026-11-07)

- PNG 원화·상태 컷·기존 AE 연출을 기본으로 유지한다. 별 반짝임, 나뭇가지·잎, 머리카락 끝·옷자락, 불꽃·연기·물결에만 선택적으로 짧은 루프를 덧붙인다. 첫 적용은 배경·머리카락·나뭇가지 세 유형을 비교한 뒤 회차당 3~5컷 정도부터 판단한다. 모든 컷에 적용하지 않는다.
- 얼굴·머리·몸 전체를 흔들거나 눈·입·부상·소품·배경 위치를 바꾸지 않는다. 고정 카메라를 기본으로 한다. 루프 전체 프레임에서 얼굴·말풍선·꼬리·타이포·중요 정보의 보호 영역과 움직임 영역이 겹치지 않아야 한다. 머리카락이 새로 눈·입을 덮는 연출도 금지한다.
- 원본 GIF를 화면 전체에 자동 재생하지 않는다. 로컬 준비 도구로 승인 영역만 투명 PNG 프레임으로 추출하고 GIF disposal과 실제 프레임별 지속시간을 보존한다. 원본 PNG, GIF, poster PNG, 프레임 및 `ambient_loop/v1` manifest를 함께 보관한다. GIF 제작 도구가 실제 제공되지 않을 때 생성했다고 보고하거나 다른 유료 모델을 임의로 호출하지 않는다.
- AIR Studio 미리보기는 편집 시간에서 씬 시작을 뺀 밀리초로 프레임을 선택한다. 일시정지는 현재 프레임을 유지하고 탐색은 즉시 해당 프레임을 선택한다. 상태 컷이 바뀌면 이전 패치를 제거한다. `start_ms/end_ms/phase_ms/repeat`를 명시하고 브라우저 자동 GIF 재생 시간에 의존하지 않는다.
- 보조 움직임은 원화 위, 편집 가능한 말풍선·타이포 아래에 둔다. 미리보기 프레임 로딩·체크섬 오류는 원본 PNG로 표시한다. 표시 오류를 조용히 완성 처리하지 말고 제작 검수에 기록한다.
- 실제 AE 제작은 통합워커의 동결된 제출 입력으로 실행한다. 원화 SHA, 프레임 SHA, 캔버스, 실제 알파 픽셀의 이동 영역을 확인하고 동일 프레임 시계를 출력 FPS로 샘플링하여 HOLD 키로 적용한다. 일반 업로드 영상의 반복·정지·리타이밍 금지 정책과 별개 계약이다. 원화·상태 연결이 다르거나 지원하지 않는 제작 경로면 움직임을 임의로 생략하지 않는다.
- 준비 및 등록 방법은 `docs/AMBIENT_LOOP_INTEGRATION.md`를 따른다. 원화 검수·미리보기 검증·실제 AE 출력 검증을 구분하여 기록한다.

## 선택적인 대사 입모양 (2026-11-07)

- 사용자는 1·2·3화에서도 조건이 맞는 컷에만 입모양을 적용하도록 지정했다. 최초 수동 적용 범위는 **1화만**이었다. 2·3화의 기존 산출물 수정은 별도 실행하며, 새 회차는 아래 자동 준비 정책을 따른다.
- 모든 대사 씬이나 최소 개수를 강제하지 않는다. 얼굴이 충분히 크고 입과 양쪽 입술 경계가 잘 보이는 경우만 원화별로 선택한다. 적합한 컷이 **0개인 토픽도 정상**이다. 원경·뒷모습·작은 얼굴, 손·머리카락·수염·소품 등에 가려진 입, 윤곽·화자가 불확실한 컷은 원화를 유지한다.
- 첫 적용의 보수적인 기술 기준은 얼굴 높이 원화의 20% 이상과 충분한 입 해상도이며, 이 수치만 통과했다고 선택하지 않는다. 실제 원화와 닫힘·반열림·열림 합성본을 확인한다. 모델 응답의 “보인다”만으로 승인하지 않는다. 입을 크게 보이게 만들기 위한 줌·크롭·얼굴 확대를 새로 추가하지 않는다.
- `wuxia_dialogue_mouth/v1`은 선택한 **상태 원화 SHA + 화자 + 대사 블록 + 확정 음성 ID/SHA + 자막 행 원문·성우·시각**에 묶는다. 입만 제한된 투명 패치로 교체하고 머리·턱·눈·코·부상·배경은 보존한다. 눈 깜빡임이나 음성 반응 조명은 함께 추가하지 않는다.
- 해당 원화가 표시되고 선택 화자가 실제로 말할 때만 녹음의 진폭과 쉼에 따라 세 포즈를 전환한다. 내레이션·상대방 대사·원화 전환·음성/대본 변경에는 오래된 패치를 적용하지 않는다. 파생 연기 원화에 원본의 입 좌표를 무조건 상속하지 않는다.
- AIR Studio 편집 시계와 통합워커가 같은 포즈 선택을 사용한다. 입 패치는 원화 위, 말풍선·타이포 아래다. AE 입력은 `wuxia_native_timeline/v2`로 동결해 구형 워커가 입모양을 조용히 생략하지 못하게 한다. 전체 영상의 기존 음성·대본 무결성 검사도 우회하지 않는다.
- 진폭에 맞춘 3단계 웹툰식 발화 연출이며 음소별 정밀 립싱크로 보고하지 않는다. 원화·포즈 합성·실제 녹음 대사 일치·저장 재조회·웹 재생·실제 AE 렌더의 검증 범위를 구분한다.

### 앞으로의 자동 준비·확정 음성 연결

- 새 무협 패키지는 `wuxia_mouth_policy.auto_prepare=true`로 기록한다. 명시적인 비활성화는 존중한다. 과거 수동 적용 회차를 자동으로 재작성하지 않는다.
- **대본워커**가 실제 게시된 모든 상태 원화를 검토한다. 19씬 이후 제한·회차당 개수 제한·최소 개수는 적용하지 않는다. 얼굴 높이 20% 이상, 입 너비 1.4% 이상, 식별 신뢰도 90% 이상이며 실제 입술 윤곽·가림·얼굴 방향을 검수한 컷만 선택한다. 다른 화자의 얼굴이나 파생 원화에 좌표를 상속하지 않는다.
- 확정 음성 없이도 닫힘·반열림·열림 이미지를 내장 이미지 생성 기능으로 준비한다. 원화 SHA와 검수 좌표에 묶인 투명 패치·합성 검수·캐시·저장 경로를 보존한다. 원화·말풍선·타이포·카메라는 변경하지 않는다. 외부 유료 이미지 API로 임의 전환하지 않는다.
- 확정 녹음 저장은 같은 DB 트랜잭션에서 후속 작업을 등록한다. 대본워커는 준비된 이미지를 재사용하고, 음성 ID/SHA 및 실제 녹음의 행 원문·성우·시간을 대조한 뒤 진폭·쉼에 맞춰 연결한다. 실제 PNG의 SHA·캔버스·알파 범위와 발화 구간 밖 움직임을 다시 검사한다. 음성·대사·원화 변경 시 이전 연결을 재사용하지 않는다.
- 모든 대상 검토를 끝내고 적합한 컷이 0개면 `not_required`로 **정상 완료**한다. 원화가 게시되기 전에는 `waiting_images`, 음성 확정 전에는 `waiting_audio`라는 정상 대기 단계다. 검수 도구·생성·다운로드 실패는 0개로 둔갑시키지 않고 원본·부분 산출물을 보존하며 재시도한다.
- 유저웹은 같은 편집 시계로 결과를 재조회·표시한다. 통합워커는 제출 시 동결된 연결을 사용해 AE 합성·출력과 출력물 검수를 수행한다. 대본워커의 입 이미지 준비·녹음 연결 검수와 최종 AE 영상 검수는 별도 증거로 기록한다.

## 이미지 행동 지시와 실제 낭독문 분리 (2026-11-07)

- 무협 웹툰은 그림과 대사가 이야기를 이끌고 나레이션은 필요한 연결을 맡는다. 자세·손 위치·이동·표정·부상·소품·컷 전환은 이미지 제작용 `visual_action`에 상세히 기록한다. 실제 들려줄 문장만 `spoken_blocks`에 `narration`/`dialogue`로 구분하고, 대사에는 화자를 기록한다. `scene_text`와 낭독용 `script`에는 발화 문장만 연결하며 행동 지시·화자 라벨을 섞지 않는다. `narration_text`는 나레이션 블록만 별도 보관한다.
- 화면에 이미 보이는 행동·감정을 그대로 설명하는 나레이션은 검수해 제거한다. 예: 바닥을 짚은 손이 보이는 컷에서 “손으로 바닥을 짚었습니다”를 다시 읽지 않는다. 동작 정보를 지우지 않고 이미지 지시에 보존한다. 새 사실·시간 변화·화면에 드러나지 않는 원인·꼭 필요한 의미를 더하는 문장은 유지한다. 특정 동사나 정규식만으로 의미를 추측해 삭제하지 않는다.
- 로컬 Codex 대본워커는 모든 나레이션 블록을 같은 컷의 행동 지시·인접 컷·대사와 대조한다. 삭제에는 정확한 원문과 같은 컷의 시각적 근거가 필요하고, 유지에는 새로 전달하는 정보가 명시되어야 한다. 삭제 후 전체 이야기의 인과·부상·소품 소유·인물 관계·결말을 다시 검수하고 기록한다. 대사를 임의 삭제하거나 설명 대사를 새로 채우지 않는다.
- 무협에는 공통 청취 전용 검수의 “이미지 없이 모든 행동을 이해” 기준이나 씬별 최소 글자 수를 강제하지 않는다. 무대사 컷(`spoken_blocks=[]`, `text=""`)도 정상이다. 컷의 이미지 지시·기획 길이·효과음/호흡/정지는 보존한다. 줄어든 낭독 분량을 행동 설명, 비슷한 표현, 감상적 독백으로 채우지 않는다. 실제 음성 길이와 기획 길이는 별도 확인한다.
- 이미지 프롬프트·장면 연출·캐릭터 배치는 `visual_action`과 발화 내용을 함께 사용한다. 제작용 묘사를 없애 이미지의 정보가 빈약해지게 하지 않는다. `wuxia_visual_narration/v1` 검수는 **기획 시각 정보와 낭독문**의 대조이며 실제 이미지·음성 검수 완료로 보고하지 않는다. 이미지 게시 후에는 실제 컷과 대사를 함께 보며 중복·정보 누락을 다시 확인하고, 원화가 지시와 다르면 우선 시각 연출을 보완한다.
- 기존 1·2·3화의 확정 대본·이미지·녹음은 자동 재작성하지 않는다. 이 정책은 앞으로 만드는 무협 웹툰 대본에 적용한다. 기존 회차 수정은 명시된 요청 범위와 음성·타이밍 영향 검증을 따른다.

## 충격·떨림 연출 (2026-11-07)

- 실제 원화 검수에서 손가락 개수만 확인하지 않는다. 인물 자신의 해부학적 좌우를 화면 좌우와 구분하고 어깨→팔꿈치→전완→손목→엄지 기저부→손가락으로 이어지는 구조, 손바닥·손등 및 전완 회전, 물체를 잡는 엄지 방향을 함께 확인한다. 반대 손을 붙인 형태는 원화를 수정한다.
- 익명의 치료자·부축자는 얼굴이 보인다고 새 주연이 되는 것이 아니다. 몸통이나 목선이 프레임 안에 보이면 머리·목·어깨가 자연스럽게 연결돼야 한다. 얼굴 생성을 피하려고 머리 없는 몸통을 그리지 않는다. 손·전완만 필요한 구도는 몸통이 실제 프레임 밖에 있도록 설계한다. 컷 내부의 빈 목선·떠 있는 몸통·출처 없는 팔을 허용하지 않는다. 같은 의원의 치료자는 컷마다 동일한 외형을 사용한다.

- 원화 프롬프트와 참조에는 해당 컷에 실제 등장하는 인물만 포함한다. 등장하지 않는 주인공의 외형을 부정문으로 반복해 배경에 인물이 추가되는 일을 피한다. 최종 원화에서 소품 소유·빈 칼집 입구·부상 좌우·환부 아래 붕대 위치를 직전 회차와 대조한다. 보정본은 원본을 보존하고 새 SHA로 재검수한 뒤 원화·말풍선·입모양의 참조를 함께 갱신한다.

- 실제 타격·충돌·낙하 순간에만 `impact_shake`, `impact_flash`, `debris_burst` 등을 선택한다. 긴 대화나 모든 컷에 일괄 적용하지 않는다. 원화에 없는 폭발·상처·무공을 만들지 않는다.
- 효과는 확정 음성의 정확한 앵커와 상태 원화 ID에 묶는다. 충격 후 카메라 흔들림은 `shake_hz:10`으로 **1초에 10회 완전 왕복**하는 속도를 유지한다. `shake_axis`는 장면의 힘 방향에 따라 `vertical` 또는 `horizontal`, `duration_seconds`는 장면별 독립 값으로 정한다. 3초는 30회, 5초는 50회이며 총 10회를 긴 시간에 늘여 재생하지 않는다. 지원 범위는 0초 초과~10초, 24fps 이상을 기본으로 하고 초당 20프레임 미만이면 동결을 거부한다. 두 축을 동시에 임의 흔들지 않는다.
- 낙하·내려찍기는 상하, 횡방향 충돌·측벽 파괴는 좌우를 우선 검토한다. 충격·잔진동이 이어지는 장면은 3·5초를 쓸 수 있고 작은 신체 충돌이나 짧은 원화 노출은 1·2초로 끝낼 수 있다. 앵커 시작 후 0.05초 지연, 얼굴·말풍선 보호, 실제 상태 노출 구간을 검수한다. 상태 컷에서 중단되어 반복 횟수가 줄거나 안전 검사에서 일부 프레임만 정지되는 설정은 게시하지 않는다. 카메라 진폭은 1920×1080 기준 가로 최대 16px, 세로 최대 12px이며 장면별로 조절한다. 종료 후 고정으로 복귀하고 느린 줌으로 분량을 채우지 않는다.
- 섬광·파편 등 다른 일회성 효과는 기존 0.8초 이하 제한을 유지한다. `shake_cycles`는 이전 1초 테스트의 호환 필드이며 새 제작에는 `shake_hz`를 쓰고 둘을 동시에 저장하지 않는다. 1·3·5초의 10Hz 샘플과 AE HOLD 키를 검사해 반복 속도가 같음을 확인한다.
- 실제 저장 원화와 SHA를 검수한다. 원화·입모양·보조 움직임은 함께 움직이며 말풍선·대사 글자는 고정한다. 이동 및 순간 확대 후에도 얼굴을 자르거나 말풍선에 가리지 않는다. 파편·섬광·집중선은 모든 머리와 문자 보호 영역을 피한다. 얼굴 핵심 영역의 별도 검수는 해당 원화 SHA에 귀속한다.
- 웹은 편집 재생 시계에서 결정론적으로 같은 효과를 계산한다. 통합워커 제출 시 `wuxia_native_timeline/v3`에 매 프레임 변환·도형을 동결하고 AE는 그 값을 그대로 실행한다. AE에서 별도 랜덤 흔들림이나 속도 재해석을 추가하지 않는다. 대본워커는 연출과 자산 준비, 통합워커는 확정 음성 연결 및 최종 합성을 맡는다.
- 효과만 수정할 때 기존 원화·대본·음성·입모양 자산을 재생성하지 않는다. 타이밍 앵커 누락·얼굴 검수 누락·잘못된 동결 계약은 오류로 기록하고 복구한다. 테스트 통과, 웹 재생 확인, AE 출력 파일 검수는 서로 다른 증거로 보고한다.
- 웹 배포만으로 AE PC의 실행 소스가 갱신되지 않는다. 무협 제출은 `required_worker_contract`를 기록하고 실제 점유 토큰에 묶인 워커 지원 확인 없이는 서버가 실행·완료 상태를 거부한다. 실제 작업 결과에서 원화 그대로 넘기기(`source_passthrough`)가 확인되면 효과 적용본으로 보고하지 않는다. 기존 원본·음성·실패 증거를 보존하고 실행 소스 갱신 후 다시 제작한다.
- 짧은 효과는 편집 화면 전체의 반올림된 시간 상태만으로 재생하지 않는다. 재생 중 원화 미리보기는 실제 최종 음성의 currentTime(구간 음성은 장면 시간으로 매핑)을 직접 읽고 렌더 프레임 단위로 갱신한다. 일시정지·탐색은 편집 시계로 복귀하며, 버퍼 대기 시간을 애니메이션 진행으로 계산하지 않는다.
- 발화가 없는 컷은 제작용 행동 지시를 TTS 문장으로 바꾸지 않는다. 원화 패키지에 명시적인 시작 시각·짧은 유지 시간을 저장하여 무발화 컷의 상태 전환과 작은 접촉 효과도 재생할 수 있게 한다. 이 프리뷰 시간과 확정 음성 시간표를 구분한다.
- 선택 입모양의 실제 얼굴 좌표 검수가 실패하면 같은 원화와 실패 사유를 붙여 한 번만 좌표를 다시 찾고 독립 검수한다. 재검수에서도 입술 위치를 확신할 수 없는 인물은 사유와 실패 증거를 보존한 채 원화를 유지한다. 다른 적합 인물의 준비를 계속하며, 미확인 좌표를 승인으로 바꾸지 않는다. 파일·SHA·실행 오류는 적합 컷 0개로 숨기지 않고 복구 대상으로 남긴다.
- 입술 표식이 얼굴 윤곽 또는 입 패치 밖에 놓인 수치 검증 실패도 같은 한 차례 복구 대상이다. 두 번째에도 확인되지 않으면 원화를 유지하고 실패한 좌표·원본 얼굴을 보존한다. 검수 응답 자체의 화자·순서·불리언 판정이 잘못된 경우는 정상적인 부적합 판정으로 바꾸지 않는다.
- 선택 입모양 검사에서 정상 형식의 낮은 신뢰도·불확실한 입 노출 판정은 해당 인물의 원화 유지로 처리하고 다른 컷 검사를 계속한다. 일반 AE의 엄격한 화자 확정 정책을 무협의 최소 적용 개수로 오해하지 않는다. 신뢰도를 올려 쓰거나 불확실한 입을 승인으로 바꾸지 않는다.
- 실제 세 포즈 합성에서 입술선·혈흔·얼굴 정체성이 깨져 독립 검수에 탈락하면 해당 화자만 원화를 유지한다. 실패한 실제 PNG와 사유를 격리 보관하고 같은 원화·좌표의 탈락 자산을 재시도 루프로 반복 생성하지 않는다. 통과한 다른 화자의 준비는 계속한다. 도구 부재·업로드·체크섬 등 실행 실패는 합성 품질 탈락과 구분해 오류로 남긴다.
- 유저에게 예약 배정된 `pending` 주제도 원화 준비 대상이다. 실제 프로젝트로 가져간 `assigned_at` 여부와 예약 소유자를 구분한다. 준비 시작 시 예약 소유자를 고정해 매 작업과 저장 RPC에서 일치를 검사하고, 소유자·주제 상태·원화 지문이 바뀌면 기존 작업을 보존한 채 쓰기를 중단한다.
