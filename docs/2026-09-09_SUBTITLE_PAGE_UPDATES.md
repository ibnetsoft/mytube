# 자막 페이지 업데이트 이력

작성일: 2026-09-09

## 목적

STD 유저 웹의 자막 편집 화면에서 영상 미리보기, 자막 싱크, 성우 선택, 화면 전환 효과와 자막 스타일 제어를 안정화했다.

## 반영 내용

- 씬에 업로드된 영상을 자막 페이지의 해당 씬 카드에서 영상 썸네일로 표시한다. 이미지 페이지의 원본 이미지 썸네일은 유지한다.
- 자막 카드의 영상 썸네일은 자동 반복 재생하지 않고 첫 프레임으로 표시해 초기 로딩 부담을 줄였다.
- 화면 전환 효과를 실제 미리보기 전환에 적용하고, 선택한 효과 이름을 씬 썸네일 시간 정보 아래에 표시한다.
- 미리보기 재생 상태의 하늘색 씬 강조와 플레이어 내부의 중복 재생 패널을 제거하고, 활성 자막 구간과 단어 하이라이트에만 재생 상태를 표시한다.
- 마이크와 효과 버튼의 활성화, 성우 선택 메뉴의 펼침 방향, 썸네일 시간 표기를 자막 편집 흐름에 맞게 정리했다.
- `자막 싱크` 기능을 추가했다. 최종 TTS가 없을 때에는 자막 구간별 음성 길이를 이용해 구간 시간을 보정한다.
- 최종 렌더 워커도 저장된 최종 나레이션 길이를 기준으로 자막 시간을 보정하도록 구성했다.
- 최종 TTS 생성 전, 대사 성우는 내레이션 성우와 다른 성우로 일괄 적용되어야 한다.
- 최종 TTS가 이미 저장된 경우 미리듣기는 ElevenLabs를 다시 호출하지 않는다. 저장된 전체 TTS의 선택 자막 시점부터 재생한다. 최종 TTS가 없는 경우에만 기존 구간 TTS 캐시를 사용한다.
- 자막 미리보기의 `테두리`는 네 방향 그림자 조합이 아니라 실제 글자 외곽선(`WebkitTextStroke`)으로 표시한다. 별도의 흐림 그림자는 제거했다.
- 상단 자막 설정에 `줄간격`, `최대글자수` 라벨을 추가했다.
- `최종 저장 및 TTS 생성` 버튼을 `자막 싱크` 버튼의 오른쪽으로 이동했다.

## 비용 동작

- 최종 TTS 전 자막 미리듣기: 처음 요청한 구간만 ElevenLabs를 사용하고, 동일한 자막/성우/속도/설정 조합은 캐시를 재사용한다.
- 최종 TTS 후 자막 미리듣기: 저장된 최종 오디오 파일을 재생하므로 ElevenLabs API를 사용하지 않는다.
- 최종 저장 및 TTS 생성: 전체 대본을 새로 생성해 저장한다. 현재 구간 미리듣기 캐시를 이어 붙여 최종 파일을 만들지는 않는다.
- 렌더링: 저장된 최종 오디오를 사용하며 TTS API를 다시 호출하지 않는다.

## 주요 파일

- `auth-web/app/std/page.tsx`: 자막 도구 모음, 미리보기, TTS 재사용, 스타일 표시
- `auth-web/lib/stdRenderQueue.ts`: 렌더 큐 자막 데이터 구성
- `services/remote_render_service.py`: 최종 렌더 시 자막 시간 보정

- 자막 구간 미리듣기 관련 Python 테스트는 이전 변경 시 통과했다.
- 2026-09-09 프런트엔드 ESLint 재실행은 로컬의 혼합된 npm/pnpm 의존성 폴더 처리 중 Windows 프로세스 오류로 완료되지 못했다. 각 변경 후 `git diff --check`는 통과했다.
