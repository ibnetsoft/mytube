# 웹툰 영상 연출 레퍼런스 분석

작성일: 2026-10-10
목적: 원본 웹툰 PSD를 AIR Studio 영상 제작 파이프라인에 활용할 때 구현 가능한 연출 범위와 단계별 개발 방향을 정리한다.

## 분석 대상

1. [괴력난신 웹툰 몰아보기](https://www.youtube.com/watch?v=NELzJ6H-KZc&t=2107s)
   - 확인 구간: 약 35:05~35:25
   - 분류: 웹툰 컷 재구성 중심의 모션 코믹·리캡 영상
2. [재혼황후 1~10화 팬메이드 애니메이션](https://www.youtube.com/watch?v=hjqSuyhRaqA)
   - 확인 구간: 도입부, 약 10:20, 30:19, 55:30 전후
   - 분류: AI 보조 생성과 수작업 보정을 결합한 리미티드 애니메이션

이 문서의 시각적 분석은 위 구간을 브라우저에서 직접 재생해 확인한 결과를 기준으로 한다. 두 번째 영상의 제작 방식은 제작자가 영상 설명에 공개한 내용을 함께 반영했다. 영상 전체의 모든 프레임이나 실제 프로젝트 파일을 조사한 결과는 아니므로, 세부 도구나 개별 장면의 정확한 제작 방식을 단정하지 않는다.

## 결론

첫 번째 영상의 핵심은 원본 컷 선택, 16:9 재구도, 빠른 컷 전환, 줌·패닝, 말풍선 강조와 색·광원 보정이다. 구조가 정리된 원본 PSD가 있으면 높은 비율로 자동화할 수 있다.

두 번째 영상은 원본 컷을 움직이는 수준을 넘어 새로운 구도와 동작을 생성하고, 얼굴·입·음악 타이밍을 사람이 반복 검수한 결과물이다. PSD는 캐릭터 정체성, 배경, 레이어 합성과 제한된 움직임에 유용하지만 동일한 수준을 PSD 레이어 이동만으로 만들 수는 없다. AI 이미지·영상 생성, 시간 일관성 검사, 수작업 보정과 승인 절차가 추가로 필요하다.

## 레퍼런스 1: 웹툰 컷 재구성형 연출

### 관찰된 연출

- 세로형 웹툰 컷을 16:9 화면에 맞춰 크롭하고 다시 배치한다.
- 인물 전신, 상반신, 얼굴 사이를 내레이션 박자에 맞춰 전환한다.
- 정지 이미지에 지속적인 줌인·줌아웃과 패닝을 적용한다.
- 약 2초 동안 넓은 구도로 빠르게 빠지는 줌아웃을 사용한다.
- 일부 프레임을 기울이거나 원근감 있게 배치한다.
- 말풍선을 분리해 검은 배경 위에서 강조한다.
- 장면 분위기에 맞춰 밝기, 색상, 광원과 블러를 조절한다.
- 대체로 2~5초 단위로 화면 구도나 컷을 바꿔 정지감을 줄인다.

### PSD가 있을 때 자동화하기 좋은 기능

- 패널 경계와 관심 인물 기준 자동 크롭
- 화자·대사에 맞춘 얼굴 또는 상반신 중심 프레이밍
- 카메라 줌·패닝·회전·홀드
- 전경·캐릭터·배경 사이의 2.5D 패럴랙스
- 말풍선·효과음 글자의 순차 등장과 강조
- 심도 블러, 색상 보정, 광원, 글로우, 안개, 먼지
- 충격 순간의 짧은 확대, 흔들림, 방향성 블러
- 대사·내레이션·음악 비트에 맞춘 장면 전환

### 필요한 PSD 조건

- 배경, 전경, 캐릭터, 소품, 말풍선, 효과음이 구분되어야 한다.
- 캐릭터가 움직일 범위 뒤의 배경이 복원되어 있어야 한다.
- 16:9 재구도에 필요한 해상도와 화면 밖 여유 영역이 있어야 한다.
- 레이어 그룹과 역할을 기계가 읽을 수 있도록 이름 또는 메타데이터가 있어야 한다.
- 눈·입 교체가 필요하면 열린 상태와 닫힌 상태 등 승인된 변형 레이어가 있어야 한다.

### 구현 판단

원본 PSD가 위 조건을 만족하면 이 유형은 AIR Studio의 씬 연출 계획과 AE/FFmpeg 렌더 단계로 대부분 구현할 수 있다. 편집자의 강조 타이밍까지 동일하게 재현하려면 대본 워커가 장면의 극적 목적과 시선 대상을 기록하고, 중요 장면을 사람이 검수해야 한다.

## 레퍼런스 2: AI 보조 리미티드 애니메이션

### 관찰된 연출

- 고해상도 인물과 배경에 카메라 이동, 초점 이동과 심도 블러를 함께 적용한다.
- 전경과 배경의 속도 차이, 광원과 파티클을 사용해 공간감을 만든다.
- 인물의 표정과 자세가 장면 사이에서 변하고, 원작 컷에 없는 중간 구도가 등장한다.
- 얼굴·머리카락·의상에 제한된 움직임이 보이며 장면 전환이 첫 번째 영상보다 부드럽다.
- 음악 구간에서는 노래와 화면 전환, 인물 표현을 밀접하게 맞춘다.
- 일반적인 웹툰 패널 표시보다 애니메이션 장면처럼 보이도록 원본 구도를 다시 설계한다.

### 제작자가 공개한 제작 방식

영상 설명에 따르면 다음 과정을 사용했다.

- 원작 컷을 참고 이미지로 AI 도구를 사용했다.
- 생성 결과물을 사람이 직접 다듬었다.
- 여러 구성원이 모든 장면을 검수하고 선별했다.
- 자연스럽게 이어질 때까지 연출·편집·수정을 반복했다.
- 음악에 맞춰 입 모양과 타이밍을 한 컷씩 확인하고 조정했다.
- 대사, 효과음, 음악, 자막과 화면 전환을 수작업으로 다듬었다.
- 제목의 674시간은 참여자의 실제 작업 시간을 합산한 수치라고 밝혔다.

따라서 결과 품질을 특정 AI 모델이나 PSD 자동화만의 성과로 해석해서는 안 된다.

### PSD만으로 가능한 부분

- 카메라 줌·패닝·회전과 구도 변경
- 전경·인물·배경 패럴랙스
- 심도 블러와 초점 이동
- 조명·글로우·파티클·안개 합성
- 승인된 머리카락·옷자락 레이어의 제한된 변형
- 열린 눈·감은 눈 레이어를 이용한 눈 깜빡임
- 승인된 입 모양 세트를 이용한 제한된 립싱크
- 말풍선·효과음·자막의 개별 제어

### PSD만으로 해결하기 어려운 부분

- 원본에 없는 카메라 각도와 전신 구도
- 고개 돌리기, 걷기, 손 내밀기 같은 새로운 신체 동작
- 두 인물이 접촉하거나 물건을 주고받는 상호작용
- 원본에 없는 표정과 자세 변화
- 가려진 신체·배경의 신뢰할 수 있는 복원
- 머리카락·의상의 자연스러운 물리 움직임
- 장시간 유지되는 얼굴·의상·배경의 시간 일관성
- 노래에 맞춘 자연스러운 립싱크의 무검수 자동 완성

### 추가로 필요한 제작 단계

1. 원본 PSD에서 캐릭터·배경·소품과 승인된 변형을 가져온다.
2. 대본 워커가 장면 목적, 샷 크기, 시선 대상, 카메라와 동작 계획을 작성한다.
3. PSD 모션으로 처리할 장면과 AI 생성이 필요한 장면을 분류한다.
4. 원본에 없는 동작만 참조 이미지 기반 생성 작업으로 보완한다.
5. 생성 결과의 얼굴, 손, 복식, 배경과 프레임 연속성을 검사한다.
6. 실패 장면은 PSD 모션 또는 원본 정지 컷으로 대체한다.
7. 승인된 장면만 AE 합성과 최종 렌더에 사용한다.

## 두 레퍼런스 비교

| 구분 | 컷 재구성형 | AI 보조 리미티드 애니메이션 |
| --- | --- | --- |
| 주된 소스 | 기존 웹툰 컷 | 원작 참조 + 생성 결과 + 수작업 보정 |
| 핵심 연출 | 컷 선택, 크롭, 줌, 패닝, 전환 | 새 구도·동작, 표정, 립싱크, 공간 합성 |
| PSD 의존도 | 높음 | 중요하지만 단독으로 부족 |
| 자동화 난이도 | 중간 | 높음 |
| 시간 일관성 문제 | 비교적 작음 | 얼굴·복식·손·배경에서 큼 |
| 사람 검수 | 중요 장면 위주 | 장면과 프레임 단위로 필요 |
| 안전한 실패 대체 | 원본 컷 + 기본 카메라 모션 | PSD 모션 또는 원본 정지 컷 |

## AIR Studio 적용 구조

### 연출 프로필

두 결과를 같은 프로필에서 강제로 만들지 않는다.

- `vertical_webtoon_speed`
  - 컷 재구성, 빠른 구도 전환, 줌·패닝, 말풍선 강조 중심
- 향후 `webtoon_cinematic_animation`
  - PSD 모션, 제한된 캐릭터 애니메이션, 선택적 AI 동작 생성과 프레임 검수 포함

씬별 연출 계획은 아래 처리 모드 중 하나를 명시해야 한다.

```text
psd_motion_only
ai_insert_motion
ai_full_shot
still_hold
fallback_psd_motion
fallback_original
```

### 대본 워커가 저장할 데이터

- 씬의 극적 목적과 감정 변화
- 대사·화자·내레이션 연결
- 샷 크기와 시선 대상
- 카메라 시작·종료 구도와 타이밍
- 사용할 PSD 레이어와 원본 해시
- 눈·입·얼굴 등 승인된 교체 영역
- AI 생성이 필요한 이유와 참조 자산
- 연속성 규칙과 금지 변경 사항
- 검수 조건과 실패 대체 방식

### 제출 후 통합 워커가 할 일

- 제출 시점의 PSD·이미지·영상·TTS·자막을 고정한다.
- 소스 해시와 연출 계획의 분석 대상이 일치하는지 확인한다.
- 승인된 레이어만 AE 컴포지션에 배치한다.
- PSD 모션 장면을 먼저 렌더한다.
- 필요한 장면에만 AI 생성 결과를 수집하고 검수한다.
- 좌표나 레이어가 없으면 해당 선택 효과만 건너뛴다.
- 씬 렌더가 실패하면 지정된 원본 또는 PSD 모션 대체물을 사용한다.
- 모든 씬에 유효한 미디어가 확보되면 최종 영상을 자동 렌더한다.

## 향후 개발 항목

### 1단계: 컷 재구성형 완성

- PSD 그룹·레이어 역할 가져오기
- 패널 경계와 안전 크롭 분석
- 대사·화자 기반 자동 프레이밍
- 카메라·패럴랙스·말풍선 강조 템플릿
- 레이어·이미지 해시 기반 무효화와 재사용
- 씬별 미리보기와 사용자 승인

### 2단계: 제한된 캐릭터 애니메이션

- 캐릭터별 눈 깜빡임 설정과 눈 레이어 검증
- 승인된 입 모양 세트와 음소 기반 립싱크
- 머리카락·옷자락용 제한된 Puppet/Mesh 템플릿
- 얼굴·손·의상 손상 검사
- 효과 실패 시 해당 효과만 제외하는 대체 처리

### 3단계: AI 보조 시네마틱 장면

- 장면별 생성 필요성 분류와 비용·시간 제한
- 캐릭터·의상·배경 참조 자산 묶음
- 생성 프레임의 정체성·시간 일관성 검사
- 얼굴·손·접촉 동작 검수 대기열
- 승인 결과만 사용하는 AE 합성 계약
- 생성 실패 시 PSD 모션으로 자동 복귀

## 품질 원칙

- 원본 PSD를 훼손하지 않고 파생 에셋과 결과를 별도 저장한다.
- 자동 분할 또는 복원 결과를 검수 없이 승인 레이어로 취급하지 않는다.
- 소스에 없는 신체 동작을 AE 변형만으로 억지로 만들지 않는다.
- 불확실한 얼굴·눈·입 좌표로 애니메이션을 강제하지 않는다.
- 효과 실패가 프로젝트 전체 렌더를 중단시키지 않게 한다.
- 자동화 비율보다 캐릭터 정체성, 복식, 손, 배경과 대사 싱크를 우선한다.
- 외부 작품을 제작에 사용할 때는 원작과 파생 영상의 이용 권한을 별도로 확인한다.
