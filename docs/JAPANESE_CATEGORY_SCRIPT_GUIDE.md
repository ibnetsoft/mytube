# 다섯 카테고리 공통 대본 제작 기준

기준일: 2026-11-04. 대상: 日本昔話, 다큐멘터리, 일본사건, 일본판타지, 무협 웹툰. 여러 컴퓨터의 대본 담당자가 같은 기준으로 설정을 확인하기 위한 문서다. 이 문서의 과거 사례는 다른 작품에 자동 적용할 기본값이 아니다.

## 적용과 확인

- 우선순위: 해당 작품에 대한 사용자의 명시적 지시와 확정 설정 → 선택한 전용 제작 프로필 → 카테고리 기본 제안 → 공통 대본워커 기준. 진행·복구 중인 작업은 기존 확정 설정을 유지한다.
- 신규 대본은 아래 작품별 선택 항목의 최종 값을 사용자에게 보여주고 명시적인 시작 지시를 받은 후 생성한다. 빈 항목이나 저장된 기본값을 확인으로 간주하지 않는다.
- 카테고리 이름만으로 시대·영상 수·AE 범위를 확정하지 않는다. 실제 선택한 작품 설정을 저장하고 이어받는다. 대본워커는 대본과 연출 방향을 준비하며, 프롬프트나 계획을 실제 이미지·영상·음성·AE 결과물로 보고하지 않는다.
- 서로 다른 기존 설정을 억지로 합치지 않는다. 작업 중 기존 설정과 현재 구현이 충돌하면 저장된 지시와 실행 경로를 확인하고 차이를 명시한다.

## 공통 기본 기준

**대본과 자료.** 선택한 언어에 맞는 자연스러운 낭독문을 쓰고 인물 관계, 시간, 물건, 원인과 결과를 일관되게 유지한다. 같은 내용의 반복으로 분량을 채우지 않는다. 참고 영상의 자막이나 전사를 실제 확인하고, 자료가 불충분하면 추측하지 않는다. 창작 각색은 원본의 고유 인물·대사·장면 배열을 복제하지 않는다. 역사·시사 자료는 사실, 해석, 전망과 확인되지 않은 내용을 구분한다.

**일본 배경.** 사용자가 정한 시대·지역과 원문에서 확인한 정보를 보존한다. 일본 옛이야기라는 이유만으로 특정 시대를 추정하지 않는다. 확정된 시대의 호칭, 복식, 건물, 물품과 제도를 대조하고 확인되지 않은 세부는 중립화한다. 현대 일본에 전통 소재를 무조건 넣지 않는다.

**나레이션과 대사.** 공통 기준은 간접화법 우선이다. 효과 범위가 명시된 일반 이야기에서는 효과 구간 마지막 씬까지 극적으로 필요한 직접 대사를 허용하고, 이후 고정 이미지 구간은 간접화법을 기본으로 한다. 작품별 명시적 대사 범위나 아래 전용 프로필이 우선한다. 무협 웹툰은 중요한 순간의 직접 대사와 말풍선을 사용하는 별도 기본값을 따른다. 화자·대사·나레이션을 씬별로 구분한다.

**화면과 카메라.** 같은 작품에서는 인물의 얼굴 정체성과 의상을 유지하고, 서로 다른 인물 및 기존 다른 토픽의 실제 참조 이미지와 얼굴을 비교한다. 머리·옷·주름·표정만 바꾸어 다른 얼굴로 취급하지 않는다. 고정 카메라가 기본이다. 느린 줌과 씬 전체의 완만한 줌을 추가하지 않는다. 필요한 경우 짧고 분명한 중속 움직임과 전후 정지를 사용한다. 업로드 영상 자체의 움직임은 보존한다.

**영상·AE.** 공통 대본워커의 제안은 1~18씬 이미지 1장씩, 19~50씬 필요한 레이어·입모양·패럴랙스 등 AE 연출 지침, 51씬 이후 이미지 1장씩이다. 이 제안은 영상 클립 수를 확정하지 않는다. 클립이 있는 별도 제출 절차에서는 실제 제출된 영상을 확인한 뒤 원본을 보존하며 AE 연출을 정한다. 효과가 필요 없는 씬은 홀드로 기록한다. 이미지와 레이어는 실제 필요에 따라 설계하며 복제한 단일 이미지를 독립 레이어로 취급하지 않는다. 이전 8fps 파일럿은 현행 기본값이 아니다.

**번역과 음향.** 검토 번역은 요청한 언어별로 원문 씬과 대응한다. 자막 검토 번역은 이 컴퓨터의 로컬 Codex CLI 워커를 사용하며 변경되지 않은 원문의 번역은 보존한다. 문장부호만 남은 자막은 앞 자막에 붙이되 화자와 기록된 타이밍을 유지한다. 음악 프롬프트와 효과음 계획, 실제 오디오 파일은 별개로 기록한다.

## 작품마다 확정할 항목

1. 카테고리, 제작 형식·대본 스타일, 제목·소재·참고 자료, 대상 시청자.
2. 목표 전체 길이와 장별 길이, 참고 영상 길이의 적용 여부, 언어·국가·시대·지역.
3. 이미지 스타일, 인물과 공간, 얼굴 일관성, 실제 이미지 제작 요청 여부.
4. 영상 클립 사용 여부·출처·정확한 씬 범위, 나머지 정지 이미지 범위.
5. AE 효과·패럴랙스·분리 레이어 범위와 선택적/전체 방식, 입모양 사용 범위.
6. 같은 구도의 장면 상태 변화 여부, 시작·종료 씬과 상태 수.
7. 나레이션 시점·화법, 직접 대사 허용 범위, 화자·말풍선 사용 여부.
8. 검토 번역 언어, 음악 프롬프트 생성 여부·방향, 효과음과 추가 요청.

작업 기록에는 위 확정값, 출처와 버전, 예외 지시를 함께 남긴다. 씬마다 원문·화자·길이·소스 종류·이미지 지시·필요한 효과와 타이밍을 기록한다. 목표 낭독 길이와 실제 녹음 길이는 구별한다.

## 1. 日本昔話 (ID 13)

### 카테고리 기본

- 일본어 이야기·야담·인정물. 따뜻하고 차분한 자연스러운 일본어 구연체로 쓴다. 구체적 사건이나 물건으로 시작하고 선택과 결과를 통해 전개한다. 이름·호칭·단서·물건의 이동을 일관되게 하며 교훈을 설교하기보다 변화된 행동으로 여운을 남긴다.
- 옛 시대를 지정했다면 근거와 확정 설정에 맞게 고증한다. 현대 참고 소재를 시대극으로 바꿀 때는 현대 제도와 물건의 이름만 바꾸지 않고 사건의 원인·증거·해결을 새로 설계한다.
- 기본 대본 스타일은 `story`. `jidaigeki_cel`은 일본 시대극의 절제된 2D 셀화 선택지이며, `sumi_e_ukiyo_e`도 실제 작업에 사용됐다. DB의 `realistic` 기본값을 일부 경로가 `jidaigeki_cel`로 해석하므로 실제 적용 스타일을 확인한다.
- 나레이션 중심이며 영상·AE·직접 대사의 씬 범위는 작품별로 확정한다. BGM 프롬프트도 작품별 선택이다.

### 작품별 선택과 이력

- 에도·메이지·시대 미상 중 배경, 분량, 참고 원본 길이를 따를지, 화풍, 영상·레이어·상태 변화 범위를 확정한다.
- 기존 토픽에는 영상 12씬과 18씬이 모두 있었다. 45분 작업에서는 영상 1~18씬과 19~40씬의 3상태를, 다른 작업에서는 19~20씬의 2상태를 지정했다. 이는 각각의 작품 설정이다.
- 장편 UI에는 180분·15분씩 12장 프리셋이 있으나 카테고리 공통 분량은 아니다.

## 2. 다큐멘터리 (ID 14)

### 카테고리 기본

- 일본어 해설을 기본으로 한다. 주제의 사실·해석·불확실성을 구분하고 자료 출처와 날짜를 남긴다. 역사와 현재 시사·경제는 아래처럼 별도 형식을 선택한다.
- DB에 등록된 스타일은 `default` / `realistic`이며, 선택한 전용 프로필의 실제 설정은 다를 수 있다.

### 일본 역사 다큐멘터리 선택 시

- 전용 `japanese_historical_documentary` 구현은 일본어·일본 배경·30분·`sumi_e_ukiyo_e`를 지정한다. 원사료·공공기관·학술 자료를 실제 열람하고 서로 다른 출처를 최소 2개 확보한다. 부족한 핵심 근거는 추가 조사하고 확인하지 못한 주장은 제외한다.
- 사실·이설·해석을 일본어 나레이션에서 구분한다. 인물의 미확인 속마음이나 대화를 꾸며내지 않는다. 직접 인용은 정확한 출처가 있을 때만 허용한다. 작품에서 나레이션만 지정했다면 직접 인용도 쓰지 않는다.
- 수묵화·우키요에 재현 이미지라는 점을 명확히 한다. 근거 없는 비밀 행동을 사실처럼 보여주지 않는다. 영상과 AE 씬 범위는 별도 확정한다.
- 구현상 30분이 강제되므로 다른 분량을 원할 때는 설정만 바꿔 적용된다고 가정하지 말고 실제 실행 경로를 확인한다.

### 시사·경제 다큐멘터리 선택 시

- 기본 제안: 일본 시니어 대상 일본어, 20~25분, 도입·본론 4장·결론. 일본의 생활과 연결된 질문에서 시작해 원인과 영향을 설명한다. 통계의 출처·기준일을 밝히고 확정적 예측과 근거 없는 공포 조장을 피한다.
- 화면 밖 나레이션만 사용한다. 진행자나 카메라를 보고 말하는 나레이터를 만들지 않는다. 고정 인물은 기본적으로 사용하지 않는다.
- 기본 제안은 1~18씬 영상, 19씬 이후는 모션그래픽이 필요한 씬만 영상이며 나머지는 정지 이미지다. 지도·그래프·2D 도표는 필요한 곳에 사용하고 읽을 시간을 둔다. AI 재현과 실제 자료를 구분한다.
- 절제된 악기 배경음악을 제안하고 음악 프롬프트 생성 여부를 확인한다. 자세한 기준은 `current-affairs-production-defaults.md`를 따른다.

### 작품별 선택

역사 또는 시사·경제 등 세부 유형, 주제·근거·기준일, 길이, 음성·직접 인용, 화풍, 영상·모션그래픽·AE 범위와 음악을 확정한다. 역사 전용 프로필의 30분과 시사의 20~25분을 하나의 공통값으로 합치지 않는다.

## 3. 일본사건 (ID 15)

### 카테고리 기본

- 일본어 사건·인간관계 이야기. 실제 사용자 설정에 따라 현대극 또는 시대극이 될 수 있다. DB 기본 스타일은 `japanese_domestic_drama`, 이미지 키는 `jp_domestic_watercolor`다. 이 키의 현재 전용 시각 지침은 따뜻하고 섬세한 현대 일본 2D 애니메이션이다.
- 창작물은 원본을 단순 번역하지 않고 이름·장소·직장·주거·호칭·사회 관습과 인과를 일본에 맞게 재구성한다. 확인되지 않은 실제 사건·법률 결과를 단정하지 않는다.

### 현대 사건극 전용 프로필 선택 시

- `japanese_domestic_drama`는 현대 일본, 40~60대를 포함한 성인 대상 관계 픽션이다. 절제된 나레이션과 필요한 짧은 대사를 사용하며 화자와 시간 순서를 유지한다. 불륜이나 동일한 결말을 강제하지 않는다.
- 대본과 실제 첫 발화, 게시 설명의 시작에 `本作は日本向けに脚色したフィクションです。`를 넣는다. 이미지에 글자를 굽지 않고 필요한 자막·말풍선은 편집 가능한 오버레이로 계획한다.
- 한국 YouTube URL이 있으면 자막·전사와 메타데이터의 정확한 재생시간을 확인하고 이름·장소·회사·가족·주거·금액·제도 현지화 대응표를 저장한다. 원본 길이 확인 없이 임의의 15분으로 대체하지 않는다. URL이 없으면 확정한 길이를 사용한다. 구현 지원 범위는 1~60분이다.
- 구현은 최대 첫 18씬을 사용자 업로드 영상, 이후를 이미지로 지정하며 영상 프롬프트·키프레임·전환·대사·AE 계획을 요구한다. 씬이 18개보다 적으면 실제 씬 수만큼 적용한다. 구현은 음악 프롬프트도 켠다. 이 프로필에서 다른 영상 수나 음악 설정을 원하면 실제 실행 경로를 먼저 확인한다.
- 음악 방향은 절제된 긴장 피아노, 반전의 따뜻한 현악기, 조용한 결말의 보컬 없는 악기곡. 효과음은 장면의 실제 행동에 맞춘다.

### 작품별 선택과 이력

현대극 전용 프로필과 별도 `story` 시대극 중 선택하고 시대·각색·분량·직접 대사·영상·AE 범위를 확정한다. 과거 3381은 현대극·영상 18씬, 3386은 에도 시대 `story`·영상 0씬·19~50씬 AE·50씬까지 필요한 직접 대사를 선택했다. 두 설정은 서로 대체하지 않는다.

## 4. 일본판타지 (ID 17)

### 카테고리 기본

- 일본어 창작 판타지. DB 기본 스타일은 `story` / `realistic`. 이 카테고리 전체에 고정된 영상·AE 범위나 고정 세계관은 확인되지 않았다.
- 작품의 초자연적 규칙, 조건과 대가를 일관되게 유지하고 사건과 인물의 선택이 실제 결과로 이어지게 한다. 분량을 반복 설명으로 채우지 않는다.

### 현대 일본 전당포 연작을 선택한 경우
