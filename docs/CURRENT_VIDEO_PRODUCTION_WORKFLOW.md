# 현행 영상 제작 지침

이 문서는 현재 프로젝트의 영상 제작 절차를 정한다. 씬 1~18은 사용자가 준비한 영상 클립을 원본으로 사용한다. 그중 13~18씬은 사용자가 씬 이미지를 바탕으로 영상으로 생성한 뒤 업로드하고 제출한다. 사용자 제출 전에는 AE 후공정을 하지 않는다. 제출 후 업로드된 영상에 기반한 씬별 연출안과 필요한 레이어를 준비해 AE 후공정을 하고, 그 뒤 프로젝트 전체 씬을 순서대로 최종 렌더링한다.

## 사용자 제출 전

- 1~12씬 영상 클립을 준비하고, 13~18씬은 사용자가 씬 이미지를 영상으로 생성해 각 씬에 업로드한다.
- 씬 1~18의 업로드 영상과 원본 씬·대본·대사·타이밍 정보를 연결해 보존한다. 업로드한 영상의 길이와 씬 배정이 확인되지 않으면 제출 또는 후속 AE 작업을 완료 처리하지 않는다.
- 제출 전에는 AE 연출, 레이어 분리·생성, AE 렌더를 수행하지 않는다.
- 19씬 이후는 이미지 기반으로 유지한다. 별도 지시가 없는 한 추가 영상 생성이나 모션그래픽 이미지 시퀀스를 요구하지 않는다.

## 사용자 제출 후

1. 1~18씬 각각의 실제 업로드 영상에서 대표 프레임을 확인하고 대본·대사·앞뒤 씬과 함께 검토한다. 업로드 영상 프레임을 보지 않은 사전 계획은 확정 연출안으로 사용하지 않는다.
2. 연출 페르소나는 씬마다 극적 목적, 시선 대상, 효과, 시작·종료 타임코드, 원본 영상의 보존 조건, 검수 기준을 작성한다. 씬별로 효과가 필요 없으면 의도적인 홀드로 기록한다.
3. 연출안에 필요한 이유가 적힌 경우에만 배경·인물·소품·빛 등의 분리 레이어나 추가 이미지를 준비한다. 레이어는 영상에 실제로 적용되기 전 역할·연속성을 확인하고, 준비되지 않았으면 해당 씬을 검토 대기 상태로 둔다. 모든 씬에 추가 레이어를 만들지 않으며, 초당 이미지 수나 8fps 프레임 시퀀스를 기본 요구하지 않는다.
4. AE는 업로드 영상을 기본 소스로 사용한다. 원본의 액션·인물 정체성·복식·색감·길이를 지키고, 승인된 연출안에 기재된 효과와 타이밍만 반영한다. 소스에 없는 표정·동작을 AE가 만든 것처럼 처리하지 않는다.
5. 씬별 렌더 후 대표 프레임을 연출안의 검수 기준과 대조해 타임코드별 효과 적용, 인물·의상·색의 연속성, 불필요한 반복·정지, 프레임 손상을 확인한다. 영상 길이·재생 가능성과 오디오·자막 싱크도 검사한다. 레이어 누락이나 연출 구현 실패가 있으면 해당 씬을 검토 필요 상태로 남기고 임의 효과로 대체하지 않는다.
6. 1~18씬 후공정 결과를 준비한 뒤 프로젝트 전체 씬을 순서대로 최종 렌더링한다. 씬 순서와 에셋 포함 여부, 전체 길이, 오디오·자막 싱크를 점검한다.
7. 실제 처리 및 렌더 상태를 정확히 보고한다. 사용자를 대신해 제작 완료를 선언하지 않는다.

## 연출안 데이터 계약

각 씬 계획은 `dramatic_intent`, `visual_strategy`, `source_video_review_status`, `timed_beats`, `ae_operations`, `required_layers`, `layer_specs`, `continuity_rules`, `qa_assertions`를 포함한다. 각 `timed_beats` 항목은 씬 길이 안의 `start_seconds`, `end_seconds`, `action`, `target`을 갖는다. `layer_specs`는 필요할 때만 역할, 사용 이유, 원본 소스, 생성 지침을 기록한다. 전 씬에 대한 매초 스토리보드 프레임이나 8fps 추가 이미지 목록은 사용하지 않는다.

## 보존된 이전 파일럿

이전 ComfyUI 영상 및 19~20씬 8fps 모션그래픽 시험 지침은 [AE_POSTPRODUCTION_WORKFLOW.md](AE_POSTPRODUCTION_WORKFLOW.md)에 보존한다. 이는 현행 제작 절차가 아니며 사용자가 다시 지정하기 전에는 자동 적용하지 않는다.
