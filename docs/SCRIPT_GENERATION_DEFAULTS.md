# 새 대본 기본값

로컬 대본워커에서 새로 예약하는 `new`/`grounded` 작업에 `efficient_v1` 프로필을 저장한다.
기존 작업과 재시도에는 기본값을 다시 주입하지 않는다. 기존 요청에 필드가 없으면 이전
모델 기본값(영상 18씬 등)을 유지한다. 작품별 명시 입력은 새 기본값보다 우선한다.

- 영상 업로드 대상: 기본 0씬. 필요한 경우 직접 수량 지정.
- 패럴럭스: 선택적, 이미지 레이어: 하이브리드, 연출 프로필: 자동.
- 고정 효과 범위 없음. 시작·종료를 입력한 경우에만 해당 범위에 효과 집중.
- 전체 이미지 씬에서 호환 소재 재사용을 먼저 확인하고 생성량이 줄 때만 선택.
- 기본 이미지 준비는 제출 전, AE 레이어 제작·검수는 제출 후.
- 고정 카메라 선호, 느린 줌 금지. 필요한 짧은 움직임과 업로드 원본 움직임은 구분.
- 언어·국가·시대·그림체·목표 분량은 저장된 작품별 선택을 유지.
- 제목 3개·설명·태그·썸네일 문구 3개와 배경 프롬프트·편집 가능한 디자인 기획 기본 포함.
  최종 대본(논버벌은 최종 행동 대본)을 기준으로 로컬 CLI 한 단계에서 생성한다.
  기본 생성 화면이나 대본 설정에서 이 항목을 끌 수 있다.
- 썸네일 배경 실제 생성, 최종 이미지 저장, 관리자 게시와 YouTube 업로드는 별도 상태다.
  기획 완료를 이미지 제작이나 업로드 완료로 표시하지 않는다.
- BGM 프롬프트는 기존 선택을 유지하며 기본적으로 추가 생성하지 않는다.

설정은 기존 `codex_script_defaults_<worker_id>` 저장 경로를 사용하며 해당 컴퓨터의 다음
신규 생성에 적용한다. 요청에 프로필과 실제 선택값을 저장하므로 나중의 기본값 변경이
이전 작업/재시도에 소급되지 않는다. 웹 토픽 승인을 통한 새 생성도 영상 18씬을 강제하지 않는다.
