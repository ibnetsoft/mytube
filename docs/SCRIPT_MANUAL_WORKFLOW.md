# 대본워커 단계별 수동 진행

새 일반/무빙툰 대본은 네 단계로 작성한다. 기존 작업과 재실행은 저장된 정책을 보존하며, 논버벌 전용/설교/리페어 작업은 기존 흐름을 유지한다.

1. **대본** — 씬 제목, 짧은 화면 상황, 나레이션, 화자별 대사. 이미지/영상 프롬프트와 AE 계획을 함께 생성하지 않는다.
2. **이미지 프롬프트** — 확정 대본의 씬을 컷으로 구분하고 구도, 행동, 인물/복장/소품 상태, 필요한 승인 참조 자산을 지정한다. 실제 이미지를 생성한 것으로 표시하지 않는다.
3. **영상 씬·프롬프트** — 모든 이미지 컷의 영상 필요 여부와 이유를 제안한다. 체크박스로 직접 선택·해제하고 프롬프트를 수정한다. 선택 0개도 정상이다.
4. **AE 지침** — 확정한 앞 단계 결과를 기준으로 효과와 보호 대상, 적용 시점·읽기 구간을 계획한다. 실제 원화 검토와 최종 음성 연결, AE 실행은 별도다.

로컬 대본워커의 **작업 이력·결과 → 단계별 수동 진행**에서 사용한다. 단계마다 `수정 저장`, `이 단계 확정`, `다음 단계 열기`, `생성 시작`을 따로 제공한다. 확정만으로 다음 생성이 시작되지 않는다. 모든 결과는 기존 `script_worker_jobs`의 candidate/job_record와 로컬 복구본에 저장한다. 새 데이터베이스 테이블은 필요하지 않다.

앞 단계의 내용 수정이나 재생성은 이후 결과를 보존하면서 `이전 단계 변경 · 다시 생성`으로 표시한다. 이후 단계 확정은 해제되며, 새 입력을 반영한 생성과 확인을 거쳐야 한다. 수정 전 결과는 로컬 `manual-history`에 보존한다. 저장되지 않은 편집 중에는 확정·재생성·탭 전환을 막고, 사용자가 저장하거나 버리도록 한다. 오래된 화면 버전의 저장/확정 요청과 다른 컴퓨터의 작업 변경은 거절한다.

실행 실패는 해당 단계에 기록하며 앞 단계 확정본을 보존한다. 같은 단계의 `생성 시작/다시 생성`으로 재시도한다. 재시작 후 자동 재실행하지 않는다. 사용자 수정본에는 이전 자동 검토가 그대로 적용된 것으로 표시하지 않는다. 단계별 독립 검토는 대본/계획만 대상으로 하며 실제 그림·녹음·렌더 판정으로 표시하지 않는다.

네 단계가 끝나도 자동 이미지·영상 생성, 자동 유저웹 주제 등록, 음성 생성, AE 렌더, 게시 또는 YouTube 업로드를 실행하지 않는다. 최종 상태는 **대본과 제작 지침 작성 완료**다. 관리자 웹의 대본워커 화면에서도 단계 상태와 이 컴퓨터의 워커 연결을 확인할 수 있다.
