# 대본 지침 개선

기준 저장소는 Supabase입니다. 로컬 대본워커 `http://127.0.0.1:3003/`의 **대본 지침 개선**에서 문제와 개선안을 등록합니다.

1. 문제·수정 또는 반려 사유와 다음 작성에 적용할 구체적인 지침을 기록합니다. 관련 작업 ID는 선택 사항입니다. 대본 수정 작업의 입력 의견도 자동으로 승인 대기 개선안에 모읍니다.
2. 개선안은 승인 대기로 저장됩니다. **승인**해야 적용되며, 잘못된 개선안은 반려합니다.
3. 승인된 전체 또는 일치하는 카테고리·대본 언어의 지침을 새 대본 작성·검수에 전달합니다. 진행 중인 작업과 기존 대본은 변경하지 않습니다.
4. 각 작업 결과에 적용한 지침 ID·버전·내용을 고정하여 저장하고, 검수 결과와 승인 상태를 함께 기록합니다. 모델의 검수 점수는 실제 사용자 반응이나 객관적인 품질 보장이 아닙니다.
5. 지침 변경은 새 개선안으로 등록합니다. 이전 지침은 사유와 함께 비활성화합니다. 승인 기록을 덮어쓰지 않습니다.

`script_guideline_versions`는 개선안·검토·버전 이력을, `script_guideline_outcomes`는 적용 버전과 검수 결과를 저장합니다. RLS를 활성화하고 공개·일반 사용자 접근을 차단하며 로컬 서버의 service-role만 접근합니다. 개선 지침 조회가 실패하면 지침을 누락한 채 대본을 생성하지 않습니다.

Notion 복사는 버튼을 눌렀을 때만 실행하는 선택 기능입니다. 기존 `NOTION_API_KEY`와 `NOTION_LEARNING_DATABASE_ID` 연결을 사용합니다. 문제·지침·검토·버전의 열람용 스냅샷을 복사하며 Notion의 수정 내용은 워커에 적용하지 않습니다. 실패해도 Supabase 기록이나 대본 작업은 유지됩니다. 자동 모델 학습, 자동 지침 승인, 사용자 반응에 따른 자동 점수 수집은 하지 않습니다.

기존 일본 시대·문화 고증 지침과 사용자 입력은 유지합니다. 새 개선 지침은 현재 선택한 언어·배경·요구를 보완하는 기준입니다. 파일 저장은 기존 GCS 경로를 사용하며 이 기능을 위해 대본 전문이나 미디어 파일을 Notion으로 전송하지 않습니다.
