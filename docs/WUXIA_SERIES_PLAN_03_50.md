# 「나 혼자 무공을 진화시킨다」 1~50화 전체 이야기 재설계 v2

2026-11-07 사용자 요청: 화면과 부상 설명의 반복을 줄이고, 매회 새로운 사건·발견·관계·무공 변화가 실제 결과를 만들도록 전면 재설계한다. 이 문서가 이전 3~50화 계획을 대체한다. 이전안은 `wuxia-handoff/plans/2026-11-04-series-plan-v1.md`에 보존한다.

**범위:** 전체 이야기 기획이며 새 회차 대본 생성·원화 수정·등록을 시작하는 지시가 아니다. 1~4화 확정 대본·원화·음성은 덮어쓰지 않는다. 아래 1~4화는 확정 사건의 요약과 선택적 압축 지점이며 새 사건을 소급 확정하지 않는다. 실제 새 전개는 4화의 확정 결말을 이어받는 5화부터 적용한다. 초기 회차를 실제로 빠르게 만들려면 별도의 재편집·재제작이 필요하며, 기획서 수정만으로 기존 영상 속도가 바뀌었다고 보고하지 않는다.

## 1. 새로운 이야기의 동력

**내공을 쌓지 못하는 짐꾼이 적의 무공을 관찰하고 자기 몸에 맞게 바꾸어, 사람을 버려 살아남는 문파의 방식을 자기 무공으로 뒤집는다.**

한 회의 변화는 통증이나 깨달음의 양이 아니라 **이전에는 못 하던 일을 해내거나, 되돌릴 수 없는 선택으로 다음 상황에 들어가는 것**이다. 매회 중심 사건 하나를 실제로 마무리하고 새 문제를 연다. 새 인물·이동·전투·발견을 매번 전부 채우지 않으며, 사건의 결과가 다음 사건의 원인이 되도록 잇는다.

- 생존 탈출의 반복 → 생환 소식을 무기로 목격자를 지키고 자기 일거리를 얻는다.
- 치료·훈련 독립 회차의 반복 → 필요한 기간은 생략하고, 새 기술의 성패는 의뢰·구조·대련에서 보여준다.
- 장부·정황만 조금씩 모으기 → 증거를 얻을 때마다 실제 행동권·동맹·추적 대상이 바뀐다. 서류는 사건을 여는 열쇠이지 장기 대화 분량이 아니다.
- 계속 도망치는 주인공 → 7화 첫 제압, 10화 유급 길잡이, 16화 첫 괴물전 승리, 24화 경쟁자 격파, 30화 공개 자격 획득, 39화 독자 무공 완성, 47화 장호 제압.

## 2. 반드시 이어받을 실제 상태

출처: `WUXIA_EPISODE04_DELIVERY_2026-11-07.md`, `wuxia-handoff/episode-04/script-final.json`, 1~3화 확정 원문. 이전 기획안의 예정 사건보다 실제 확정 대본이 우선이다.

- 4화 끝: 서진·도겸은 청하진 의원에서 응급 처치를 받는다. 수레꾼도 도왔다가 별원 인계 대상이 됐다. 길목 무사와 수색 무사는 감시 중이다.
- 서진의 옆구리·오른손·입술·어깨 부상, 도겸의 오른다리 부상은 사실로 유지하되 매번 다시 설명하지 않는다. 5화는 무력 탈출이 아니라 공개 목격과 인계 책임을 이용한 해결이다.
- 서진의 단검은 탈출 현장에 남았고 오른쪽 허리 칼집은 비었다. 도겸의 목도리는 오른쪽 무릎 아래, 물통·지게는 이전 석실에 남았다. 장호가 봉함을 가졌다. 생존자에게 원장부나 지시서가 갑자기 생기지 않는다.
- 새 고정 소품 시트는 디자인 기준이고 소유 상태를 복원하는 도구가 아니다. 단검을 다시 갖게 되는 사건을 6화에 명시한다. 기존 손상 흔적과 반환품 확인을 거친다.
- 강호·한국어·내공 축적 불가·진화록의 개인 가시성·석상 여섯의 기존 설정 유지. 진화록은 미래·정답·완성 기술을 지급하지 않는다.

## 3. 인물과 욕망 — 주인공을 따라다니는 설명자가 아닌 행동자

| 곽무 | 자신이 만든 유적 설비로 생긴 죽음을 바로잡는다 | 8화 등장. 비급 주는 은둔고수가 아니라 도구·현장을 제공하며, 34화 과거의 은폐를 인정 |

| 장호 | 유적의 무공 기록과 독점 지휘권을 얻는다 | 체포 명령만 보내지 않는다. 10화 덫, 20화 거래, 27화 직접 패배를 안김, 38화 기록고 선점, 45~47화 최종 대결 |
| 서리·수레꾼 | 각각 자기 자리 보전·빚진 동료 보호 | 5화 목격자 보호 사건에 참여. 서리는 18화 조작에 가담한 책임을 인정하고 원장을 넘김. 수레꾼은 22화 운반망을 행동으로 움직임 |

## 4. 50화 회차별 사건표

각 행의 **사건→결과**는 해당 회 안에서 보여준다. 마지막 열의 연결만 남기고 본 사건을 다음 회로 미루지 않는다. 표의 제목은 가제이며, 실제 제작에서 이미 확정된 제목을 덮어쓰지 않는다.

### 1부 · 버려진 짐꾼이 자기 이름을 되찾다 (1~10화)

| 화 | 제목·핵심 사건 | 회 안의 결과·새 발견 | 관계·무공 변화 / 다음 행동 |
|---|---|---|---|
| 1 | **버려진 짐꾼** — 장호가 봉함을 챙겨 탈출하고 서진·도겸이 석실에 남는다 | 버림받음과 진화록 출현. 탈출이라는 목표가 생긴다 | 확정본 보존. 압축한다면 준비 설명보다 배신과 첫 선택을 중심으로 묶는다 |

## 7. 대본 단계의 필수 전개 검수

- 회차 작성 전에 `episode_turn`: 시작 목표 → 방해 → 인물의 선택 → 회 안에서 벌어진 결과 → 달라진 끝 상태를 기록한다. `new_information`, `relationship_delta`, `martial_delta`는 해당하는 변화만 기록한다. 모든 필드를 억지로 새 사건으로 채우지 않는다.
- 각 시퀀스는 정보·목표·관계·전투 우세·장소·행동권 중 하나를 바꾸거나 다음 변화에 꼭 필요한 준비여야 한다. 통째로 빼도 인과와 감정이 그대로면 삭제·병합한다. 칼 들기·숨 고르기·상처 확인을 각각 독립 시퀀스로 늘이지 않는다.
- 도입에서 이번 회의 목표와 곧 벌어질 사건을 제시한다. 말미 예고뿐 아니라 본편 안에 성취·실패·발견의 결과를 준다. 대치·관찰만 여러 회 쌓아 결과를 미루지 않는다.
- 부상은 불가능한 행동·비용·선택을 바꾸는 순간만 사용한다. 같은 상처의 설명·혈흔 클로즈업·신음·다짐을 새 진척으로 세지 않는다. 치료·회복은 필요한 실제 기간을 확보하되 반복 묘사는 시간 경과로 압축한다.
- 회상은 현재 문제와 연결된 경험·관계·비밀을 드러낸 뒤, 복귀한 현재에서 행동과 결과를 바꾼다. 설명만 더하고 원래 대치를 이어가는 회상은 삭제한다.
- 보이는 행동의 낭독 중복을 제거하는 `wuxia_visual_narration/v1`과, **이야기 상태가 실제로 달라지는지** 보는 전개 검수는 별개다. 무대사 그림으로 같은 통증을 반복해도 느린 전개 문제는 남는다.
- 약 10분은 제작 목표이며 채워야 할 낭독 할당량이 아니다. 핵심 사건을 다 썼는데 짧으면 사건의 원인·선택·반전·관계의 실제 변화를 설계하거나 간결하게 유지한다. 화면 설명·중복 독백·느린 줌·정지 유지로 시간을 늘이지 않는다.
- 새 인물과 장소는 사건에 필요한 때만 도입한다. 빠른 전개를 이유로 우연한 구원·즉시 치유·근거 없는 급성장·매회 대형 부상·소품 복원을 남발하지 않는다. 사건 사이에는 행동으로 이어지는 원인이 있어야 한다.
- 기존 음성·원화·등록은 보존한다. 새 회차 시작은 사용자 지시와 확인된 연작 설정을 따르며, 이번 계획 변경을 제작 개시로 취급하지 않는다.
