# 무협 새 화면 효과 검증 품질 기록

부분 비네팅·반투명 정보 패널·단발 스케일 바운스·방향 슬라이드 모션 블러를 미래 신규 무협 웹툰 흐름에 연결했다. 실제 원화 검토, 웹 미리보기, 실제 Adobe AfterFX/aerender 출력, SHA 확인과 전체 디코딩을 각각 확인했다. 실제 원화와 패널 문구는 기술 QA용으로 연결했으며 기존 회차의 대본이나 이미지를 수정하지 않았다.

- 첫 렌더의 고정 구간 비네팅은 배경 어두워짐이 분명하지 않다는 검토 결과가 있었다. 원본 보호 영역과 최대 불투명도 38%를 유지하면서 마스크의 농도 분포를 보완했다. 수정본의 등장·고정·종료 구간 실제 출력 검토는 모두 통과했다. 원래 판정은 로컬 `first-render/ACTUAL_AE_REVIEW.json`에 보존했다.
- 수정본의 배경 모서리는 비교본보다 평균 RGB 밝기가 약 22.49 낮아졌으며, 보호된 주인공 얼굴·손의 밝기 차이는 각각 약 -0.04로 유지됐다. 압축에 따른 평균 RGB 절댓값 차이는 약 1.4–1.7이다. 측정은 명시된 표본 영역에 한정한다.
- 슬라이드 도중의 가로 방향 디테일 감소와 고정 구간의 선명함, 정확한 `입문 조건 충족` 문구와 반투명 배경, 단발 바운스 후 읽기 구간과 종료를 실제 디코딩 표본으로 확인했다. 패널은 읽을 시간이 부족하면 생략하도록 했다.
- 새 v6 타임라인의 기존 카메라 실행 연결도 보완하고 회귀 검사를 추가했다. 네 효과와 짧은 우측 이동을 조합한 별도 실제 AE 출력에서 예상 21.69px에 대한 실제 이동 22px을 확인했다. 패널·마스크 정렬과 마지막 고정 구간도 통과했다.
- 각 영상은 1920×1080, 24fps, 96프레임, 4초의 무음 기술 검증이다. 제공한 원화·프레임 표본을 통한 확인이며 전체 시간의 모든 픽셀이나 전체 회차·최종 음성 검증을 뜻하지 않는다. 원화에 구워진 말풍선과 입모양 패치는 이 표본에 없으므로 해당 보호 동작의 실제 픽셀 검증을 이 영상에서 했다고 주장하지 않는다. 제작별 실제 원화/출력 검토에서 별도로 확인한다.
- 원격 기존 제작은 공통 잠금을 지켜 잠시 보존한 뒤 정상 운영 매니저로 재개했다. 기존 에피소드의 상태가 18번 씬의 direction 단계로 진행된 DB readback을 확인했다. 관리자 게시 및 YouTube 업로드는 수행하지 않았다.

파일 SHA, 저장 경로, 실제 검토 판정, 웹 배포, 운영 워커 서명은 [VERIFICATION.json](VERIFICATION.json)에 기록했다.
