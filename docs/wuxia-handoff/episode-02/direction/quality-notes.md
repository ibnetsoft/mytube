# 2화 원화·연출 품질 기록

검수 범위: 실제 원화 48장, 장면 접촉 시트, 편집 글자 35개와 웹 미리보기. 독립 대본 검토의 사소한 지적은 최종본에 반영했다.

1. 관절에 짧은 단도가 걸린 접촉과 다른 손의 돌검을 유지. 우두머리의 웅크린 자세 때문에 체격 대비가 일정하지 않다.

2. 칼날 변형과 손 상처 확인. 도겸 대사는 화면 밖 발화로 배치.

3. 물통 회수와 철제 고리 발견. 두 얼굴을 피해 좌상단 말풍선으로 보완.

4. 시스템 글자는 원화에 없고 별도 편집 레이어. 새 능력 획득이나 회복으로 과장하지 않는다.

5. 철문으로 향하지 못하는 바닥 자세. 점검구 주변 석조 단차가 컷마다 다소 바뀐다.

6. 물 붓기와 걸쇠 당김을 분리. 물통 중복처럼 보이는 허리 소품은 원화의 잔여 차이로 기록.

7. 고리와 개방된 통로 확인. 첫 상태 손의 돌조각/단도 좌우는 대본과 다르며 손 연속 매치를 피한다. 입구는 대본보다 넓은 계단처럼 보인다.

8. 옆구리 통증과 진입 중단. 두 번째 상태 단도가 바닥에 놓인 표현이 있어 연속 손 접사로 매치하지 않는다.

9. 검의 입구 차단. 두 번째 상태는 고정 상세 프레이밍으로 닫힌 배경 판을 제외한다.

10. 실제 물통/끈/받침 접촉 상세 원화를 확인. 첫 상태는 손과 목도리 고정 프레이밍.

11. 긴 보폭 실패와 기둥 쪽 회피. 첫 상태 배경 점검판은 닫힌 모습이 남아 있어 직접 매치를 피한다.

12. 발과 옆구리를 각각 고정 크롭. 움직이는 줌 없음.

13. 받침 당김과 회수. 끈이 걸린 위치 및 나무 형태가 S10 상세와 완전히 같지는 않다.

14. 짧은 보폭과 기둥 정지. 도겸 응원은 화면 밖 왼쪽 발화.

15. 목도리를 다리 띠로 사용. 배낭과 중복 목도리 보정본을 사용.

16. 서진의 유인과 도겸 하강. 첫 상태 원경의 목도리는 고정 프레이밍으로 화면 밖 처리.

17. 다리 부상과 하강 후 신호. 배낭/목도리 보정. 하강 방향의 공간 연결은 압축되어 있다.

18. 칼과 겉옷 근접은 강조하되 승리 연출 없음. 원경 도겸의 지상 위치가 대본보다 늦게 남는 차이는 품질 기록.

19. 물통 전달 컷. 두 번째 보정본의 왼쪽 잔여 다리와 물통은 고정 크롭으로 제외. 세트 점검구/판 위치가 장면마다 달라진다.

20. 다리 먼저 진입과 팔꿈치 지지. 물통 제거/단도 수납 보정. 도겸의 지상 도움 자세는 대본의 아래쪽 도움과 차이가 남는다.

21. 뒤꿈치 유도와 판 아래 긴장. 단도 수납/물통 제거 보정.

22. 한 줄 이동, 다친 다리와 손·옆구리 유지. 목도리/물통/단도 보정. 대사별로 말풍선 순차 노출.

23. 철창 너머 경계. 배낭과 목도리, 물통/단도 보정. 원화의 손 위치는 정확한 침묵 손짓 대신 어깨 접촉으로 표현된다.

24. 무사 장화 실제 접사, 별도 화면 밖 경계 대사. 다음 화 위협으로 종료.

썸네일은 별도 무문자 원화와 편집 가능한 글자 3개로 구성했다. 최종 PNG는 유저웹 공통 렌더러로 저장했다. 글자 폰트 외곽선의 장식 형태를 유지했다.

검토 번역 48개는 최종 한국어 블록과 정확히 연결했다. 목소리 녹음 기준의 실제 시간 동기화나 AE 실행 결과로 보고하지 않는다. 유저웹 등록 확인은 DB의 정확한 재조회와 실제 웹 준비 판정 코드로 수행하며, 로그인된 카드 화면 열람과 구별한다.
