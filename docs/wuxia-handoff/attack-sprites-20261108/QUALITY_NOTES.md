# 투명 방전 원화 적용·실제 AE 출력 검증 — 2026-11-08

## 제작물과 적용 범위
사용자가 제공한 참고 이미지를 스타일 참고로 붙여 내장 image_gen으로 투명 RGBA 방전 원화 3장을 제작했다. 첫 생성은 불꽃에 가까운 형태여서 폐기하고, 날카로운 비대칭 번개와 백색 중심·황색 광채로 재생성했다. 최종 원화 3장은 workspace `output/wuxia-attack-sprites-20261108/raw/key-01.png`부터 `key-03.png`까지 저장했으며 생성 알파(최소 0, 최대 254)를 보존했다. 사용한 프롬프트 전체는 `prompts.json`에 있다. raw 키와 준비 프레임은 GCS에도 SHA 기반으로 저장했다.

실제 기존 1화 11씬의 PNG 상태 원화 3장을 사용하는 독립 2.5초/24fps/1920×1080 무음 검증 패키지에 적용했다. 원본 회차의 대본·확정 음성·저장 프로젝트는 덮어쓰지 않았다. 연속 신체 애니메이션이나 전체 회차 마스터 검증을 뜻하지 않는다.

전기 도형 생성 효과는 이 검증 씬에서 제거하고, 3개 원화를 배치·크기·불투명도별로 준비한 PNG 6장만 방전으로 쓴다. 바닥 접촉점은 기존의 (0.328,0.774), 접촉 18프레임/0.75초이며 플래시 다음에 PNG 방전이 시작한다. 보호 영역에서 실제 알파를 0으로 만들고 외곽에 부드러운 전이를 둔다. 웹과 AE는 같은 체크섬·캔버스·프레임 목록을 검사하며, 프레임 인덱스를 편집 시계로 고정하고 AE HOLD 키를 사용한다.

## 실제 웹과 실제 AE 확인
- 실제 production React `StdWuxiaScenePreview`를 브라우저에서 60프레임 캡처했다. 원화는 동일한 API URL에 대한 SHA가 같은 로컬 PNG 응답으로 공급한 격리 검증이며, 운영 DB의 프로젝트에 쓰기를 했다는 주장은 아니다.
- Windows Adobe After Effects 2026 / AfterFX / aerender로 같은 동결 snapshot을 실제 렌더했다. 기존 제작 작업이 슬롯을 잡고 있어 240초 이상 안전하게 기다렸고, 작업 종료 후 슬롯을 획득했다. 기존 프로세스를 강제 종료하거나 mutex를 우회하지 않았다.
- 실제 GCS 출력 파일을 내려받아 SHA를 대조하고 60프레임 전체를 디코드했다. 실제 AE 결과 SHA: `fb6ba7a345f4abfb6409072ace710127084d149475fb6d7eae02af193154703b`.
- 동결 snapshot SHA: `eaaba444a4c8a42b926b50f226e4cd1cd0686c930603e2085233e4a602adfe1c`.
- 웹/AE에서 20–31프레임에만 PNG 방전이 보인다. 20–21은 PNG 0, 22–23은 1, 24–25는 2, 26–27은 3, 28–29는 4, 30–31은 5, 32부터 사라진다. 속도선 13–17, 플래시 18–19도 포함해 실제 전체 가시 프레임 13–31이 일치했다.
- 실제 주요 출력 20/23/24/31/32 및 비교 시트를 검토했다. 중심 위치·가지 형상·원화 교체·종료가 대응하고 사각형 플래시 구멍은 없다. 입력 벡터 비교만으로 실제 AE 성공을 주장하지 않는다.

## 측정과 품질 기록
PNG 방전 구간 변화 마스크 평균 IoU 0.93967, 최소 0.83564, 원시 bbox 차이 최대 5px다. 잔광의 낮은 알파·H264 압축·브라우저/AE 리샘플링 때문에 픽셀 단위 동일성은 주장하지 않는다. 실제 AE의 보호 영역 내부 변화(동일 상태의 무효과 32프레임 대비)는 평균 절대 차이 최대 0.2462/255였다. 준비한 원본 PNG의 모든 보호 영역 알파는 정확히 0이다.

이전 엄격 픽셀 검사의 결과 `passed:false`를 그대로 보존했다. 이 검사는 의도된 화면 전체 노출 변화도 보호 영역 변화로 집계하며, 가는 속도선·낮은 알파 잔광은 압축으로 변화 마스크 임계값을 넘나든다. 검사를 완화하거나 실패 결과를 삭제하지 않았다. PNG 프레임 시각과 실제 주요 윤곽의 대응 확인은 그와 구분한다.

참고 그림을 복제한 것이 아니라 그 색감·불규칙 백색 중심·황색 광채를 참고한 새 원화다. 생성 원화는 큰 창 모양 가지가 두드러지고, 참고의 복잡한 미세 필라멘트와는 차이가 있다. 보호 마스크에서 일부 가지가 끊길 수 있으며, 이번 출력은 타격 바닥 범위에 국한된 선택적 방전이다. 기존 그림에 이미 그려진 청색 검기는 선행 상태에서 그대로 보인다.
