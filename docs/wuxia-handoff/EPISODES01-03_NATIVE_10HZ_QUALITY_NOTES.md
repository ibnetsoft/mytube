# 1·2·3화 실제 AE 출력 검증 기록

1·2·3화 전체 AE 렌더·서버 등록·다운로드 해시 대조·전체 영상/음성 디코딩과 8개 흔들림 구간 실측을 완료했다. 자동 시각 검수의 보완 기록은 별도로 유지하며 전체 작화·말풍선 품질 승인으로 해석하지 않는다. 기계 판독 증거는 `EPISODES01-03_NATIVE_10HZ_VERIFICATION.json`을 따른다.

## 고정 기준

- 초당 10회 왕복. 3초는 30회, 5초는 50회다.
- 상하·좌우 방향과 지속 시간은 `EPISODES01-03_SHAKE_10HZ.json`을 따른다.
- 원본 이미지·확정 음성·말풍선·입모양 자료와 동결된 입력을 유지한다.
- 전체 회차 파일의 프레임 수, 씬 경계, 효과 시작·종료를 실제 디코딩 결과로 확인한다.

## 실제 출력에서 확인한 항목

- 1화 11씬 실제 AE 출력: 상하 3초, 30회, 10Hz. 이동 오차 최대 0.10px, 직전·직후 정지 경계 오차 0.02px 이내.
- 2화 9씬 실제 AE 출력: 상하 3초, 30회, 10Hz. 이동 오차 최대 0.21px, 정지 경계 오차 0.04px 이내.
- 3화 11씬 실제 AE 7초 시험 출력: 상하 5초, 50회, 10Hz. 이동 오차 최대 0.14px, 정지 경계 오차 0.02px 이내.
- 위 결과는 개별 씬/시험 출력의 증거다. 전체 회차 검증과 구분한다.

## 발견된 문제와 보완

- AE 도형의 꼭짓점·접선 배열을 한 번에 할당하도록 수정했다. 실제 AE 출력 생성으로 확인했다.
- 이미지 상태마다 크기가 달라도 웹의 cover 맞춤과 같은 정렬을 적용한다.
- 동결된 무협 효과 시간표와 일반 연출 효과가 중복 적용되지 않게 했다.
- AE의 정상 종료만 믿지 않고 실제 프레임·길이를 검사한다.
- 호스트 저장 공간 부족으로 손상된 AE 파일과 검수 프레임 쓰기 오류가 발생했다. 완료 씬과 원본은 보존하고 재시도한다.
- GCS 원본의 크기·MD5와 동결 SHA-256이 일치하는 다운로드 사본만 정리하며 복원 경로·generation·해시를 남긴다.
- 최종 검수 프레임은 원래 해상도의 고품질 JPEG로 저장하고 씬별 검수 후 해시 기록을 남겨 임시 캐시를 정리한다. 최종 영상에 대한 재압축 설정 변경이 아니다.
- 일부 무협 네이티브 결과를 원본 패스스루 캐시와 혼동하던 재사용 조건을 수정했다.

## 전체 회차 프레임 검증에서 발견된 차이

1화 결합 측정본 `f7a75877514c0a1c07b8c919c4e44fda0c3070cab7dd9ada8366abec6ce7f1eb`은 14,389프레임이었다. 동결된 시간표의 24fps 기준 목표는 14,393프레임이다. 기대한 전역 효과 구간과 실제 움직임의 정렬도 맞지 않아 이 측정본은 전체 회차 효과 검증에 통과하지 못했다.

개별 11씬 영상도 동결 샘플 555개에 비해 실제 영상은 554프레임이었다. 최종 결합에 필요한 프레임 수보다 짧은 캐시는 다시 제작하도록 보강했다. AE 컴포지션 길이를 동결 샘플 개수/FPS로 만들고, 영상 프레임 수와 음성 입력의 자르기를 구분한다. 최종 합성 영상의 실제 프레임 수가 공통 시간표와 다르면 완료 단계로 넘기지 않는다.

실제 합성 필터에는 공통 프레임 수가 적용돼 있었다. 씬별 실제 디코딩 대조에서 1·7·17·24씬이 각각 1프레임씩 부족했고, 합계 4프레임으로 전체 영상의 차이와 일치했다. 분할 합성 경로가 원인이라는 중간 추정은 정정한다. 부족한 씬의 재사용을 차단하고 다시 제작했다. 수정된 전체 파일은 14,393프레임이며 효과 구간 재측정에 통과했다. 일부 이미 업로드된 씬의 로컬 캐시가 외부 정리로 없어져 해당 씬도 복원·재제작됐다.

## 자동 시각 검수의 제한

초기 호스트의 검수 CLI 경로 오류와 이후 Windows sandbox setup refresh 오류가 실제로 발생했다. 이 검수 결과는 통과가 아니라 `completed_with_notes`로 남긴다. 실제 프레임 이동 측정은 이 자동 시각 검수와 별도의 증거이며, 시각 검수 실패를 성공으로 바꾸지 않는다.

## 로컬 증거

`output/wuxia-native-render-20261107/`에 상태 이력, GCS 다운로드 해시 대조, 실제 프레임 측정 결과, 전체 회차 프레임 차이, 공간 복구 기록, 전체 회차 파일과 최종 검증 결과를 저장했다.

## 활성 작업의 파일 보호

외부 캐시 정리 중 활성 작업의 확정 음성 사본이 사라져 2화 최종 등록 단계가 재시도됐다. 원본 저장소와 이미 생성된 전체 영상은 보존됐다. 소스·재사용 씬·새 씬·마지막 프레임·최종 합성 파일을 작업 종료까지 파일 핸들로 보호하도록 보강했다. 실제 Windows에서 활성 핸들의 삭제 방지와 종료 후 해제를 확인했다. 배포 커밋 `df3b873d`의 격리된 작업 트리에서 관련 10개 테스트 모음 50개가 통과했다.

## 수정 출력 등록의 복구

1화 첫 출력과 수정 출력이 같은 작업 ID를 사용해 최종 큐 등록에서 기본키 충돌이 발생했다. `20261107131500_motion_corrected_output_registration.sql`은 소유 프로젝트·작업·파일 해시를 확인하고, 이전 완료 이력을 보존한 채 수정 출력의 안정된 asset ID를 결과 큐 ID로 연결한다. 검수·음성·씬 결과 검증 조건은 유지한다. 실제 수정본 등록과 같은 완료 요청 재전송을 확인했고 중복 없이 이전/수정 두 결과가 보존됐다.

1화 최종 등록 파일은 위 실측 해시와 일치한다. 실제 내려받은 최종 MP4의 전체 영상·음성 디코딩도 오류 없이 통과했다. 최종 결과 ID: `0e5a0eaf-e3ac-5dbf-b0f0-b90bba918f39`.

2화 최종 등록본 SHA-256은 `aedaf05ac6686299b155ec80e1baf59db0a0e609926f6884e6b23ca2eada6295`다. 재합성으로 앞선 결합 측정본과 파일 해시가 달라 최종 등록본을 다시 내려받아 전체 디코딩과 세 구간 측정을 반복했다. 모두 10Hz와 지정 지속 시간에 통과했다. 최대 이동 오차 0.21px, 인접 정지 구간 오차 0.024px 이내. 최종 결과 ID는 `13f6e0a5-ab9f-4750-aa3e-0d5b895694dc`다.

자동 검수 입력 JSON을 읽는 과정의 Windows 실행 오류를 피하도록 실제 검수 자료를 CLI 표준 입력에 직접 전달한다(`1a206043`). 쉘의 보안 설정을 변경하지 않는다. 이미지 첨부·한글/일본어 자료 전달 회귀 테스트 5개 통과(`e5ee2119`). 기존 실패 기록은 보존한다.

3화 이번 회차용 11씬 AE 출력도 별도로 측정했다. SHA-256 `c5590c6d284ca47224f806cbc98d021864e862ddd492bc0956327f265acb13a0`, 상하 5초/50회/10Hz, 실제 활성 프레임 120개, 최대 이동 오차 0.15px, 인접 정지 구간 오차 0.014px 이내로 통과했다. 앞선 7초 시험 출력과 다른 실제 회차 구성 파일이다. 전체 회차 측정은 별도로 기록한다.

## 세 회차 최종 결과

## 시각 검수의 보완 기록

최종 보고서의 상태는 세 회차 모두 `completed_with_notes`다. 누적 메모는 1화 112건, 2화 99건, 3화 60건이며 재시도·실행 오류 기록을 포함하므로 고유한 작화 결함 개수가 아니다. 원본 자동 보고서는 각 최종 결과의 `review_bucket`/`review_path`에 보존한다.

- 1·2화에는 CLI 실행/입력 읽기 오류와 그 후속 검수 기록이 남아 있다. 통과로 바꾸지 않는다.
- 3화 자동 검수에는 말풍선 꼬리 연결의 불확실성과 손·종이 등 행동 부위 가림 지적이 있다. 이 항목들은 별도 시각 보완 사항으로 유지한다.
- 일반 고정컷 검수 지시가 동결된 이미지 상태 전환을 예상하지 못한 지적도 있다. 예를 들어 1씬의 25.083초 구도 전환은 동결 샘플의 `E03_S01_STATE_02` 전환 시각과 일치한다. 이 지적을 미승인 원화 변경으로 확정하지 않는다.
- 내레이션 자막이 보이지 않는다는 지적에는 무협의 내레이션 표시 정책과 일반 자막 검수의 차이가 섞여 있다. 이를 임의로 자막 추가 지시로 적용하지 않는다.

흔들림·프레임·파일·음성 검증의 통과와 위 시각 보완 기록은 별개의 결과다.
