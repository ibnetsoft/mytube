# 무협 나레이션 분리·역할 점검 — 2026-11-08

## 결론
**대본 생성 단계에 무협 웹툰 전용 분리 경로가 있다. 그러나 형식 분리가 기존 납품 대본의 의미·문체 품질을 보장하지 않는다.** 저장된 1~3화에는 영상으로 보이는 행동의 중복 낭독과 보고체 종결 반복이 상당하다. 이 자료를 근거로 ‘제대로 분리됐으니 문제없다’고 보고할 수 없다.

이번 점검은 로컬 `output/wuxia-series-rebuild/episode-01..03/script-final.json`의 한국어 저장본과 현재 웹/대본워커 코드 기준이다. 세 파일은 `wuxia_episode_script/v1`의 `visual_states`/`blocks` 형식이며 현재 생성 경로의 `wuxia_visual_narration/v1` 검수를 통과했다는 동일한 증거는 없다. 운영 DB 최신 대본 재조회나 실제 최종 음성 청취 검증으로 보고하지 않는다. 각 파일 SHA와 통계는 `source-audit.json`에 보존했다. 기존 대본/녹음은 변경하지 않았다.

## 실제 적용 시점과 범위
1. `worker/codex_content_runner.py`는 신규 대본 계획 때 무협 전용 계약을 제공하고, 무협에 한해 `produce_sections`를 실행한다. 카테고리 18/무협 웹툰 또는 해당 명시적 스타일 설정이 대상이다. 주제에 ‘무협’이라는 단어가 들어간 다른 콘텐츠까지 적용하지 않는다.
2. 생성 단계에서 이미지 지시는 `visual_action`, 실제 발화는 `spoken_blocks`의 narration/dialogue로 분리한다. `text`는 발화 블록만 정확히 연결해야 하며 형식 검사가 불일치를 거부한다. 무발화 컷도 허용하고 무협의 최소 발화 글자 수는 0이다.
3. 계획된 시각 정보와 같은 컷의 나레이션을 문장별로 대조해 중복을 삭제한다. 원문과 같은 컷의 정확한 시각 근거가 없으면 삭제를 승인하지 않는다. 삭제된 행동 정보는 시각 지시에 남기며 대사를 자동 삭제하지 않는다.
4. 저장되는 `scene_text`/`script`는 나레이션+대사의 통합 발화 원고이고, `narration_text`가 나레이션 전용이다. 레거시 이름 `scene.narration`에도 통합 발화가 복사되므로 이름만 보고 순수 나레이션으로 해석하면 안 된다. 이미지 프롬프트는 시각 지시와 발화를 함께 쓴다.
5. 웹 TTS의 기본 경로는 저장된 `script`를 우선 사용한다. `visual_action`을 직접 낭독하는 호출은 확인되지 않았다. 이는 저장된 script 안의 행동 중계 문장이 적절하다는 뜻이 아니다. 레거시 fallback과 편집 후 입력까지 이번 텍스트 점검으로 청취/전수 보증하지 않는다.
6. 다른 장르는 기존 일반 대본/나레이션 경로를 사용한다. 이번 나레이션 역할·분리 정책 보강은 무협 웹툰에 한정한다.

## 실제 문장 검토와 수정 제안

### 2화 S01 — 행동 중계를 줄이고 성취의 의미만 남기기
원래 나레이션에는 “짧은 칼끝이 틈 안으로 들어갔습니다”, “돌아오던 손목이 덜컥 멎었습니다”, “머리 위의 거대한 팔도 한순간 붙들렸습니다”가 연속된다. 같은 컷의 원화 지시가 이미 단도·회전축·멈춘 손목을 묘사하므로 이 행동들은 시각 지시와 소리로 처리할 후보가 맞다.

수정 제안(기존 파일 적용 아님):
- **시각/소리:** 피 묻은 오른손, 관절에 끼인 부러진 단도, 한쪽 손목이 걸리는 변화, 짧은 금속 마찰음. 반대 손목과 검의 위치는 연속성 지시에 보존한다.
- **캐릭터:** 서진의 기존 “걸렸다……!”를 짧은 반응으로 유지한다.
- **나레이션:** 필요하면 “힘으로 버틴 게 아니었다.”만 남겨, 힘으로 제압한 성공이 아니라 틈을 이용한 제한적인 성공임을 짚는다. 원문에 이미 있는 원인에 근거한 해석이다. 그 의미도 그림과 앞뒤 맥락만으로 명확하면 침묵을 선택한다.

이것은 `했습니다→했다` 치환 예시가 아니다. 여러 동작 설명을 시각 채널로 돌리고, 남길 의미를 하나로 좁힌 편집 예시다. 확정 성우 원고나 기존 음성을 자동 교체하지 않는다.

### 1화 S11 — 타격은 그림·소리, 반응은 캐릭터
“장호의 검에서 푸른 기운이 솟았습니다”, “첫 검격이 부딪히자 돌바닥이 움푹 패였습니다”, “서진은 도겸의 허리띠를 잡아당겨 짐수레 뒤로 굴렀습니다”는 해당 시각 상태의 행동과 겹친다. 동작 원화·타격음·짧은 침묵으로 처리할 후보이며 나레이션으로 전부 따라 읽을 필요가 없다.

장호의 기존 “돌덩이 따위가! 물러서라!”와 도겸의 “왜 잡아당겨!”는 오판/명령과 인물 반응을 드러내므로 유지할 이유가 있다. 다음 씬에서 석상이 기운을 좇는다는 발견은 캐릭터의 관찰·경고 순서에 맞춰 공개하고, 나레이터가 이 컷에서 먼저 정답을 말하지 않는다.

### 1화 S08·S13 — 중요한 경고는 인물이 직접 말하기
“대장님. 여기서 돌아가야 합니다”, “내공을 거두세요! 기운을 쓸수록 그쪽으로 몰립니다!”는 캐릭터의 판단·경고와 다른 인물의 거절을 통해 사건을 움직인다. 나레이터의 ‘서진이 경고했습니다’ 같은 요약으로 바꾸지 않는다. 반대로 같은 경고를 나레이터가 다시 풀어서 읽으면 중복이다.

## 정리한 집필 원칙
- **그림:** 무엇이 어떻게 보이고 움직이는가. 원근·동작·표정·공간·소품·시선·타격·컷 지시를 보존하며 읽지 않는다.
- **나레이션:** 앞뒤 흐름, 시간/장소 전환, 인과·대비·새 정보와 공개 순서를 조율한다. 불필요하면 말을 비우고, 나중 사건을 성급히 스포일러하거나 없는 사실을 만들어 역할을 채우지 않는다.
- **캐릭터 대사:** 실제 행동을 바꾸는 선택·경고·요구·거절·관계 변화와 필요한 반응. 행동 설명을 대사로 옮겨 쿼터를 채우지 않는다.
- **문체:** 보고체 나열을 정보·기능부터 고친다. 어미나 접속어의 기계적 다양화, 무작위 존대 변경, 반복적인 ‘그때/하지만/아직 몰랐다’, 설명 독백 확대는 수리로 세지 않는다. 일관된 이야기 목소리와 호흡을 유지한다.

## 이번 보강과 검증
기존 연속성/이해/부풀림의 3개 항목에 **narrator_conductor / narration_rhythm / character_agency** 3개를 추가해, 정확한 원문 근거가 있는 6개 검수를 요구한다. 어떤 필수 항목이 빠지거나 실패하면 성공 감사로 기록하지 않는다. 매 검토 라운드에 실제 텍스트의 종결·연속 반복·발화 비중 진단을 함께 제공하고, 결과에는 텍스트/기획 원화 검토와 실제 원화/음성 청취의 차이를 명시한다.

진단 도구는 읽기 전용이며 통계로 나레이션을 자동 삭제/재작성하지 않는다. 나레이션을 남기는 기능에는 새 사실·시간 전환·화면에 없는 원인·필수 의미 외에 장면 연결·대비·정보 공개·위험의 의미를 명시적으로 허용했다. 모든 의미는 기존 대본과 같은 컷·앞뒤 흐름에 근거해야 한다.

관련 테스트 **30개 통과**. 기존 발화 보존·다른 장르 비적용·무발화·중복 삭제·허위 근거 차단에 더해, 새 필수 항목 누락/실패와 읽기 전용 통계, 대사/나레이션 구분을 확인했다. 이는 새로운 전체 대본을 모델로 생성해 품질 승인했거나 실제 성우/TTS를 청취한 결과가 아니다.
