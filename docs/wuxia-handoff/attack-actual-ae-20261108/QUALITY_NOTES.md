## 범위와 결과
기존 1화 11씬의 실제 상태 이미지 3장을 사용한 독립 2.5초, 24fps, 1920×1080 무음 검증본이다. 원본 에피소드, 저장된 대본·음성·제작 작업은 변경하지 않았다. 실제 웹 `StdWuxiaScenePreview`의 60장 캡처와 Windows Adobe After Effects 2026 / AfterFX / aerender로 생성한 실제 출력 60장을 비교했다. 연속적인 신체 애니메이션이나 최종 에피소드 완성본 검증을 뜻하지 않는다.

**시간 일치 확인, 완전한 시각 동일 판정은 불합격.** 실패한 엄격 픽셀 비교 결과를 그대로 보존했다. 출력 없는 성공이나 입력 벡터 비교만으로 실제 렌더 성공을 주장하지 않는다.

## 품질 기록
1. 초기 웹 검토에서 보호 영역을 지난 뒤 원격 번개 조각이 다시 나타났다. 보호 영역에 막히면 해당 분기를 끝내도록 수정했다. 수정된 웹 캡처와 동결 데이터로 실제 AE를 렌더했다. 회귀 테스트 포함 관련 15개 테스트 통과, auth-web production build 통과.
2. AE 출력의 전체 명암이 웹보다 밝다. AE 자체가 만든 native.mp4 첫 프레임도 웹과 RGB 평균 절대 오차 약 8.75/255이고, 후속 MP4 재인코딩과의 차이는 약 1.01/255다. 따라서 후속 변환만의 문제로 단정하지 않는다. AE 원본은 Mainconcept H264 yuv420p이며 색 공간 태그가 보고되지 않았다. 색관리/출력 프로필 원인은 확정하지 않았다.
3. 화면 전체 플래시의 얼굴·손 보호 영역이 사각형 구멍으로 드러난다. 웹/AE 양쪽에 같은 모양으로 재현되지만 시각 품질은 승인하지 않는다. 해당 컷의 실사용에는 국소 플래시나 부드러운 보호 마스크로 바꾼 뒤 재렌더 검토가 필요하다.
4. 압축 잡음 때문에 원시 변화 마스크의 바운딩 박스 최대 오차가 981px로 나와 엄격 검사에 실패했다. 이 이상치를 감추거나 임계값을 완화해서 통과시키지 않았다. 밝은 핵심 윤곽을 별도 분석한 파일도 남겼다. 보호 영역의 프레임 간 평균 변화 최대는 약 1.46/255이나 무손실 픽셀 동일성을 뜻하지 않는다.
5. 원본에는 청색 전기가 이미 그려져 있어 추가한 황백색 방전과 함께 보인다. 이번 검증은 원본 그림을 유지한 합성 시험이다.
