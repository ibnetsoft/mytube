# 3화 실제 유저웹 확인

- 새 주제 #3432가 무협 웹툰·20씬·영상 X로 큐에 표시되는 것을 확인했다. 실제 카드 이미지도 렌더됐다.
- 3화 주제를 작업 프로젝트로 클레임하지 않았으며 기존 활성 1화 프로젝트는 유지했다.
- 최종 원화의 인증된 웹 자산 경로가 Chrome에서 gcs-file (1672×941) 이미지 페이지로 열렸다. 이후 DOM 검사는 다른 확장 UI가 열려 있어 도구가 차단했으므로 DOM 치수를 읽었다고 표시하지 않는다.
- 상세 모달의 초반 훅 5초 비디오·Cinematic/Ghibli·1줄 자막 문구는 공통 하드코딩 안내이며 실제 저장된 무협 설정과 다르다. 이 문구를 제작 지시로 사용하지 않았다. 기존 웹의 안내 표시 관찰로 기록하며 등록을 되돌리거나 영상 작업을 추가하지 않았다.
- 원격 파일73개는 실제 다운로드 SHA-256이 로컬과 일치했다. 별도 공통 웹 컴포넌트에서 말풍선/타이포50개를 실제 Chrome으로 검사했고 글자 이탈·기록된 얼굴 영역 겹침·이미지 디코딩 문제0개였다.
