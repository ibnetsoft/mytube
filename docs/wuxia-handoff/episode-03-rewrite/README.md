# 3화 재작성 납품 — 살아 돌아온 짐꾼

2026-11-06 한국 시각. 새 주제 **#3432**. 기존 3화 #3430은 `excluded`·`admin_hidden=true`를 유지한다. #3428·#3429·#3430의 본문/구조/진행 페이로드 지문이 등록 전후 동일하다.

- 20씬, 실제 상태 원화49개, 캐릭터 시트7개, 원문84단락을 보존한 발화85구간(실제 대사45), 편집 가능한 그래픽50개.
- 태국어 검토 번역85구간, 제목/설명/편집 가능한 썸네일3레이어. 원격 파일73개 다운로드 SHA-256 확인.
- 등록 저장 재조회 일치, 실제 유저웹 큐에서 무협 웹툰·20씬·영상 X 표시 및 카드 이미지 확인. 작업 프로젝트 클레임은 수행하지 않았다.
- 실제 웹 공통 컴포넌트의 그래픽50개에서 글자 이탈/얼굴 겹침/이미지 디코딩 문제0개. 본체·통합 꼬리·최대 강조 크기·회전·꼬리 선분 교차도 검사했다.

[품질 기록](QUALITY_NOTES.md)과 [웹 확인 관찰](WEB_VERIFICATION_NOTES.md)은 납품의 일부다. 최종 얼굴 대조의 유사성 우려2쌍·판정 불가50쌍, 픽셀 미확보 참조6건, 원화별 부상/소품/공간 연속성 관찰을 통과로 바꾸지 않았다. 품질 우려를 기록하고 승인된 등록을 완료했다.

## 이야기의 승계

이 재작성본이 옛 3화의 지하 은신 중심 전개와 4화까지 탈출을 미루던 계획을 대체한다. 3화 안에서 인간 보초와의 대치 실패→단도 희생→야외 탈출→수레꾼의 도움→청하진 검문까지 진행한다. 마지막 발화는 서진의 “형. 이번엔 제가 말할게요.”다.

정전은 `script-final.json`의 `continuity_out`이다. 서진의 오른손 손바닥·왼옆구리와 추가 어깨 타격, 도겸의 오른다리 비체중부하를 유지한다. 단도는 덧문 하단 보강쇠 아래에 잃었고 오른허리 칼집은 빈 상태다. 기존 물통·지게·옛 수레를 되살리지 않는다. 연청색 천은 도겸 오른무릎 아래이며 목도리가 아니다. 새 운반 수레는 수레꾼의 것이다. 봉함은 장호에게 있다. 원화 품질 관찰에 적힌 부정확한 소품/부상 표현을 새 정전으로 승계하지 않는다.

## 다른 컴퓨터에서 복원

저장소의 `worker/connection.env` 또는 승인된 환경 인증을 준비한 뒤 실행한다. 비밀키는 이 스냅샷에 없다.

```sh
.venv-script/bin/python docs/wuxia-handoff/episode-03-rewrite/RESTORE.py
.venv-script/bin/python docs/wuxia-handoff/episode-03-rewrite/RESTORE.py --assets --readback
```

기본은 체크인된 텍스트를 `output/wuxia-series-rewrite/episode-03`로 복원한다. `--assets`는 GCS의 최종 원화/시트/썸네일/연출 및 기록을 지문 검증하여 내려받고, `--readback`은 **#3432 읽기만** 수행한다. 기존 파일이 다르면 덮어쓰지 않는다. 기존 #3430을 복원/재등록하거나 이 회차를 중복 등록하지 않는다.

등록 상태의 권위는 `packaging/registration-receipt.json`, 현재 요약은 `script-summary.json`이다. 창작 원본 스냅샷과 등록 후 상태를 혼동하지 않는다. 저장 연출은 고정 카메라·영상클립0·말풍선/선택 타이포이며 일반 내레이션 자막을 사용하지 않는다. 예비 타이밍을 실제 녹음 길이로 주장하지 않는다.
