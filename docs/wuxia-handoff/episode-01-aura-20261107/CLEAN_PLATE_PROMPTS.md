# 검기 분리용 바탕 편집 지시

내장 image_gen 편집 도구를 사용했다. 외부 이미지 모델 API는 호출하지 않았다.
대상은 실제 상태 원화 `E01_S11_STATE_01`, `E01_S12_STATE_02`, `E01_S13_STATE_02`다. 11씬 파생 연기 상태는 같은 배경·검기 영역의 바탕을 재사용하고 인물 원본은 각각 보존했다.

공통 지시: 제공한 웹툰 원화에서 검 주변의 electric-blue magical wisps/glow만 제거한다. 뒤의 기존 석실 배경을 복원하며 인물, 얼굴, 손, 실제 금속 검날과 손잡이, 석상, 횃불, 구도와 캔버스를 유지한다. 새 인물·물체·문구·말풍선을 추가하거나 크롭하지 않는다.

11씬: 화면 왼쪽 장호의 뻗은 손과 중앙 제단 사이의 작은 푸른 검기만 제거한다.
12씬: 왼쪽 먼 장호가 들어 올린 검 주변의 작은 푸른 검기만 제거한다.
13씬: 우하단부터 오른쪽 가장자리의 큰 검 주변 기운만 제거한다. 머리·갑옷의 기존 푸른 테두리 빛은 유지한다.

생성 결과를 원화 전체로 교체하지 않는다. 원화의 검기 색상 마스크로 제한된 바탕과 분리한 검기만 패치로 합성한다. 인물·검날 보호 다각형에는 바탕과 움직임 양쪽 모두 알파 0을 강제한다. 바탕의 미세한 비대상 변경은 합성에 들어가지 않는다.

생성 바탕과 64개 프레임은 `output/wuxia-episode01-aura-20261107/`에 보관한다. 게시된 프레임은 저장된 패키지의 GCS 경로와 SHA에 연결돼 있다.
