# 자동 검기·신체 기운 검증 및 품질 기록

새 무협의 실제 상태 원화를 로컬 Codex CLI로 판별하고, 원본 SHA에 결합된 기운 패치를 준비·저장하는 경로를 연결했다. 인물·손·검날·손잡이·말풍선을 보호한다. 입 모션을 꺼도 기운 준비는 독립적으로 실행한다. 기존 확정 회차는 자동 변경하지 않는다.

실제 원화 검수는 청색 검기, 황금색 신체 기운, 기운 없는 원화 세 경우로 확인했다. 신체 기운은 기술 검증용 별도 원화이며 새 제작 회차를 등록한 것이 아니다. 원화 게시 후 판별, 실제 합성 검수, GCS 재다운로드, 웹 재생, Adobe 출력은 서로 다른 증거다.

## 최종 확인

- 실제 저장소의 투명 PNG 32개를 재다운로드해 SHA·캔버스·알파·네이티브 로더를 검증했다. 모든 손실 없는 패치 합성에서 보호 다각형 안의 원본 픽셀 변경은 0이었다.
- 실제 웹 Preview 컴포넌트에서 두 경우 모두 9초 동안 반복되고 9초의 다음 상태 진입 즉시 사라졌다. 마지막 두 위상 비교에서 기운 영역 밖 픽셀 변경은 0이었다.
- 운영 Windows 소스 경로의 Adobe AfterFX와 aerender로 두 장면을 각각 실제 렌더했다. 각 파일은 1920×1080, 24fps, 228프레임, 9.5초이며 216프레임의 기운 상태와 12프레임의 일반 상태다. 저장소 파일 SHA와 동결 스냅숏 SHA를 재검증하고 전체 파일을 디코딩했다.
- 실제 출력의 초반·중간·8.7083초·마지막 기운 프레임 8.9583초·다음 상태를 검토했다. 검기는 원본 해상도에서 13개 초기/후기 위상과 같은 위상의 반복도 추가 대조했다. 최종 독립 검수에서 두 경우 모두 이글거림·보호·다음 상태 종료 확인이 통과했다. 증거는 `final-native-review.json`에 있다.
- AE MP4는 H264 압축본이다. 마지막 두 위상에서 보호 영역의 최대 채널 차이 평균은 검기 0.187, 신체 기운 0.160이며 99백분위는 둘 다 3이었다. 이 값은 압축 잡음 허용 비교이고, 정확한 0픽셀 보호 증거는 손실 없는 패치 검사다. 실제 출력의 시각 검수는 표본 검수다.
- Python 37개, JavaScript 21개 검사와 격리된 웹 프로덕션 빌드가 통과했다. 실제 DB에서 입 모션 비활성/기운 활성 상태의 큐 등록과 소스 결합 저장을 트랜잭션 안에서 확인하고 롤백했다.

## 수정·불확실성 기록

- 초기 검기는 0.5픽셀 진폭으로 움직임이 약해 출력 검수를 통과하지 못했다. 자동 준비에서 서브픽셀 진폭을 허용하지 않도록 수정했다.
- 기운 원화와 함께 배경 RGB를 이동시키는 방식은 검기 경계에 노치·중복 윤곽을 만들었다. 검기는 원본과 클린 플레이트 사이의 발광 성분만 분리해 이동시키도록 수정했다. 실제 원화·합성 검수 실패 기록을 성공으로 바꾸지 않았다.
- 더 큰 진폭은 상단 기운의 경계 겹침을 만들어 실제 합성 검수에서 탈락했다. 게시하지 않았으며 최종 검증은 안전하게 분리된 바깥 검기의 4픽셀 진폭을 사용한다. 검날에 겹친 발광과 인물에 겹친 기운은 고정된다.
- 넓은 화면의 적은 표본만 사용한 검수는 검기의 흐름/반복을 불확실하게 판단했다. 초기 실패 기록은 `initial-native-output-review.json`과 `native-actual_output_review.json`에 보존했다. 실제 디코딩한 부분 확대와 반복 위상 대조를 추가한 최종 검수에서는 요청한 이글거림을 확인했다. 별도의 발사체 궤적 이동은 요구하지 않는다.
- 불확실한 실제 선택·합성은 `uncertain`과 품질 기록으로 저장하고 원화를 유지한다. 생성·업로드·해시 오류는 재시도하며 기운 없음 성공으로 바꾸지 않는다.

## 운영 연결

운영 웹·DB·Mac 대본 워커와 Windows 네이티브 소비 경로를 연결했다. Windows의 별도 로컬 수정은 원본을 백업하고 병합해 유지했다. 실제 기운 확대 검수 모듈의 SHA는 최종 커밋과 일치한다. 기존 자동 시작 바로가기로 로컬 미디어 감독 워커를 실행했고 로컬 상태 응답을 확인했다. Windows 설치 프로그램·릴리스는 변경하지 않았다.

별도 기존 1화 전체 렌더는 원화·음성·완료 씬 캐시를 보존한 자동 복구 작업으로 재개했다. 이 보고서의 9초 기술 검증이 1화 전체 마스터 완료를 의미하지 않는다. 관리자 게시·YouTube 업로드는 별도다.
