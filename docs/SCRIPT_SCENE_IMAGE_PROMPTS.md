# 씬 카드 안의 이미지 프롬프트

수동 작업의 대본 탭에서 각 씬 카드에 이미지 프롬프트를 추가한다. 전체 대본 확정이나 다음 단계 자동 실행 없이 해당 씬만 생성/수정/저장한다. 대본 자체는 변경하지 않는다. 실제 이미지 생성은 이 기능의 실행 범위가 아니다.

- `이 씬 이미지 프롬프트 생성`: 현재 씬, 인접 씬, 선택한 참조 이미지의 실제 경로와 SHA, 제작 지침을 로컬 Codex CLI에 전달한다.
- `이 씬 프롬프트 저장`: 프롬프트와 선택 참조를 해당 작업의 `manual_workflow.scene_image_prompts[scene_id]`에 저장한다.
- 1화 인물 시트, 소품 참조 매니페스트, 화풍, 실제로 존재하는 1화 상태 원화를 공용 선택 목록으로 제공한다. 원본 이미지는 복제/수정하지 않는다. 참조 연결은 새 원화의 해부학/상태 검수나 실제 이미지 생성 도구 첨부를 의미하지 않는다.
- 대본 변경은 해당 씬의 프롬프트를 `stale`로 표시한다. 프롬프트 변경은 후속 단계의 확정을 무효화한다. 사용자 수정과 기존 프롬프트는 이력에 보존한다.
- 후속 전체 이미지 프롬프트 단계는 저장한 씬별 초안과 선택 참조를 입력으로 받는다. 승인/후속 단계 생성은 계속 별도 수동 실행이다.
- 실패 시 기존 텍스트를 보존하고 실패 상태를 표시한다. 존재하지 않는 참조 ID, 다른 컴퓨터 작업, 변경된 결과 버전은 거절한다.

참조 제공 위치: `output/wuxia-series-rebuild/episode-01/character-sheets/`, `docs/wuxia-props/reference-manifest.json`, `docs/wuxia-handoff/episode-01/image-inventory.json`. 원본 파일이 이 컴퓨터에 없으면 목록에서 제외한다.

검증: `tests/test_script_manual_workflow.py`의 씬별 생성 입력 전달, 상태 격리, 사용자 저장, 대본 변경 무효화, 알 수 없는 참조 거절, 실패 시 텍스트 보존 검증. 실제 이미지·AE 출력 검증과 구분한다.
