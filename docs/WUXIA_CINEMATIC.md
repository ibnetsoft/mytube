# 무협 웹툰의 선택적 화면 연출

`wuxia_cinematic/v1`은 앞으로 생성하는 무협 웹툰에서 다음 네 연출만 추가한다. 기존 이동·줌·플래시·쉐이크·디졸브·검기 루프를 중복 생성하지 않는다.

| 연출 | 자동 선택 기준 | 보호와 시간 |
| --- | --- | --- |
| 부분 비네팅 | 고립, 위기, 내적 갈등의 시선 집중 | 실제 원화의 인물·손·주요 무기·문자를 보호한 배경 마스크, 최대 불투명도 38% |
| 반투명 정보 패널 | 대본에 명시된 새로운 경지·능력·임무 정보 | 계획된 이미지 지시에서 정확히 인용, 사실·수치 생성 금지, 기존 글자와 중복 금지, 장면당 최대 한 상태 |
| 스케일 바운스 | 정보 패널의 짧은 등장 강조 | 0.86 → 1.08 → 0.98 → 1, 한 번 뒤 고정, 읽을 시간 확보 |
| 슬라이드 모션 블러 | 이미 선택된 방향 슬라이드의 이동감 | 첫 0.24초 이내, 최대 12px, 원화만 9개 노출 샘플, 편집 글자는 별도, 원화에 구워진 글자는 선명한 패치 복원 |

선택은 로컬 Codex CLI 대본 워커가 장면의 실제 계획 내용으로 수행한다. 사용 횟수나 순환 할당이 없으며 모두 선택하지 않아도 정상이다. `new`/`grounded` 생성에만 적용하고 기존 확정 회차를 자동 변경하지 않는다. 명시적 비활성화와 수동 장면 선택을 보존한다. 검기만 움직이도록 지정된 `energy_only_motion` 원화에서는 네 연출을 억제한다.

이미지가 게시되면 기존 원화 준비 워커가 원본 SHA와 장면 계획, 편집 문자에 연결된 실제 이미지 검토를 수행한다. 얼굴·손·무기·문자 보호 영역과 패널의 전체 108% 바운스 이동 범위를 검토한다. 공간이 없거나 글자를 읽을 시간이 부족하면 해당 연출을 생략하고 품질 노트를 남긴다. 검토의 불확실성은 원본으로 제작을 계속하는 사유이며 기술 실패를 성공으로 치환하지 않는다. 원본·계획·문자 변경은 검토를 무효화한다.

웹의 편집 시계에서 계산한 마스크·패널·바운스·블러 샘플을 `wuxia_native_timeline/v6`에 고정한다. 통합 AE 워커는 같은 샘플을 네이티브 레이어와 원화 전용 노출 프리컴프로 실행한다. 별도 플러그인이 필요하지 않다. 캐시는 렌더러 코드 서명과 실제 출력 검토 항목까지 일치해야 재사용한다. 실제 출력 검토는 비네팅 보호, 정확한 패널 문구와 가독성, 단발 바운스와 고정 구간, 전환 뒤 블러 종료를 포함한다.

## 검증 범위

자동 선택, 실제 원화 검토, 웹 미리보기, 실제 Adobe 렌더 파일은 각각 별도 증거다. 기술 QA용 단일 원화 비교 렌더는 새 회차나 기존 1화 전체 완료를 뜻하지 않는다. 관리자 게시와 YouTube 업로드는 별도 작업이다.
