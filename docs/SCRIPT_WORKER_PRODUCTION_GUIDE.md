# 대본워커 기본 제작·완료 기준

이 문서는 AIR Studio의 로컬 Codex 대본워커와 이를 감독하는 작업자가 사용자 요청을 실행할 때 적용하는 운영 기준이다. 현재 요청과 저장된 프로젝트 설정이 이 문서의 예시보다 우선한다. 실제 실행하지 않은 단계는 완료로 보고하지 않는다. 웹 제품은 `auth-web/`이며 은퇴한 Windows 패키지는 대상이 아니다.

## 1. 시작 전에 확정할 것

- 신규 대본은 제작·대본 종류, 소재·카테고리·참고 URL 또는 자료, 길이와 장별 길이, 대본 언어·국가·시대, 이미지와 연출 스타일, 패럴랙스·레이어·영상 씬 범위, 장면 상태 변화, 음악 프롬프트와 추가 요구를 사용자에게 보여주고 확인한다. 저장된 기본값만으로 확인된 것으로 보지 않는다. 최종 설정을 보여준 뒤 명시적인 시작 지시를 기다린다.
- 이미 실행 중이거나 복구하는 작업은 기존에 확정된 설정을 유지한다. 중간에 바뀐 사용자 지시는 저장된 설정과 진행 단계를 확인해 반영하고, 취소·소유권과 중복 생성 여부를 확인한다.
- 원본 길이와 내용을 확인한다. YouTube 자막을 사용할 수 없으면 이용 가능한 음성을 로컬에서 전사해 내용과 결말을 확인하고, 불확실한 부분을 표시한다. 자료가 없으면 추측하지 않는다. 원본은 참고 자료이며 대사·이름·장면을 그대로 복제하지 않고 설정에 맞게 독창적으로 각색한다.

## 2. 대본과 번역

- 선택한 언어와 배경에 맞게 이야기의 인과관계, 인물 관계와 정보의 출처를 일관되게 작성한다. 조사와 결말에서 같은 사실이나 결정을 반복하지 않는다. 한 인물이 직접 보거나 전달받지 않은 사실을 아는 것처럼 쓰지 않는다.
- 인물 발화는 간접화법을 우선한다. 효과 구간의 마지막 씬까지는 극적으로 필요한 경우 직접화법을 허용하고, 그 다음 고정 이미지 씬부터는 인물 발화 없이 나레이션의 간접화법으로 전달한다. 사용자가 다른 화법 범위를 지정하면 그 설정을 따른다. 이 규칙은 명시된 효과 범위가 있는 작업에 적용한다.
- 대본 수정 후 씬 수·길이·대사 주석·이미지 프롬프트·연출·음향과 번역이 수정된 원문에 맞는지 다시 확인한다. 내용을 반복해서 분량만 채우지 않는다. 확정된 목표 길이를 맞출 수 없다면 실제 예상 길이와 차이를 보고한다. 계획 길이와 실제 녹음 길이는 구분한다.
- 요청한 검토용 번역을 생성하고 각 씬 원문과 번역을 빠짐없이 대응시킨다. 일본어 대본을 한국어·태국어로 검토하는 제작에서는 두 언어를 모두 준비하되 사용자가 범위를 달리 정하면 그 지시를 따른다. 자막 검토 번역은 이 컴퓨터의 로컬 Codex CLI 워커만 사용하며 Gemini 또는 OpenAI 모델 API를 직접 호출하지 않는다. 원문이 바뀐 부분만 다시 번역하고 변경되지 않은 번역은 보존한다. 대본 씬 번역과 실제 타이밍 자막 번역은 구분한다.

## 3. 이미지·레이어·연출·음향

- 씬별 기본 연출은 다음과 같다. 신규 대본 시작 전 사용자에게 이 기본값을 보여주고 확인하며, 사용자가 다른 범위나 방식을 지정하면 그 설정을 따른다.
  - 1~18씬: 씬마다 이미지 1장.
  - 19~50씬: 레이어별 이미지 생성과 입모양 효과, 패럴랙스 등 AE 효과 작업을 위한 연출 지침 생성.
  - 51씬~마지막 씬: 씬마다 이미지 1장을 사용하고 줌인·줌아웃·좌우 이동과 문맥 기반 씬 전환을 적용한다. 카메라 움직임은 아래의 속도와 정지 기준을 따른다.
- 사용자가 실제 이미지 제작까지 요청한 작업은 프롬프트나 계획 저장에서 멈추지 않는다. 각 씬의 실제 이미지 파일을 생성·검증·저장하고 저장된 링크를 재조회한다. 이미지 프롬프트만 있으면 ‘미생성’이다.
- 효과 구간에는 사용자가 지정한 범위와 방식에 따라 원본에 등록되는 독립 배경·인물·전경 등 필요한 레이어 이미지를 실제 생성하고, 투명도·정렬·파일 무결성·저장 위치를 확인한다. 단일 이미지를 복제해 가짜 레이어로 간주하지 않는다. 효과 범위 밖은 확정된 고정 이미지 또는 별도 요청에 맞춘다.
- 캐릭터는 같은 토픽 안에서 승인된 얼굴 정체성을 유지한다. 새 토픽의 인물들끼리와 다른 모든 카테고리의 저장된 실제 참조 이미지들을 비교해 얼굴 정체성이 다른지 확인한다. 머리·옷·표정·주름만 다른 경우는 다른 얼굴로 간주하지 않는다. 비슷한 새 얼굴은 다시 디자인하고 기존 토픽 자산은 보존한다. 실제 비교하지 않았다면 검토 완료라고 쓰지 않는다.
- 느린 줌과 장면 전체에 걸친 부드러운 줌을 추가하지 않는다. 고정 카메라를 우선하며 필요한 경우 짧은 이동 구간과 전후 정지가 있는 명확한 중속 움직임을 사용한다. 업로드된 영상 자체의 움직임은 보존한다.
- 배경음 프롬프트와 효과음은 최종 대본의 사건·감정에 맞게 구성한다. 기존 사용자 효과음과 자산을 보존하고, 변경된 대본과 일치하지 않는 위치는 검토 대상으로 표시한다. 실제 음성과 이미지가 없으면 타이밍·화면 검증이 완료된 것으로 쓰지 않는다.

## 4. 등록·검증·보고

- 유저웹 토픽 등록은 대본 또는 작업 결과를 연결하는 단계다. 등록만으로 이미지, 레이어, 번역, 실제 영상이 만들어진 것이 아니다. 각 단계는 요청 범위대로 이어서 처리한다.
- 원본 대본 지문, 토픽 출처, 미배정·취소 상태와 기존 자산을 확인해 중복 토픽이나 다른 사용자의 작업을 덮어쓰지 않는다. 각 생성 파일과 저장 위치, 씬·레이어·번역 수를 실제로 확인하고 DB와 유저웹에서 재조회한다.
- 이미지·레이어·번역·프롬프트·연출 계획·효과음 계획·실제 음성·렌더를 별개 상태로 보고한다. 품질 우려는 사실대로 품질 메모에 기록하고 승인된 제작 흐름을 계속한다. 없는 파일이나 깨진 출력은 완료로 표시하지 않는다. 관리자 게시와 YouTube 업로드는 별도 작업이다.
- 실행 오류나 중단은 사용자에게 즉시 알리고 원인을 확인한다. 자동 복구할 수 있으면 기존 작업 ID·입력 지문·완료된 결과물을 재사용해 재시도하며, 중복 생성이나 위험한 덮어쓰기를 피한다. 반복 오류는 근본 원인을 고치고 재검증한다. 장시간 작업은 오류·완료를 감시하고 정상 진행 중에는 불필요한 반복 알림을 보내지 않는다.
- 최종 보고에는 완료된 실제 산출물과 개수, 저장·재조회 결과, 아직 생성·확인하지 못한 것, 오류와 복구 결과, 품질 메모를 명시한다. 사용자 요청이 계획·검토에만 한정되면 그 범위를 넘겨 제작하지 않는다.
