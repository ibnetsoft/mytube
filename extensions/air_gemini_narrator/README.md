# AIR Gemini Narrator — 0.1.0 실험 버전

**사용하지 않는 초안:** 사용자 요청에 따라 새 확장 설치를 중단했다.
현재 워커 경로는 `docs/COWORK_GEMINI_NARRATION.md`를 따른다.

Gemini Reader의 코드·계정·멤버십에 의존하지 않는 별도 확장 프로그램.
사용자가 로그인한 Gemini 웹에 원문을 보내고, 응답 원문 일치 여부를
확인한 뒤 읽어주기에서 사용되는 단일 audio Blob을 다운로드한다.
공식 Gemini TTS API 또는 임의의 비공개 엔드포인트를 호출하지 않는다.

## 설치

Chrome 확장 프로그램 관리에서 개발자 모드를 켜고, '압축해제된 확장
프로그램을 로드합니다'로 이 폴더를 선택한다. Gemini 탭을 새로고침한다.
Gemini Reader 오버레이가 열려 있으면 닫는다. AIR 패널에서 짧은 문장으로
시험한다. 확장 버튼으로 접힌 패널을 다시 열 수 있다.

## 검증 상태

- 실제 한국어 Gemini 화면에서 원문 응답과 '옵션 더보기 → 듣기' 확인.
- 독립 확장 프로그램 설치 후 오디오 확보는 아직 검증하지 않음.
- 단일 Blob을 사용하는 HTMLAudioElement 재생만 지원한다.
  WebAudio, MediaSource, 분할 스트림 등은 추가 구현이 필요하며 성공으로
  보고하지 않는다. API의 유료 TTS와 같은 목소리 선택을 보장하지 않는다.
- 생성·파일 저장 시 전체 재생 시간이 필요하다.
- 다운로드/AIR-Narration 아래 원래 오디오 형식으로 저장한다.
- 워커 작업 전달, 자동 회수, 인물 대사 합성은 아직 연결하지 않음.
  그 연결 전에 설치된 확장에서 파일 생성 성공을 검증해야 한다.

## 다음 연결 계약

로컬 워커에서 job_id, segment_id, narration text를 인증된 채널로 전달하고,
확장은 완료 파일과 식별자를 반환한다. 한 번에 하나의 세그먼트만 처리한다.
임의 페이지 메시지를 작업으로 실행하거나 Google 세션 쿠키를 워커로
전달하지 않는다. 다운로드 완료·오디오 디코드·원문 검증 이후에만
완료 처리하며, 인물 대사는 기존 ElevenLabs 경로로 별도 생성한다.

## 제한

브라우저를 켜 두어야 한다. 로그인 만료·한도·화면 변경은 작업 중단으로
표시한다. 유료 API로 자동 전환하지 않는다. 유료 구독이 웹 음성의
무제한 생성이나 사용량 확대를 보장한다는 가정은 하지 않는다.
