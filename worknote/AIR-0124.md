# AIR-0124: Settlement Payout Processor

## Goal
Implement a manual payout processor for the Admin Dashboard to atomically transition `pending` referral commissions to `paid` status and increment the beneficiary's `usdt_balance`.

## Actions Taken
- Created `auth-web/migration_payout_rpc.sql` containing the PostgreSQL RPC `process_referral_payout`.
- Updated `auth-web/supabase_schema.sql` to include the RPC for new environments.
- Created `POST /api/admin/settlements/payout` to expose the RPC securely to superadmins.
- Updated `auth-web/app/admin/settlements/page.tsx` to add an "Approve & Pay" button for `pending` commissions, complete with a confirmation dialog and loading state.
- Excluded automated cron, real-time payouts, and negative balance rollbacks for refunds to strictly adhere to the sprint scope.

## Status
- Merged into `main`.
- Idempotency verified: `FOR UPDATE` combined with `status = 'pending'` ensures safe atomic execution, preventing double payouts.
- Future work (subsequent sprints) may involve cron/automated payouts and rollback handling for refunded recharges.
