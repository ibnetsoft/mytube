# AIR-0147 — Subtitle API 정리 (Dead Route 삭제 + 이동)

## 작업 개요

AIR-0146 조사 결과를 바탕으로 main.py의 Subtitle 관련 Dead Route 삭제 및
실제 사용 중인 라우트를 app/routers/video.py로 이동.

## 작업 배경

AIR-0146 조사에서 main.py에 4개의 @app.* Subtitle 라우트가 있음을 확인:

| 라우트 | 상태 | 조치 |
|--------|------|------|
| GET /api/settings/subtitle/default | 호출처 없음, 응답 구조 inconsistent | 삭제 |
| POST /api/settings/subtitle/default | 호출처 없음 | 삭제 |
| GET /api/settings/subtitle/defaults | autopilot.js 사용 중 | video.py 이동 |
| POST /api/project/{id}/subtitle/delete | 호출처 없음, 기능 유효 | video.py 이동 보존 |

또한 main.py에 선언만 되고 미사용인 클래스 SubtitleGenerationRequest 확인 → 삭제.

## 변경 파일

- main.py
- app/routers/video.py
- worknote/AIR-0147.md (이 파일)

## main.py 삭제 내역

### 1. GET/POST /api/settings/subtitle/default (singular)

```
- @app.get("/api/settings/subtitle/default")   # L1182 (구버전 기준)
- async def get_subtitle_defaults():
-     return db.get_subtitle_defaults()
-
- @app.post("/api/settings/subtitle/default")  # L1187
- async def save_subtitle_defaults(req: SubtitleDefaultSave):
-     db.save_global_setting("subtitle_default_style", req.dict())
-     return {"status": "ok"}
```

이유:
- 코드베이스 전체 검색 결과 프론트엔드 호출처 없음
- /defaults (plural) 라우트와 동일한 DB 함수 호출하나 응답 형식 불일치
  - singular: raw dict 반환
  - plural: {"status": "ok", "settings": {...}} 반환
- autopilot.js는 data.settings를 참조하므로 plural만 유효
