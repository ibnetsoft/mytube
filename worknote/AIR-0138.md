## 1. 개요
Autopilot 관련 중복 API 일부가 `main.py`와 `app/routers/autopilot.py`에 혼재되어 있어, 이 중 실제로 동작하지 않는 `main.py` 내의 Dead Route들을 제거하고 메인 코드를 간결하게 정리하였습니다.
기능상의 변경이나 API 응답 사양의 변경은 전혀 유발하지 않았습니다.
