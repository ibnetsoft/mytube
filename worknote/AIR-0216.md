## Release Artifact Structure

```
release/
  AIRStudio-{version}-win-x64.zip
  AIRStudio-{version}-win-x64.zip.sha256
  AIRStudioSetup-{version}.exe
  AIRStudioSetup-{version}.exe.sha256
  latest.json
  latest.json.sha256
```

## Build Number Flow

```
packaging/windows/build_counter.txt (215)
       │
       ├─ build_windows.ps1 reads → increments → writes back
       │   └─ passes to current.json + version.json + latest.json
       │
       └─ CI workflow reads next = current+1 → passes -Build to build_windows.ps1
           └─ commits updated counter back to repo [skip ci]
```

## Manual Release Commands

```powershell
# Build
.\tools\build_windows.ps1 -Version 1.0.0

# Publish
.\tools\release_github.ps1 -Version 1.0.0 -Build 216
```

## Automated Release

Push a version tag → GitHub Actions builds, packages, and publishes automatically:
```bash
git tag v1.0.0 && git push origin v1.0.0
```
