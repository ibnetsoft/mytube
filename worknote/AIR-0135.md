# AIR-0135: Repository API Cleanup — Duplicate create-plan Removal

Date: 2026-07-05
Branch: feature/AIR-0135-repository-api-cleanup
Status: COMPLETE

## Problem

`POST /api/repository/create-plan` was defined in two places:

1. `app/routers/repository.py` line 100 — via `router.post()`
2. `main.py` line 3672 — via `@app.post()` (dead code)

`repository_router.router` is included at main.py line 345,
BEFORE main.py's direct `@app.post` at line 3672.

FastAPI resolves routes in registration order — first match wins.
The repository.py handler was always called; main.py's handler was NEVER reached.

## Decision: Canonical = repository.py

| Criterion | repository.py (ACTIVE) | main.py (DEAD) |
|-----------|------------------------|----------------|
| Registration order | First (line 345) | Second (line 3672) |
| Actually called | YES | NO |
| success_factor saved | YES (project_settings) | NO |
| app_mode set | "longform" (explicit) | Not set |
| Gemini call | None (fast) | generate_script_structure (slow, blocking) |
| Input model | dict/Body (flexible) | Pydantic (strict) |
