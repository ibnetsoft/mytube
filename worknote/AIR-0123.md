# AIR-0123: Referral Settlement Worker (Pending)

## Goal
Implement a background worker to calculate and generate pending referral commissions based on Admin Recharge events, ensuring correct distribution for Level 1 and Level 2 sponsors.

## Actions Taken
- Modified `auth-web/app/api/admin/users/recharge/route.ts` to trigger a settlement process asynchronously upon successful token recharge.
- Created `auth-web/lib/settlement.ts` to calculate commissions:
  - Fetches `referral_level1_percent` and `referral_level2_percent` from `global_settings`. Defaults to `0` if not set (no fallbacks).
  - Rounds amounts to two decimal places.
  - Generates `pending` commissions for Level 1 and Level 2.
  - Safely ignores `OFF` mode, self-referrals, and loops.
- Created `auth-web/migration_settlement_unique.sql` containing a unique index on `metadata->>'source_tx_id'` and `commission_type` to prevent duplicate payout entries.
- Created `auth-web/app/api/admin/settlements/route.ts` and `auth-web/app/admin/settlements/page.tsx` for a read-only Admin Dashboard view of settlements.

## Status
- `main` merged.
- E2E flow verified for pending commission generation.
- Payout generation and automated transfers are excluded from this sprint and will be implemented in a subsequent phase.
