## Objectives
Introduce a "Production Workflow" guide to `image_gen.html` so that users know the exact 7 steps to generate an image and start video production, reducing onboarding friction.

## Key Changes
1. **Collapsible Workflow UI**: Added a UI container in `image_gen.html` that toggles between expanded and collapsed states, showing 7 steps from Prompt Generation to Ready for Video Generation.
2. **State Persistence & Auto-check**: 
   - State is persisted to `localStorage` under `imageWorkflow_{projectId}`.
   - Step 1 (Prompt Gen), Step 6 (Upload), and Step 7 (Render) are automatically checked based on backend API callbacks.
   - Steps 2-5 are manually checkable by users.
3. **i18n Support**: Supported translations for ko, en, vi, th for step descriptions, external badges, and OpenAI ChatGPT usage hints.
4. **UX Improvements**:
   - Added `Prompt 복사` and `Open ChatGPT` quick action buttons directly under Step 2 to easily copy prompts and jump to ChatGPT.
   - External tasks explicitly labeled with `[External]` / `[외부 작업]`.
